# 07. 엔진 테스트

> 상태: **확정**  
> 역할: 첫 3D 시뮬레이션이자 게임 규칙을 학습시키는 시험

## 1. 시험 목적

고정 시험대에 장착된 엔진을 점화해 목표 추력을 일정 시간 유지한다. 발사 전 설계 단계에서 플레이어는 엔진 부착 위치, 출력 방향, 목표 추력, 엔진 ON/OFF 타이밍을 조정한다. `발사` 이후에는 조작하지 않고 점화와 출력을 지켜본다.

엔진 시험은 다음 내용을 가르친다.

- 설계 단계에서 성공률을 확인한다.
- 연구 진행도와 설계 적합도가 결과에 영향을 준다.
- 부품 위치, 힘, 방향, 엔진 ON/OFF 타이밍이 결과에 영향을 준다.
- 경고가 발생해도 자동 복구하면 성공할 수 있다.
- 실패해도 진행도와 발사 경험이 조금 남는다.

## 2. 시험 조건

- 엔진 진행도 20 이상
- 발사 비용 600
- 현재 분기 1개 소비
- 엔진 단계는 게임 시작부터 활성화
- 설계 단계 진입은 비용과 분기를 소비하지 않음
- 발사 버튼 선택 전에는 연구 단계로 복귀 가능

## 3. 장면 구성

최소 에셋:

- 고정 엔진 1개
- 간단한 시험대
- 설계 단계용 목표 출력 라인
- 출력 방향 핸들
- 콘크리트 바닥과 안전벽
- 엔진 불꽃
- 연기
- 스파크
- 폭발 VFX
- 설계 오류 경고 VFX

## 4. 권장 시퀀스

설계 단계에서는 목표 추력 벡터와 안정 범위를 보여준다. 플레이어는 엔진 위치, 힘, 방향, ON/OFF 타이밍을 조정한 뒤 발사한다.

| 시간 | 상태 | 연출 |
|---:|---|---|
| 0~3초 | 브리핑 | `ENGINE STATIC FIRE TEST`, 날짜, 테스트 방식 |
| 3~6초 | 카운트다운 | 밸브음, 경고등, 3-2-1 |
| 6~10초 | 점화 | 작은 불꽃에서 주 불꽃으로 확대 |
| 10~18초 | 출력 유지 | 추력·온도·안정성 표시 |
| 18~22초 | 사고 또는 정상 종료 | 등급에 따른 분기 |
| 22~25초 | 종료 | 엔진 정지 또는 폭발 후 암전 |

총 길이 목표: 20~25초

## 5. 주요 지표

```text
THRUST
TEMPERATURE
STABILITY
```

결과 보고서에는 아래 값을 표시한다.

- 최대 추력 달성률
- 안정 연소 유지 시간
- 최고 온도
- 사고 원인

이 값은 실제 시뮬레이션 계산값이 아니라 등급과 사고에 맞춰 생성한다.

## 6. 사고 목록

| ID | 사고 | 주 연계 설계 항목 | 결과 표현 |
|---|---|---|---|
| `PressureSpike` | 연소실 압력 급증 | 힘 과다 | 불꽃 진동, 압력 경고 |
| `Overheat` | 과열 | OFF 타이밍 지연 | 온도 상승, 붉은 엔진 |
| `FuelLeak` | 연료 누출 | 일반 기술 사고 | 옆으로 새는 불꽃 또는 연기 |
| `IgnitionDelay` | 점화 지연 | ON 타이밍 지연 | 조명 깜빡임, 점화 불안정 |
| `Explosion` | 엔진 폭발 | F 결말 | 폭발과 카메라 흔들림 |

한 시험에서는 하나만 선택한다.

## 7. 등급별 연출

### S

- 빠르고 안정적인 점화
- 추력 105~112%
- 안정성 96~100%
- 정상 종료
- 강한 성공음

### A

- 온도 또는 압력 경고가 짧게 발생
- 자동 제어로 정상 범위 복귀
- 추력 100~106%
- 정상 종료

### B

- 불꽃이 크게 흔들리고 경고가 길게 유지
- 마지막 순간 안정화
- 추력 95~101%
- 최소 목표 달성 후 즉시 종료

### C

- 목표 추력에 근접하지만 안정 유지 시간 부족
- 자동 긴급 정지
- 엔진은 파괴되지 않음
- `TEST ABORTED`

### F

- 점화 실패, 연료 누출 화재 또는 압력 폭발
- 엔진과 시험대 일부 파손
- `CRITICAL FAILURE`

## 8. 설계 오류별 표현

- 힘 과다: 압력 경고와 불꽃 진동
- 힘 부족: 목표 추력 미달과 짧은 연소
- 방향 오류: 배기 방향 흔들림과 시험대 진동
- ON 타이밍 지연: 점화 지연과 카운트다운 후 침묵
- OFF 타이밍 지연: 온도 상승과 긴급 정지

설계 적합도가 낮은 항목을 사고 원인으로 우선 표현한다.

## 9. 카메라

1. 시험대 전체
2. 노즐 클로즈업
3. 계기 또는 옆면
4. 사고 순간 광각

4개 구도면 충분하다.

## 10. 완료 기준

- 점화, 유지, 종료의 세 구간이 명확하다.
- C는 안전 정지, F는 파괴 또는 점화 실패로 구분된다.
- 설계 오류 원인이 장면에 보인다.
- 텔레메트리와 결과 보고서 값이 일치한다.
- 폭발 후에도 결과가 중복 적용되지 않는다.
