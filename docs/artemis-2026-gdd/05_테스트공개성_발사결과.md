# 05. 테스트 공개성과 발사 결과

> 기준일: 2026-09-06  
> 이 문서는 실제 물리 발사의 결과 처리 계약을 정의한다.

## 1. 결과 원칙

발사 결과를 미리 정하지 않는다. 설치한 엔진, 추력 방향, 점화 시간과 실제 비행 중 발생한 물리 상태가 결과를 만든다.

결과 데이터는 아래 항목만 가진다.

- 미션 성공 여부
- 종료 사유
- 최고 고도, 이동 거리, 목표 구역 체류 시간, 총 연소 시간, 남은 연료 등 실제 텔레메트리
- 사용한 엔진 프리셋과 공개 여부

실행 전 결과 예측이나 결과 품질 표식은 사용하지 않는다.

## 2. 미션 성공

각 미션의 평가기는 실행 중 수집한 상태로 목표 충족 여부를 계산한다. 성공 조건은 `04_연구_진행도_단계해금.md`와 `launch-test-progression.md`를 따른다.

- 성공: 해당 미션의 모든 필수 조건 충족
- 실패: 종료 시점까지 필수 조건을 충족하지 못함
- 종료 사유: 이륙 실패, 연료 소진, 과열, 지면 충돌, 수면 접촉, 제한 시간 만료 등 실제 원인

종료 사유는 표시 문자열을 다시 분석하지 않고 구조화된 값으로 전달한다.

## 3. 엔진과 설계의 반영

엔진 스탯과 설계 입력은 시뮬레이션에 직접 반영한다.

- 최대 출력은 엔진 추력에 반영한다.
- 연료량과 연소율은 가동 가능 시간에 반영한다.
- 냉각 능력은 온도 변화와 과열 시점에 반영한다.
- 점화 신뢰도는 개별 엔진의 점화 시도에 반영한다.
- 장착 위치와 방향은 힘과 토크에 반영한다.
- ON/OFF 시간은 엔진 가동 구간에 반영한다.

이 값을 다시 하나의 보정치로 합쳐 결과를 덮어쓰지 않는다.

## 4. 공개·비공개 테스트

최종 미션을 제외한 발사에서는 공개 또는 비공개를 선택할 수 있다. 이 선택은 비행 물리와 미션 성공 여부를 바꾸지 않는다.

- 공개: 결과를 신문으로 발표하고 공개 발사 이벤트 후보를 사용한다.
- 비공개: 결과를 내부 메일로 보고하고 비공개 발사 이벤트 후보를 사용한다.
- 최종 미션: 특별호와 엔딩 흐름을 사용한다.

이벤트는 결과가 확정된 뒤 한 번만 선택하고 적용한다. 세부 규칙은 `../launch-outcome-events.md`를 따른다.

## 5. 진행 처리

- 일반 미션을 처음 성공하면 다음 미션을 연다.
- 이미 열린 미션은 다시 발사할 수 있다.
- 재발사는 기록과 후속 이벤트를 만들지만 별도 숙련 보너스를 주지 않는다.
- 최종 미션 성공은 즉시 승리 조건을 충족한다.
- 최종 미션 실패 또는 기간 만료는 승리로 처리하지 않는다.

## 6. 표시 원칙

발사 전에는 목표 조건, 현재 설계의 실제 수치, 비용만 보여준다. 결과 예측 수치는 보여주지 않는다.

발사 후에는 성공 여부, 종료 사유, 실제 텔레메트리와 정산 내역을 보여준다. 결과를 점수나 문자 표식으로 축약하지 않는다.
