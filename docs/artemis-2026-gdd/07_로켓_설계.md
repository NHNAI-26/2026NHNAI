# 07. 로켓 설계

## 정의

설계 단계에서 플레이어는 미션 목표를 보고 로켓에 엔진을 배치하고 방향과 작동 시간을 정한다. 발사 뒤에는 설계를 수정하지 않는다.

## 흐름

```text
미션 선택
-> 설계 비용 지불
-> 목표 확인
-> 엔진 설치·제거·재배치
-> 방향과 ON/OFF 시간 조정
-> 공개 여부 선택
-> 발사 확정 또는 연구 화면 복귀
```

## 조립 규칙

- 엔진은 로켓 표면에 자유롭게 부착한다.
- 선택한 엔진은 로컬 축 기즈모로 이동·회전한다.
- 추력은 각 엔진의 실제 `up` 방향으로 작용한다.
- 힘은 엔진이 붙은 위치에서 가해져 비대칭 배치가 토크를 만든다.
- 연료와 열 상태는 엔진 개체별로 처리한다.
- 엔진 제거와 설계 취소는 확정 전 설치 비용을 돌려준다.
- 정렬 가이드는 기존 엔진과 높이·방위각을 맞추되 자동 균등 배치는 하지 않는다.

세부 조작과 구현은 `../rocket-simulation.md`와 `../specs/rocket-symmetry-assist-spec.md`를 따른다.

## 화면 정보

- 미션 목표와 목표 구역
- 설치 가능한 프리셋과 실제 엔진 스탯
- 엔진별 설치 비용
- 방향과 작동 구간
- 예상 총질량, 총추력, 총연료와 열 관련 실제 수치
- 공개·비공개 선택

결과 예측이나 종합 설계 점수는 표시하지 않는다. 위험 안내가 필요하면 “총추력이 현재 중량보다 부족함”처럼 실제 수치 관계를 직접 설명한다.

## 설계 데이터

```text
missionId
mapSeed
targetPathId
partPlacements
installedEngines
reservedEngineInstallCost
engineToggleSchedules
launchVisibility
```

부품 배치는 프리셋 ID, 로켓 로컬 위치, 로컬 회전과 설치 비용을 가진다. 발사 확정 시 이 데이터를 잠그고 시뮬레이션에 전달한다.

## 물리 연결

| 설계 요소 | 실제 영향 |
|---|---|
| 엔진 출력 | 추력 크기 |
| 장착 위치 | 힘이 적용되는 지점과 토크 |
| 장착 회전 | 추력 방향 |
| 연료와 작동 시간 | 연소 지속 시간 |
| 냉각 | 온도 변화와 과열 |
| 점화 신뢰도 | 개별 엔진의 시작 점화 |

설계 입력은 물리에 직접 전달한다. 별도 결과 보정값으로 변환하지 않는다.

## 완료 기준

- 엔진을 로켓 표면에 붙이고 다시 옮길 수 있다.
- 비대칭 배치가 실제 회전을 만든다.
- 엔진 방향과 작동 시간 변경이 실제 궤적을 바꾼다.
- 발사 전 취소와 엔진 제거가 예약 비용을 정확히 복구한다.
- 발사 확정 뒤 설계를 바꿀 수 없다.
- 공개 여부를 바꿔도 물리 입력은 바뀌지 않는다.
