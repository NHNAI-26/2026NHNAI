# 06. 엔진 연구

> 상태: **확정**
> 역할: 개발된 프리셋 엔진을 개체별로 업그레이드하고, 정적 연소 시험으로 선택 엔진을 검증합니다.
> 적용 우선순위: 엔진 개발, 엔진 시험과 로켓 단계의 엔진 반영 규칙은 이 문서를 우선합니다.

## 1. 단계 목표

엔진 연구에서 플레이어는 제한된 연구비와 시간으로 현재 개발된 프리셋 엔진 중 하나를 선택해 업그레이드합니다. 게임 시작 시에는 `Engine01` 하나만 개발되어 있고, `새로운 엔진 개발` 버튼으로 최대 10개까지 프리셋을 늘립니다. 연구 대상 엔진과 성능 항목을 고르면 해당 성능에 맞는 짧은 미니게임이 시작됩니다. 미니게임 점수에 따라 선택한 엔진 프리셋의 스탯과 업그레이드 레벨이 오릅니다.

엔진 프리셋 레벨이 1 이상이면 고정 시험대에서 정적 연소 시험을 실시할 수 있습니다. 시험 결과는 해당 프리셋의 스탯 평균, 가장 낮은 스탯, 스탯 간 불균형과 시험 경험을 이용해 확률로 결정합니다.

엔진 시험이 시작된 뒤에는 플레이어가 결과에 개입하지 않습니다. 엔진 단계에서는 로켓 본체의 부품 위치, 출력 방향이나 힘을 직접 배치하는 별도의 설계 맵을 사용하지 않습니다. 개발 미니게임에서 결정한 프리셋별 엔진 스탯이 이후 로켓 설계에서 설치 가능한 엔진 데이터가 됩니다.

## 2. 핵심 데이터

엔진은 프리셋별로 업그레이드 레벨, 네 가지 스탯, 시험 기록을 가집니다.

### 2.1 엔진 프리셋

| ID | 표시 이름 | 초기 성격 | 일반 연구 비용 | 집중 연구 비용 | 설치 비용 |
|---|---|---|---:|---:|---:|
| `Engine01`~`Engine10` | 엔진 01~10 | 동일 규격, 연구 상태만 개별 성장 | 350 | 650 | 350 |

- 각 프리셋은 레벨 `0~5`를 가진다.
- 일반 연구는 선택 엔진 레벨 `+1`.
- 집중 연구는 선택 엔진 레벨 `+2`.
- 레벨 5에 도달한 엔진은 추가 연구할 수 없다.
- 엔진 프리셋 슬롯은 최대 10개다.
- 게임 시작 시에는 `Engine01` 하나만 개발되어 연구 단계에 표시된다.
- `새로운 엔진 개발` 버튼을 누르면 `Engine02`부터 순서대로 새 프리셋이 생긴다.
- 아직 개발되지 않은 프리셋은 연구나 설계 설치 대상으로 선택할 수 없다.
- 새 프리셋 개발 비용과 소요 시간은 아직 미정이다.
- 엔진 시험은 선택 엔진 레벨 1 이상에서 가능하다.
- 로켓 단계 해금 조건은 어떤 엔진이든 엔진 시험 `C 이상`이다.
- 발사 결과는 엔진 레벨이나 스탯을 직접 올리지 않는다.

### 2.2 엔진 스탯

| ID | 표시 이름 | 주요 기능 |
|---|---|---|
| `FuelCapacity` | 연료 탱크 용량 | 연소 시간을 늘리지만 탱크 무게를 증가시킵니다 |
| `Cooling` | 냉각 능력 | 열을 배출하고 연소와 출력 제어를 안정적으로 유지합니다 |
| `MaxOutput` | 최대 출력 | 무거운 로켓을 들어 올릴 추력을 제공합니다 |
| `IgnitionReliability` | 점화 신뢰도 | 엔진이 정상적으로 점화되고 재점화될 가능성을 높입니다 |

각 스탯은 `0~100` 범위로 제한합니다. 초기값은 모든 프리셋이 같습니다. 엔진 개발과 시험 결과는 프리셋별로 현재 게임 세션에 계속 저장합니다.

## 3. 스탯 상관관계

높은 스탯이 항상 좋은 결과만 만들지는 않습니다. 최대 출력을 높이면 더 많은 연료와 냉각 능력이 필요합니다. 냉각 능력이 부족하면 열, 연소와 출력 제어가 함께 불안정해집니다. 점화 신뢰도가 낮으면 충분히 개발한 엔진도 점화를 시작하지 못할 수 있습니다.

| 상태 | 발생 조건 | 예상 문제 |
|---|---|---|
| 큰 탱크와 낮은 출력 | 연료 탱크가 최대 출력보다 크게 높음 | 탱크 무게 때문에 목표 추력 미달 |
| 높은 출력과 작은 탱크 | 최대 출력이 연료 탱크보다 크게 높음 | 연료 조기 소진과 연소 시간 부족 |
| 높은 출력과 낮은 냉각 | 최대 출력이 냉각 능력보다 높음 | 과열, 추력 진동, 제어 실패 또는 폭발 |
| 높은 출력과 낮은 점화 신뢰도 | 최대 출력이 점화 신뢰도보다 크게 높음 | 점화 실패 또는 재점화 실패 |

플레이어는 시험 전에 성공 확률과 가장 위험한 두 가지 관계를 확인할 수 있습니다. 내부 계산식을 직접 풀지 않아도 현재 엔진의 약점을 이해할 수 있어야 합니다.

## 4. 엔진 개발 행동

플레이어는 개발할 엔진 프리셋과 스탯을 선택한 뒤 일반 개발과 집중 개발 중 하나를 고릅니다.

| 개발 방식 | 비용 | 레벨 | 미니게임 스탯 보상 | 소요 시간 |
|---|---|---:|---:|---:|
| 일반 개발 | 엔진별 일반 연구 비용 | +1 | +10~16 | 1분기 |
| 집중 개발 | 엔진별 집중 연구 비용 | +2 | +16~26 | 1분기 |

개발 행동의 처리 순서는 다음과 같습니다.

```text
개발할 엔진 프리셋 선택
→ 개발할 스탯 선택
→ 일반 또는 집중 개발 선택
→ 비용 검사 및 차감
→ 해당 스탯의 미니게임 실행
→ 점수 확정
→ 점수에 따른 스탯 증가
→ 선택 엔진 레벨 증가
→ 결과 표시
→ 분기 종료 및 정기 연구비 지급
```

미니게임을 중간에 종료하거나 제한 시간 안에 완료하지 못해도 최저 보상을 적용합니다. 엔진 스탯과 레벨이 감소하는 결과는 없습니다.

### 4.1 새로운 엔진 개발

`새로운 엔진 개발`은 업그레이드가 아니라 새 프리셋 슬롯을 여는 행동입니다.

```text
새로운 엔진 개발 선택
→ 최대 프리셋 수 10개 검사
→ 다음 슬롯 인덱스 선택
→ Engine02, Engine03 순서로 프리셋 생성
→ 기본 스펙과 비용 적용
→ 운영 화면에 새 엔진 카드 표시
```

새 엔진 개발의 비용과 소요 시간은 아직 확정하지 않습니다. 구현은 해당 값을 `0`으로 고정하거나 연구 비용과 공유하지 말고, 별도 밸런스 값으로 분리해 나중에 쉽게 바꿀 수 있게 합니다.

## 5. 미니게임 점수와 보상

모든 미니게임은 `0~100` 점수를 사용합니다. 낮은 점수를 실패로 표시하지 않고, 잘할수록 더 많은 스탯을 받는 보너스 구조로 처리합니다.

| 점수 | 결과 문구 | 일반 개발 | 집중 개발 |
|---:|---|---:|---:|
| 0~49 | 개발 완료 | +10 | +16 |
| 50~79 | 개발 성공 | +13 | +21 |
| 80~100 | 훌륭한 개발 | +16 | +26 |

미니게임 점수는 별도 자원으로 저장하지 않습니다. 증가한 엔진 스탯과 프리셋 레벨만 게임 상태에 저장합니다.

## 6. 공통 미니게임 규칙

- 한 번의 플레이 시간은 `8~10초`
- 마우스만으로 조작 가능
- 설명 문구는 한 문장만 표시
- 첫 플레이에 2초 이내의 조작 예시 표시
- 낮은 점수에서도 개발 진행
- 잘못된 입력 후 즉시 재조작 가능
- 별도 실패 화면과 재시작 화면 없음
- 미니게임 종료 직후 점수, 스탯 증가량과 엔진 레벨 표시

점수 계산이 끝난 뒤에는 같은 행동을 다시 플레이해 결과를 바꿀 수 없습니다. 다시 개발하려면 비용과 한 분기를 사용하는 새 행동을 시작해야 합니다.

## 7. 스탯별 미니게임

### 7.1 연료 탱크 용량: 연료 주입

움직이는 연료 게이지를 목표선에 맞춥니다.

- 조작: 버튼을 누른 상태로 주입하고 목표선에서 놓기
- 시도 횟수: 3회
- 채점: 목표선과 실제 주입량의 차이
- 안내 문구: `목표 용량까지 연료를 채우세요.`

목표선을 조금 넘거나 채우지 못해도 다음 시도를 계속합니다. 세 번의 평균 정확도로 최종 점수를 계산합니다.

### 7.2 냉각 능력: 냉각 밸브 제어

엔진 그림에서 뜨거워지거나 출력이 불안정해진 위치를 확인하고 연결된 냉각 밸브를 누릅니다. 냉각 능력은 열 배출, 연소 안정화와 자동 출력 제어를 함께 나타냅니다.

- 조작: 빛나는 위치와 같은 색의 밸브 클릭
- 작동 횟수: 4회
- 채점: 정확도와 반응 시간
- 안내 문구: `뜨거워진 부분의 냉각 밸브를 여세요.`

잘못된 밸브를 누르면 점수가 감소하지만 미니게임은 계속됩니다.

### 7.3 최대 출력: 출력 단계 올리기

출력 게이지가 초록색 영역에 들어왔을 때 다음 출력 단계로 올립니다.

- 조작: 클릭
- 출력 단계: 30%, 60%, 100%
- 채점: 세 단계에서 누른 위치의 정확도
- 안내 문구: `안전 영역에서 출력을 올리세요.`

너무 빠르면 출력이 부족하고, 너무 늦으면 붉은 경고가 나타납니다.

### 7.4 점화 신뢰도: 점화 순서 맞추기

세 개의 점화 장치가 빛난 순서를 기억한 뒤 같은 순서로 누릅니다.

- 조작: 점화 장치 클릭
- 진행 횟수: 3회
- 채점: 입력 순서의 정확도와 반응 시간
- 안내 문구: `빛난 순서대로 점화 장치를 누르세요.`

첫 번째 시도는 장치 두 개, 마지막 시도는 장치 네 개로 구성합니다. 잘못 눌러도 현재 시도만 종료하고 다음 시도를 계속합니다.

## 8. 개발 화면

개발된 엔진 프리셋 카드와 선택 엔진의 네 스탯을 한 화면에 표시합니다. 처음에는 엔진 01 카드만 보이고, `새로운 엔진 개발` 버튼으로 새 카드가 추가됩니다.

```text
엔진 연구

엔진 01 Lv.2   설치 350
엔진 02 Lv.1   설치 350
엔진 03 Lv.0   설치 350

[새로운 엔진 개발]

선택: 엔진 02
연료 탱크 용량                    42
냉각 능력                         36
최대 출력                         61
점화 신뢰도                       48

현재 예상 문제
과열 위험                         높음
점화 실패                         주의

[일반 연구 350]  [집중 연구 650]
[엔진 02 시험 600]
```

스탯을 선택하면 해당 스탯의 기능과 현재 상관관계를 보여줍니다.

```text
냉각 능력                         36

고출력 상태에서 엔진이
과열되는 것을 방지합니다.

현재 최대 출력에 비해 부족합니다.
```

## 9. 개발 결과 화면

```text
냉각 장치 개발 완료

미니게임 점수                     82
평가                              훌륭한 개발

냉각 능력                         36 → 62
엔진 02 레벨                      1 → 3

엔진 시험을 시작할 수 있습니다.
```

결과는 2초 뒤 자동으로 닫거나 클릭으로 즉시 닫을 수 있습니다.

## 10. 엔진 시험 조건

- 시험할 엔진 프리셋 레벨 1 이상
- 시험 비용 600
- 현재 분기 1개 소비
- 엔진 단계는 게임 시작부터 활성화
- 시험 결과는 `S`, `A`, `B`, `C`, `F`
- 시험 시작 전에는 취소 가능
- 시험 시작 이후 결과 개입 불가

특정 스탯의 최저 조건은 두지 않습니다. 극단적으로 불균형한 엔진도 시험할 수 있지만 성공 확률이 낮고 해당 약점과 연결되는 실패 이유를 가집니다.

## 11. 엔진 품질 계산

선택한 엔진 프리셋의 네 스탯 평균과 최저 스탯을 구합니다.

```text
평균 스탯 =
(연료 탱크 용량
+ 냉각 능력
+ 최대 출력
+ 점화 신뢰도) / 4

엔진 품질 =
평균 스탯 × 0.6
+ 최저 스탯 × 0.4
```

가장 낮은 스탯도 품질에 크게 반영합니다. 하나의 성능을 완전히 방치하면 다른 성능만으로 모두 보완할 수 없습니다.

## 12. 불균형 페널티

각 관계의 페널티를 계산한 뒤 합계를 최대 35로 제한합니다.

```text
탱크 과중량 =
max(0, 연료 탱크 용량 - 최대 출력 - 15) × 0.4

연료 부족 =
max(0, 최대 출력 - 연료 탱크 용량 - 15) × 0.4

냉각 부족 =
max(0, 최대 출력 - 냉각 능력 - 10) × 0.6

점화 불안정 =
max(0, 최대 출력 - 점화 신뢰도 - 20) × 0.35

최저 스탯 페널티 =
max(0, 35 - 최저 스탯) × 0.8

불균형 페널티 =
min(
    탱크 과중량
    + 연료 부족
    + 냉각 부족
    + 점화 불안정
    + 최저 스탯 페널티,
    35
)
```

## 13. 엔진 시험 확률

```text
성공 확률 =
20
+ 선택 엔진 레벨 × 6
+ 엔진 품질 × 0.6
- 불균형 페널티
+ 시험 경험 보너스
```

최종 성공 확률은 반올림한 뒤 `10~90%`로 제한합니다.

시험 경험 보너스는 기존 규칙을 사용합니다.

```text
시험 경험 보너스 =
min(이전 엔진 시험 횟수 × 3, 9)
```

부분 성공과 실패 확률은 기존 판정 구조를 유지합니다.

```text
부분 성공 확률 = min(15, 95 - 성공 확률)
실패 확률 = 100 - 성공 확률 - 부분 성공 확률
```

## 14. 등급 판정

`1~100` 정수 난수를 한 번 생성합니다.

```pseudo
roll = RandomIntInclusive(1, 100)

if roll <= successChance:
    margin = successChance - roll

    if margin >= 50:
        grade = S
    else if margin >= 20:
        grade = A
    else:
        grade = B
else if roll <= min(successChance + 15, 95):
    grade = C
else:
    grade = F
```

- S, A, B: 완전 성공
- C: 일부 목표 달성 후 안전 중단
- F: 시험 실패

시험 결과로 얻는 지원금과 분기 연구비 변화는 공통 등급 보상표를 사용합니다. 시험 결과는 엔진 스탯이나 레벨을 직접 올리지 않습니다.

## 15. 시험 전 위험 안내

시험 확인창에는 확률과 주요 위험 두 개를 표시합니다.

```text
엔진 정적 연소 시험

성공                              46%
부분 성공                         15%
실패                              39%

주요 위험
출력 부족                         높음
연소 시간 부족                    낮음

현재 엔진은 큰 연료 탱크에 비해
최대 출력이 부족합니다.

비용 600                          1분기

[취소]                            [시험 시작]
```

위험도는 `낮음`, `주의`, `높음`의 세 단계로 표시합니다. 색뿐 아니라 문구와 아이콘을 함께 사용합니다.

## 16. 실패 이유 계산

시험 결과가 C 또는 F이면 현재 엔진 스탯을 이용해 실패 이유별 위험 점수를 계산합니다.

```text
출력 부족 위험 =
(100 - 최대 출력)
+ max(0, 연료 탱크 용량 - 최대 출력) × 1.5

연료 소진 위험 =
(100 - 연료 탱크 용량)
+ max(0, 최대 출력 - 연료 탱크 용량) × 1.5

냉각 계통 위험 =
(100 - 냉각 능력)
+ max(0, 최대 출력 - 냉각 능력) × 1.5

점화 실패 위험 =
(100 - 점화 신뢰도)
+ max(0, 최대 출력 - 점화 신뢰도) × 1.2
```

계산한 위험 점수를 가중치로 사용해 실패 이유 하나를 선택합니다. 약한 스탯과 연결된 문제가 더 자주 발생하지만 같은 엔진에서 항상 같은 결과만 나오지는 않습니다.

한 번의 시험에는 주요 실패 이유를 하나만 사용합니다.

## 17. 실패 이유별 결과

| 실패 이유 | C 부분 성공 | F 실패 |
|---|---|---|
| 출력 부족 | 목표 출력에 근접한 뒤 안전 정지 | 목표 추력 도달 실패 |
| 연료 소진 | 일부 연소 시간을 채운 뒤 종료 | 연료 소진으로 화염 상실 |
| 냉각 계통 이상 | 온도 또는 압력 경고 후 자동 정지 | 과열, 출력 폭주, 화재 또는 연소실 파손 |
| 점화 실패 | 점화 지연 후 시험 중단 | 점화 불발 또는 재점화 실패 |

S에서는 주요 사고를 발생시키지 않습니다. A와 B에서는 가장 높은 위험과 연결된 경고가 나타날 수 있지만 자동으로 복구합니다.

## 18. 3D 시험 시퀀스

| 시간 | 상태 | 연출 |
|---:|---|---|
| 0~3초 | 브리핑 | 시험명, 날짜와 엔진 스탯 요약 |
| 3~6초 | 카운트다운 | 밸브음, 경고등과 3-2-1 표시 |
| 6~10초 | 점화 | 작은 불꽃에서 주 불꽃으로 확대 |
| 10~18초 | 출력 유지 | 추력, 온도와 점화 상태 표시 |
| 18~22초 | 사고 또는 정상 종료 | 등급과 실패 이유에 맞는 분기 |
| 22~25초 | 종료 | 엔진 정지 또는 실패 연출 후 보고서 전환 |

총 길이는 `20~25초`를 목표로 합니다.

카메라는 다음 네 구도를 사용합니다.

1. 시험대 전체
2. 노즐 근접 화면
3. 엔진 측면과 계기 화면
4. 사고 순간의 광각 화면

## 19. 등급별 연출

### S

- 빠르고 안정적인 점화
- 추력 105~112%
- 안정성 96~100%
- 경고 없이 정상 종료

### A

- 가장 높은 위험과 연결된 짧은 경고
- 자동 제어로 즉시 정상 범위 복귀
- 추력 100~106%
- 정상 종료

### B

- 불꽃과 출력이 크게 흔들림
- 종료 직전에 자동 안정화
- 추력 95~101%
- 최소 목표 달성 후 종료

### C

- 목표 추력에 근접하거나 일부 연소 시간 달성
- 선택된 실패 이유에 따라 자동 긴급 정지
- 엔진 본체의 치명적 파손 없음
- `TEST ABORTED` 표시

### F

- 선택된 실패 이유에 따라 점화 실패, 화염 상실, 화재 또는 폭발
- 엔진이나 시험대 일부 파손
- `CRITICAL FAILURE` 표시

S, A, B는 정상 연소 시퀀스를 공유합니다. 경고 시간, 흔들림, 텔레메트리와 결과 보고서로 차이를 표현합니다.

## 20. 결과 보고서

결과 보고서는 실패 이유와 관련된 스탯을 함께 보여줍니다.

```text
엔진 시험 결과

등급                              F
결과                              시험 실패
실패 이유                         냉각 능력 부족

최대 출력                         74
냉각 능력                         31

현재 출력에 비해 냉각 능력이 부족해
온도 한계를 초과했습니다.

엔진 레벨                         변화 없음
시험 경험                         +3%p
분기 연구비                       -100

[프로젝트로 돌아가기]
```

결과가 S, A 또는 B이면 사고 대신 성공에 가장 크게 기여한 스탯 관계를 표시합니다. C와 F에서는 다음 개발에 필요한 스탯을 직접 안내합니다.


첫 시험에서는 성공 확률이 약 65%입니다. 시험 안정성은 높지만 무거운 로켓에서는 출력이 부족할 수 있습니다.

## 22. 엔진 데이터 저장

엔진 상태는 프리셋별로 게임 세션에 계속 보존합니다.

```text
EnginePresetState
    presetId
    level
    fuelCapacity
    cooling
    maxOutput
    ignitionReliability
    attemptCount
    bestGrade
```

- 엔진 시험 후에도 스탯 유지
- 로켓 단계 해금 후에도 스탯 유지
- 레벨 5 전까지 해당 프리셋 추가 연구 가능
- 추가 개발 결과를 이후 엔진 시험과 로켓 발사에 즉시 반영
- 새 게임을 시작할 때만 초기값으로 재설정

## 23. 로켓 발사 단계 반영

로켓 발사에서는 설계 단계에 설치한 엔진 인스턴스들의 프리셋 스탯으로 네 가지 파생 성능을 계산합니다.

### 23.1 이륙 성능

```text
이륙 성능 =
clamp(
    최대 출력
    - 연료 탱크 용량 × 0.25
    + 30,
    0,
    100
)
```

연료 탱크가 크면 로켓이 무거워지므로 더 높은 최대 출력이 필요합니다.

### 23.2 연소 지속력

```text
연소 지속력 =
clamp(
    연료 탱크 용량
    - 최대 출력 × 0.35
    + 25,
    0,
    100
)
```

출력이 높고 연료 탱크가 작으면 상승 중 연료가 빨리 소진됩니다.

### 23.3 열 안전성

```text
열 안전성 =
clamp(
    냉각 능력
    - 최대 출력 × 0.5
    + 30,
    0,
    100
)
```

높은 출력을 오래 사용하려면 냉각 능력이 필요합니다.

### 23.4 점화 성능

```text
점화 성능 =
clamp(
    점화 신뢰도 × 0.8
    + 냉각 능력 × 0.2
    - 최대 출력 × 0.2
    + 20,
    0,
    100
)
```

높은 출력의 엔진은 점화 장치에 더 큰 부담을 줍니다. 냉각 능력은 점화 직후의 열과 출력 불안정을 보조합니다.

### 23.5 엔진 발사 적합도

```text
엔진 발사 적합도 =
(이륙 성능
+ 연소 지속력
+ 열 안전성
+ 점화 성능) / 4
```

로켓 발사 성공률에서는 전역 엔진 값 대신 설치 엔진들의 엔진 발사 적합도를 사용합니다.

```text
로켓 발사 성공률 =
20
+ 설치 엔진 발사 적합도 × 0.55
+ 직전 단계 최고 등급 보너스
+ 발사 경험 보너스
+ 로켓 설계 적합도 보정
```

## 24. 로켓 발사 실패 이유 연결

엔진 파생 성능 중 낮은 항목은 로켓 발사의 실패 이유와 연결합니다.

| 낮은 파생 성능 | 로켓 발사 문제 |
|---|---|
| 이륙 성능 | 추력 부족 또는 발사대 이탈 실패 |
| 연소 지속력 | 상승 중 연료 소진 또는 엔진 조기 정지 |
| 열 안전성 | 상승 중 과열, 추력 진동 또는 출력 제어 실패 |
| 점화 성능 | 발사대 점화 실패 또는 재점화 실패 |

로켓 자체의 구조나 유도 위험과 엔진 위험을 함께 계산한 뒤 한 번의 발사에는 주요 실패 이유 하나만 선택합니다.

## 25. 구현 우선순위

### P0

- 개발된 엔진 프리셋의 레벨과 네 스탯 저장
- 새 엔진 개발로 최대 10개까지 프리셋 생성
- 개발 대상 선택
- 일반 개발과 집중 개발
- 스탯별 미니게임 4종

- 엔진 품질과 불균형 페널티 계산
- 성공, 부분 성공과 실패 확률 표시
- 스탯 기반 실패 이유 선택
- 엔진 정적 연소 시험의 성공, 중단과 실패 연출
- 로켓 발사 적합도 계산과 로켓 단계 전달

### P1

- 미니게임별 추가 애니메이션과 사운드
- 위험 관계를 보여주는 간단한 연결선

일정이 부족하면 미니게임의 시각 표현을 단순화하되 네 스탯과 상관관계는 유지합니다.

## 26. 완료 기준

- 엔진 프리셋은 시작 시 1개만 보이고, 새 엔진 개발로 최대 10개까지 늘어납니다.
- 엔진 01~10은 같은 초기 스탯과 비용을 가지고, 연구 선택에 따라 각자 다른 성장 상태가 됩니다.
- 일반 개발과 집중 개발이 선택 프리셋의 비용과 레벨 증가를 적용합니다.
- 미니게임 점수에 따라 선택한 스탯이 정확히 증가합니다.
- 미니게임 점수가 낮아도 최저 보상을 받습니다.
- 레벨 1 미만 엔진은 엔진 시험을 시작할 수 없습니다.
- 시험 확인창에 성공, 부분 성공, 실패와 주요 위험을 표시합니다.
- 같은 입력 데이터와 시드에서는 같은 등급과 실패 이유가 나옵니다.
- C와 F의 실패 이유가 현재 엔진의 약점과 연결됩니다.
- 한 시험에서 주요 실패 이유를 하나만 사용합니다.
- 시험 결과와 보상이 한 번만 적용됩니다.
- 엔진 스탯이 로켓 단계로 전달됩니다.
- 로켓 성공률과 실패 이유에 엔진 파생 성능이 반영됩니다.
- 레벨 5에 도달한 엔진 프리셋은 추가 연구가 비활성화됩니다.
- 새 게임에서 엔진 상태가 초기화됩니다.
