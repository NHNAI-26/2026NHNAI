# 06. 엔진 연구

## 목적

연구는 엔진 프리셋의 실제 물리 성능을 바꾸는 준비 단계다. 연구 뒤 별도의 엔진 시험 결과를 굴리지 않는다.

## 프리셋 데이터

- 완성도
- 연료 탱크 용량
- 냉각 능력
- 최대 출력
- 점화 신뢰도

모든 값은 프리셋별로 저장한다. 완성도는 연구 가능량을 제한하며 성능 배율이나 설계 진입 조건으로 쓰지 않는다.

## 연구 미니게임

| 스탯 | 미니게임 | 실제 반영 |
|---|---|---|
| 연료 탱크 용량 | 연료 주입 | 사용 가능 연료 |
| 냉각 능력 | 냉각 밸브 제어 | 열 감소와 과열 지연 |
| 최대 출력 | 출력 고정 | 엔진 추력 |
| 점화 신뢰도 | 점화 순서 | 개별 엔진 점화 |

미니게임의 입력 정확도는 해당 연구 행동에서 얻는 스탯 증가량을 정한다. 결과 피드백은 점수와 실제 증가량으로 표시한다. 연구 행동 자체의 성공 여부를 따로 결정하지 않는다.

## 연구 처리

1. 프리셋과 스탯을 선택한다.
2. 비용과 연구 가능 여부를 확인한다.
3. 미니게임을 실행한다.
4. 입력 점수로 스탯 증가량을 계산한다.
5. 완성도를 고정량 올린다.
6. 실제 변화량을 결과 화면에 표시한다.
7. 시간을 진행한다.

결과 적용은 한 번만 실행한다. 완성도와 스탯은 0~100 범위로 제한한다.

## 발사 반영

스탯은 시뮬레이션 물리에 직접 전달한다. 네 값을 하나의 품질값이나 발사 보정치로 합치지 않는다. 이전 미션 기록도 엔진 성능에 더하지 않는다.

## UI

연구 전에는 현재 스탯, 비용, 예상 연구 증가 범위를 보여준다. 연구 후에는 미니게임 점수, 스탯 실제 증가량과 완성도 변화를 보여준다. 발사 결과 예측은 표시하지 않는다.

## 완료 기준

- 같은 프리셋을 연구하면 그 프리셋만 변한다.
- 입력 점수와 스탯 증가량이 일치한다.
- 완성도 100에서는 추가 연구가 막힌다.
- 연구 결과가 다음 발사의 실제 엔진 수치에 반영된다.
- 연구 결과 적용을 반복 호출해도 중복 성장하지 않는다.
