# 14. 아트·VFX·사운드

> 상태: **범위 확정**  
> 목표: 적은 에셋으로 4개 설계·발사의 차이를 명확히 보여준다.

## 1. 아트 방향

권장 스타일:

- 세미리얼 또는 깔끔한 로우폴리
- 실루엣과 조명 중심
- 세부 기계 구조보다 발사 규모와 긴장감 강조
- 회색·흰색 기체, 어두운 우주, 따뜻한 엔진 불꽃
- 운영 UI는 관제실 소프트웨어처럼 정돈된 표현

실제 아르테미스 장비를 정확히 복제할 필요는 없다. 게임 내 기체는 프로젝트를 상징하는 간소화된 창작 디자인으로 통일한다.

## 2. 필수 3D 에셋

| 우선순위 | 에셋 | 수량 | 재사용 |
|---|---|---:|---|
| P0 | 엔진 또는 노즐 | 1 | 엔진 발사·로켓 |
| P0 | 시험용 로켓 | 1 | 로켓·궤도 |
| P0 | 달 착륙선 | 1 | 달 착륙 |
| P0 | 엔진 시험대 | 1 | 엔진 |
| P0 | 단순 발사대 | 1 | 로켓 |
| P0 | 지구 구체 | 1 | 궤도 |
| P0 | 달 지형 | 1 | 달 |
| P0 | 우주 배경 | 1 | 궤도·달 |
| P1 | 통신 안테나 또는 관제 장식 | 소수 | 배경 |
| P2 | 국기·승무원·차량 | 제외 또는 선택 | 성공 장면 |

## 3. 머티리얼

최소 머티리얼 세트:

- 흰색 도장 금속
- 어두운 금속
- 단열재 또는 금색 호일
- 콘크리트
- 달 표면
- 지구 표면
- 발광 경고등
- 불꽃용 Additive 재질

복잡한 손상 데칼 시스템은 만들지 않는다. 손상은 검은 머티리얼 교체, 연기, 스파크로 표현한다.

## 4. 필수 VFX

| VFX | 사용 장면 |
|---|---|
| 엔진 주 불꽃 | 모든 발사 |
| 점화 연기 | 엔진·로켓 |
| 지상 먼지 | 로켓·달 착륙 |
| 스파크 | 모든 사고 |
| 폭발 | 엔진·로켓·달 실패 |
| 유성 궤적 | 궤도·달 |
| 작은 충돌 파편 | 궤도 |
| 비·번개 | 엔진·로켓 |
| 통신 노이즈 오버레이 | 궤도·달 |
| 카메라 흔들림 | 점화·폭발·경착륙 |

같은 폭발 VFX를 크기와 위치만 바꿔 재사용한다.

## 5. 환경별 시각 패키지

### Stable

- 기본 조명
- 추가 효과 없음

### Ideal

- 밝고 맑은 조명
- 깨끗한 하늘
- HUD 경고 없음

### HighWind

- 빠르게 이동하는 구름
- 방향성 먼지
- 연기 파티클의 옆 흐름
- 기체 미세 흔들림

### Thunderstorm

- 어두운 조명
- 비
- 번개
- 짧은 전력 깜빡임

### MeteorShower

- 배경 유성 여러 개
- 근접 유성 1개
- C/F에서 충돌 스파크

### SolarStorm

- 화면 노이즈
- 통신 글리치
- 붉은 경고 오버레이
- 끊기는 통신음

## 6. 카메라 제작량

각 장면당 P0 카메라 수:

| 장면 | 카메라 수 |
|---|---:|
| 엔진 | 3 |
| 로켓 | 4 |
| 궤도 | 4 |
| 달 착륙 | 4 |

추가 구도는 P1이다. 카메라 움직임보다 구도 전환을 우선한다.

## 7. UI 아트

필수:

- 단계 아이콘 4개
- 환경 아이콘 6개
- 등급 배지 S/A/B/C/F
- 잠금 아이콘
- 연구비 아이콘
- 시간 또는 달력 아이콘
- 경고 아이콘

모두 단색 또는 2색 벡터 스타일로 통일하면 제작이 빠르다.

## 8. 사운드 방향

게임의 긴장은 음악보다 기계음과 통신음에서 나온다.

### 운영 화면

- 낮은 볼륨의 관제실 드론
- 버튼 클릭
- 진행도 증가음
- 정기 연구비 지급음
- 단계 해금음
- 마지막 4분기에는 낮은 펄스 추가

### 엔진

- 밸브 개방
- 점화
- 지속 연소
- 금속 진동
- 긴급 정지
- 폭발

### 로켓

- 카운트다운
- 발사대 경고음
- 강한 엔진음
- 바람
- 구조 진동
- 추락·폭발

### 궤도

- 저역의 우주 앰비언스
- 점화음
- 통신 비프
- 유성 통과
- 금속 충돌
- 신호 노이즈

### 달 착륙

- 통신 음성
- 하강 엔진
- 연료 경고
- 달 먼지와 착지 충격
- 성공 직전 짧은 정적
- 성공 음악

## 9. 음성

실제 풀 보이스는 필요 없다. 짧은 관제 문구만 사용한다.

권장 문구:

```text
Ignition sequence start.
Liftoff.
Telemetry nominal.
Warning. Guidance deviation.
Automatic recovery engaged.
Mission abort.
Orbit confirmed.
Descent initiated.
Twenty meters.
Contact.
Touchdown confirmed.
```

핵심 정보는 한국어 UI에도 동시에 표시한다. 음성 파일이 없으면 무전 잡음과 텍스트만으로 대체 가능하다.

## 10. 음악

- 프롤로그: 15~20초의 낮은 긴장
- 운영: 짧은 루프 1개
- 발사: 공통 긴장 루프 또는 앰비언스 1개
- 달 착륙 성공: 10~15초 성공 스팅어
- 실패: 짧은 저음 스팅어

장면별 완전한 BGM 4곡은 만들지 않는다.

## 11. 연출 우선순위

1. 카운트다운과 점화
2. 환경 이벤트가 보이는가
3. 사고 원인이 보이는가
4. 성공·부분 성공·실패 결말 차이
5. 달 착륙 성공 보상
6. 추가 카메라와 장식

## 12. 금지 사항

- 파괴 가능한 복잡한 메시
- 절차적 파편 생성
- 승무원 애니메이션
- 사실적인 내부 조종석
- 장면별 독립적인 대규모 환경
- 4K 텍스처 다수
- 별도 시네마틱 렌더 파이프라인
