# 14. 아트·VFX·사운드

> 상태: **범위 확정**  
> 목표: 적은 에셋으로 여섯 발사 미션의 차이를 명확히 보여준다.

## 1. 아트 방향

권장 스타일:

- 세미리얼 또는 깔끔한 로우폴리
- 실루엣과 조명 중심
- 세부 기계 구조보다 발사 규모와 긴장감 강조
- 회색·흰색 기체, 어두운 우주, 따뜻한 엔진 불꽃
- 운영 UI는 관제실 소프트웨어처럼 정돈된 표현

실제 아르테미스 장비를 정확히 복제할 필요는 없다. 게임 내 기체는 프로젝트를 상징하는 간소화된 창작 디자인으로 통일한다.

| P0 | 시험용 로켓 | 1 | 모든 비행 미션 |
| P0 | 엔진 시험대 | 1 | 정적 연소 |

## 3. 머티리얼

최소 머티리얼 세트:

- 흰색 도장 금속
- 어두운 금속
- 단열재 또는 금색 호일
- 콘크리트
- 달 표면
- 지구 표면
- 발광 경고등
- 불꽃용 Additive 재질

복잡한 손상 데칼 시스템은 만들지 않는다. 손상은 검은 머티리얼 교체, 연기, 스파크로 표현한다.

## 4. 필수 VFX

| VFX | 사용 장면 |
|---|---|
| 엔진 주 불꽃 | 모든 발사 |
| 점화 연기 | 정적 연소·고도 도달 |
| 지상 먼지 | 고도 도달·최종 검증 |
| 스파크 | 모든 사고 |
| 폭발 | 정적 연소·비행 실패 |
| 작은 충돌 파편 | 목표 구역 실패 |
| 통신 노이즈 오버레이 | 최종 검증 |
| 카메라 흔들림 | 점화·폭발·경착륙 |
| 목표 경로 라인 | 설계 화면 |
| 예상 경로 라인 | 설계 화면 |
| 엔진 ON/OFF 마커 | 설계 화면 |

같은 폭발 VFX를 크기와 위치만 바꿔 재사용한다.

### 로켓 연기 프리팹

`Assets/05. Arts/Effect/Smoke/Smoke.prefab`은 로컬 -Y 방향으로 연기를 연속 방출한다.
루트의 위치와 회전은 0이며, 로켓 노즐 아래에 배치하고 필요한 방향으로 회전한다.
같은 폴더의 `smokeSheet1.png`~`smokeSheet3.png`를 원본 변경 없이 3×1 `SmokeAtlas.png`로
묶었다. 첫 이미지의 32×32 픽셀은 최근접 확대하고 나머지는 256×256을 유지한다.
Texture Sheet Animation의 Start Frame을 무작위로 선택하고 Frame over Time을 0으로 두어
각 파티클은 선택된 이미지 하나를 수명 내내 유지한다. `MAT_Smoke.mat`는 URP Particles/Unlit의
알파 블렌딩을 사용한다.

- 초당 150개, 수명 1.8~3.2초, 초기 속도 4~7, 최대 700개.
- 반각 32°의 원뿔에서 방사하며, 크기 증가와 감속 뒤 알파가 0으로 사라진다.
- Noise 모듈은 강도 0.5~1.15, 주파수 0.55, 스크롤 속도 0.45, 2옥타브로 설정했다.
- World 공간에서 시뮬레이션하므로 이미 방출한 연기는 로켓을 따라 이동하지 않는다.
- Loop와 Play On Awake가 켜져 있다. 코드에서 끌 때는 `StopEmitting`으로 잔여 연기를 소멸시킨다.

독립 프리팹 렌더링으로 외형을 확인했다. 실제 로켓 부착, 지면 충돌과 발사 상태 연동은 이 프리팹에 포함하지 않는다.

## 5. 설계 오류별 시각 패키지

### 힘 부족

- 상승 둔화
- 목표 경로 미달 표시
- 엔진 불꽃 약화

### 힘 과다

- 과속 경고
- 경로 초과 표시
- 카메라 미세 흔들림

### 방향 오류

- 목표 경로에서 옆으로 벗어나는 예상 경로
- 자세 경고
- 기체 회전

### 부품 위치 불량

- 무게중심 경고
- 구조 진동
- 스파크

### 엔진 ON/OFF 타이밍 오류

- 타임라인 경고 마커
- 점화 지연 또는 차단 지연 표시
- 연료 또는 속도 수치 급변

## 6. 카메라 제작량

각 장면당 P0 카메라 수:

| 장면 | 카메라 수 |
|---|---:|
| 정적 연소 | 3 |
| 낮은/높은 고도 도달 | 4 |
| 목표 구역 도달 | 4 |
| 목표 구역 체류 | 4 |
| 저전력 검증 | 4 |

추가 구도는 P1이다. 카메라 움직임보다 구도 전환을 우선한다.

## 7. UI 아트

필수:

- 미션 아이콘 6개
- 공개 테스트 아이콘
- 비공개 테스트 아이콘
- 등급 배지 S/A/B/C/F
- 잠금 아이콘
- 연구비 아이콘
- 시간 또는 달력 아이콘

모두 단색 또는 2색 벡터 스타일로 통일하면 제작이 빠르다.

## 8. 사운드 방향

게임의 긴장은 음악보다 기계음과 통신음에서 나온다.

### 운영 화면

- 낮은 볼륨의 관제실 드론
- 버튼 클릭
- 엔진 연구 완료음
- 정기 연구비 지급음
- 미션 해금음
- 마지막 4분기에는 낮은 펄스 추가

### 정적 연소

- 밸브 개방
- 점화
- 지속 연소
- 금속 진동
- 긴급 정지
- 폭발

### 낮은/높은 고도 도달

- 카운트다운
- 발사대 경고음
- 강한 엔진음
- 구조 진동
- 추락·폭발

### 목표 구역 도달·체류

- 낮은 긴장 앰비언스
- 점화음
- 목표 구역 진입 비프
- 금속 충돌
- 속도 초과 경고

### 저전력 검증

- 통신 음성
- 출력 제한 경고
- 연료 경고
- 목표 구역 체류 비프
- 성공 직전 짧은 정적
- 성공 음악

## 9. 음성

실제 풀 보이스는 필요 없다. 짧은 관제 문구만 사용한다.

권장 문구:

```text
Ignition sequence start.
Liftoff.
Telemetry nominal.
Warning. Guidance deviation.
Automatic recovery engaged.
Mission abort.
Target zone acquired.
Hold stable.
Power within limit.
Final verification confirmed.
```

핵심 정보는 한국어 UI에도 동시에 표시한다. 음성 파일이 없으면 무전 잡음과 텍스트만으로 대체 가능하다.

## 10. 음악

- 프롤로그: 15~20초의 낮은 긴장
- 운영: 짧은 루프 1개
- 발사: 공통 긴장 루프 또는 앰비언스 1개
- 최종 미션 성공: 10~15초 성공 스팅어
- 실패: 짧은 저음 스팅어

미션별 완전한 BGM 6곡은 만들지 않는다.

## 11. 연출 우선순위

1. 카운트다운과 점화
2. 설계 오류가 보이는가
3. 사고 원인이 보이는가
4. 성공·부분 성공·실패 결말 차이
5. 최종 미션 성공 보상
6. 추가 카메라와 장식
