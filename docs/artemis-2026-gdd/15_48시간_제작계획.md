# 15. 48시간 제작 계획

## P0

- 시간과 연구비 루프
- 엔진 프리셋과 연구 미니게임
- 로켓 조립, 방향과 가동 시간 입력
- 엔진 스탯의 실제 물리 반영
- 여섯 미션 평가기
- 성공 시 다음 미션 해금
- 실제 텔레메트리 HUD와 결과 보고
- 최종 미션 성공과 기간 만료 처리

## P1

- 공개·비공개 결과 매체
- 발사 결과 이벤트
- 성공 낙하산 연출
- 현장 사진
- 추가 카메라와 음향 연출

## P2

- 추가 엔진 외형
- 결과 이벤트 확장
- 고급 텔레메트리 그래프
- 보조 튜토리얼과 접근성 옵션

## 작업 순서

1. 캠페인 상태와 비용 처리
2. 연구 입력과 엔진 스탯 저장
3. 로켓 조립과 실제 엔진 물리
4. 텔레메트리 수집과 미션 평가
5. 여섯 미션 진행과 최종 결과
6. 결과 보고와 이벤트
7. 연출, 아트, 사운드
8. 통합 플레이테스트와 수치 조정

## 지연 시 축소 순서

1. 결과 이벤트 종류 축소
2. 공개·비공개 매체를 하나로 통합
3. 성공 전용 연출 단순화
4. 보조 HUD 수치 축소
5. 엔진 외형을 하나로 통합

실제 비행, 미션 평가와 진행 해금은 축소하지 않는다.

## 제출 전 확인

- 한 캠페인을 시작부터 최종 성공 또는 기간 만료까지 진행 가능
- 모든 발사 결과가 실제 미션 조건과 일치
- 실패 원인을 화면에서 이해 가능
- 결과 적용과 비용 차감 중복 없음
- 플레이 빌드에서 치명 오류 없음
