# 12. 밸런스 데이터표

> 기준일: 2026-09-06
>
> 수치는 플레이테스트 전 초기값이다. 발사 결과는 실제 물리와 미션 조건에서 나온다.

## 1. 전역 값

| 항목 | 값 |
|---|---:|
| 시작 연도 | 2018 |
| 종료 연도 | 2026 |
| 분기 수 | 36 |
| 시작 연구비 | 500 |
| 시작 분기 연구비 | 300 |
| 일반 연구 비용 | 100 |
| 집중 연구 비용 | 200 |
| 새 엔진 프리셋 개발 비용 | 150 |
| 설계 진입 비용 | 50 |
| 엔진 프리셋 최대 수 | 10 |
| 엔진 완성도 상한 | 100 |
| 연구 1회당 완성도 증가 | 10 |

능력치 상승량은 해커톤 플레이에서 여러 능력치를 고르게 연구해도 진행이 막히지 않도록 크게 잡는다.

| 미니게임 점수 | 일반 연구 | 집중 연구 |
|---:|---:|---:|
| 0~49 | +20 | +30 |
| 50~79 | +25 | +40 |
| 80~100 | +30 | +50 |

## 2. 미션 진행

| 미션 | 해금 조건 |
|---|---|
| `StaticFire` | 시작 시 열림 |
| `LowAltitude` | `StaticFire` 최초 성공 |
| `HighAltitude` | `LowAltitude` 최초 성공 |
| `TargetZone` | `HighAltitude` 최초 성공 |
| `ZoneHold` | `TargetZone` 최초 성공 |
| `LowPowerZoneHold` | `ZoneHold` 최초 성공 |

최종 미션 성공이 승리 조건이다. 재시도 횟수나 이전 기록은 비행 성능을 올리지 않는다.

## 3. 발사 비용과 정산

- 설계 진입 시 비용을 한 번 지불한다.
- 발사 확정 시 설치 엔진 비용을 지불한다.
- 일반 발사의 고정 결과 보상은 없다.
- 결과 이후 이벤트가 실제 경제·연구 효과를 결정한다.
- 효과는 `launch-outcome-events.md`의 상한과 소비 규칙을 따른다.

## 4. 물리 수치

엔진과 미션 수치는 ScriptableObject 또는 해당 런타임 설정을 단일 원천으로 사용한다. 문서에 물리값을 복제하지 않는다.

튜닝 순서는 아래와 같다.

1. 실제 추력, 질량, 연료와 연소율
2. 냉각과 과열
3. 미션 목표 위치와 체류 시간
4. 비용과 분기 수입
5. 결과 이후 이벤트 효과

결과를 맞추기 위해 숨은 보정치나 강제 성공을 추가하지 않는다.

## 5. 플레이테스트 기준

- 실패 원인을 실제 궤적과 텔레메트리로 설명할 수 있어야 한다.
- 같은 초기 상태와 같은 입력은 같은 물리 결과를 만들어야 한다.
- 다음 미션은 직전 미션 성공 직후 열린다.
- 최종 미션은 효율 조건을 실제로 만족해야 성공한다.
- 공개 여부를 바꿔도 같은 설계의 비행 결과는 바뀌지 않는다.
