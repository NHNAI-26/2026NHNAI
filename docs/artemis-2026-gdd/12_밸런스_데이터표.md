## 2. 엔진 연구 비용, 설치 비용, 발사 비용

| 엔진 | 일반 연구 비용 | 집중 연구 비용 | 설치 비용 |
|---|---:|---:|---:|
| Engine01~Engine10 | 350 | 650 | 350 |

모든 엔진 프리셋은 같은 초기 스펙과 같은 연구/설치 비용을 가진다. 차이는 플레이어가 어떤 프리셋을 얼마나 연구했는지에 따라 세션 중에 생긴다. 게임 시작 시에는 `Engine01`만 개발되어 있으며, `새로운 엔진 개발`로 `Engine02`부터 순서대로 추가한다.

| 미션 ID | 발사 비용 | 설계·발사 조건 |
|---|---:|---|
| StaticFire | 600 | 시험할 엔진 레벨 1 이상 |
| LowAltitude | 800 | 정적 연소 시험 C 이상 |
| HighAltitude | 900 | 낮은 고도 도달 시험 C 이상 |
| TargetZone | 1,100 | 높은 고도 도달 시험 C 이상 |
| ZoneHold | 1,300 | 목표 구역 도달 시험 C 이상 |
| LowPowerZoneHold | 1,500 | 목표 구역 체류 시험 C 이상 |

연구와 발사는 1분기를 사용한다. 설계 단계에서 엔진을 추가하는 행위 자체는 분기를 사용하지 않는다. 엔진 설치 비용은 설계 중 예약 표시하고, 최종 `발사` 버튼에서 확정 차감한다.

| 해금 미션 | 직전 미션 최고 등급 |
|---|---|
| LowAltitude | StaticFire C 이상 |
| HighAltitude | LowAltitude C 이상 |
| TargetZone | HighAltitude C 이상 |
| ZoneHold | TargetZone C 이상 |
| LowPowerZoneHold | ZoneHold C 이상 |

최종 승리는 `LowPowerZoneHold`에서 B 이상을 얻는 것이다.

| 등급 | 직접 연구 성장 | 즉시 지원금 | 분기 연구비 변화 | 다음 미션 검증 인정 | 최종 승리 |
|---|---:|---:|---:|---|---|
| S | 없음 | +900 | +150 | 예 | 예 |
| A | 없음 | +600 | +100 | 예 | 예 |
| B | 없음 | +400 | +50 | 예 | 예 |
| C | 없음 | +150 | 0 | 예 | 아니오 |
| F | 없음 | 0 | -100 | 아니오 | 아니오 |

엔진 업그레이드는 연구 행동으로만 오른다. 발사 결과는 엔진 프리셋 레벨이나 스탯을 직접 올리지 않는다.

## 5. 테스트 공개성 데이터

최종 미션 `LowPowerZoneHold`를 제외한 발사에만 적용한다.

| 방식 | 성공률 보정 | 즉시 지원금 배율 | 분기 연구비 변화 배율 | F 실패 시 분기 연구비 변화 |
|---|---:|---:|---:|---:|
| 공개 테스트 | -10%p | ×1.5 | ×1.5 | -150 |
| 비공개 테스트 | +10%p | ×0.5 | ×0.5 | -50 |
| 최종 미션 | 0 | ×1.0 | ×1.0 | -100 |

## 6. 확률 공식

### StaticFire

```text
P = clamp(
    round(
        20
        + SelectedEngineScore × 0.8
        + ExperienceBonus
        + DesignFitModifier
        + VisibilityModifier
    ),
    10,
    90
)
```

### LowAltitude / HighAltitude / TargetZone / ZoneHold / LowPowerZoneHold

```text
P = clamp(
    round(
        20
        + InstalledEngineScore × MissionEngineWeight
        + PreviousMissionBonus
        + ExperienceBonus
        + DesignFitModifier
        + VisibilityModifier
    ),
    10,
    90
)
```

설치 엔진 점수:

```text
InstalledEngineScore =
clamp(
    평균(설치 엔진별 프리셋 성능)
    + 엔진 개수 보정
    - 과중량 페널티,
    0,
    100
)
```

미션별 엔진 가중치:

| 미션 | MissionEngineWeight |
|---|---:|
| LowAltitude | 0.55 |
| HighAltitude | 0.50 |
| TargetZone | 0.45 |
| ZoneHold | 0.42 |
| LowPowerZoneHold | 0.40 |

직전 미션 최고 등급 보너스:

| 최고 등급 | PreviousMissionBonus |
|---|---:|
| S | +18 |
| A | +14 |
| B | +10 |
| C | +5 |
| F 또는 없음 | 0 |

결과 확률:

```text
Success = P
Partial = min(15, 95 - P)
Failure = 100 - Success - Partial
```

설계 보정:

```text
DesignFitModifier = round((DesignFit - 50) × 0.4)
```

`DesignFit`은 로켓 설계 단계에서 목표 경로와 현재 설계를 비교한 `0~100` 값이다. 설치된 엔진 프리셋의 업그레이드 레벨과 점화 신뢰도가 높을수록 같은 설계 오차에 대한 허용 범위가 넓어진다.

엔진 ON/OFF 타이밍은 `DesignFit`에 포함한다.

테스트 공개성 보정:

```text
Public = -10
Private = +10
FinalMission = 0
```

## 7. 등급 판정

```pseudo
roll = random integer [1, 100]

if roll <= P:
    margin = P - roll

    if margin >= 50:
        S
    else if margin >= 20:
        A
    else:
        B
else if roll <= min(P + 15, 95):
    C
else:
    F
```

## 10. 목표 플레이 리듬

### 고효율 기준 경로

집중 엔진 연구 위주, 각 발사 B, 큰 실패 없음:

- 원하는 엔진 프리셋 1개: 집중 연구 3회 + 정적 연소 시험 1회
- 낮은 고도 도달: 엔진 1~2개 설치 후 설계·발사 1회
- 높은 고도 도달: 필요한 엔진 프리셋 집중 연구 1회 + 엔진 2개 내외 설치 후 설계·발사 1회
- 목표 구역 도달/체류: 엔진 방향과 차단 타이밍을 조정해 설계·발사 각 1회
- 저전력 검증: 필요한 엔진 프리셋 집중 연구 1회 + 효율 설계 후 최종 미션 1회
- 연구·발사 행동: 9~11분기
- 예상 자금 대기: 약 5분기
- 총 약 16분기

이 경우 2018 Q1 시작 기준 2021년 전후에 최종 미션에 도달한다. 플레이 시간이 짧아지므로 공개 테스트 실패, 재시도, 자금 대기를 통해 2024~2026년 압박을 만들도록 수치를 조정한다.

### 일반적인 목표

- 총 행동 28~34분기
- 발사 5~8회
- 대기 3~7회
- 최종 미션 첫 시도 2025~2026년
- 실패 1~2회까지 복구 가능

## 11. 튜닝 우선순위

플레이테스트에서 조정이 필요할 때 아래 순서를 따른다.

1. 초기 분기 연구비 `600`
2. 엔진 프리셋별 집중 연구 비용
3. 발사 비용
4. 엔진 설치 비용
5. 등급별 즉시 지원금
6. 공개/비공개 성공률 보정
7. 설계 보정 계수
8. 엔진 프리셋 레벨 상승량

확률 공식 구조와 36분기 제한은 가급적 변경하지 않는다.

## 12. 권장 플레이테스트 통과 기준

10회 자동 또는 수동 테스트에서:

- 초보 플레이어 승률: 35~60%
- 규칙을 이해한 플레이어 승률: 60~80%
- 평균 최종 미션 시점: 2025 Q3~2026 Q3
- 2024년 이전 승리 비율: 10% 미만
- 자금 부족으로 아무 행동도 못 하는 상태: 없음
- 공개 테스트만 반복하는 전략이 항상 최적이 아님
- 비공개 테스트만 반복하는 전략이 항상 최적이 아님
