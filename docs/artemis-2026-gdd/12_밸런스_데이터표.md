## 2. 엔진 연구 비용, 설치 비용, 예산

| 엔진 | 일반 연구 비용 | 집중 연구 비용 | 설치 비용 |
|---|---:|---:|---:|
| Engine01~Engine10 | 350 | 650 | 350 |

모든 엔진 프리셋은 같은 초기 스펙과 같은 연구/설치 비용을 가진다. 차이는 플레이어가 어떤 프리셋을 얼마나 연구했는지에 따라 세션 중에 생긴다. 게임 시작 시에는 개발된 프리셋이 하나도 없고, `새로운 엔진 개발`로 `Engine01`부터 순서대로 추가한다.

| 미션 ID | 설계 진입 비용 | 설계 진입 조건 |
|---|---:|---|
| StaticFire | 50 | 없음. 게임 시작부터 가능 |
| LowAltitude | 50 | 정적 연소 시험 C 이상 |
| HighAltitude | 50 | 낮은 고도 도달 시험 C 이상 |
| TargetZone | 50 | 높은 고도 도달 시험 C 이상 |
| ZoneHold | 50 | 목표 구역 도달 시험 C 이상 |
| LowPowerZoneHold | 50 | 목표 구역 체류 시험 C 이상 |

연구와 발사는 1분기를 사용한다. 설계 단계에 들어가는 것과 엔진을 추가하는 행위 자체는 분기를 사용하지 않는다. 예산은 설계 진입 버튼을 누르는 순간 차감한다. 엔진 설치 비용은 설계 중 예약 표시하고, 최종 `발사` 버튼에서 확정 차감한다. 발사 확정 때 예산은 중복 차감하지 않는다.

2026-09-05 밸런스 패치 기준으로 설계 진입 비용은 미션별 장벽이 아니라 설계 화면 진입 확인 비용이다. 실제 발사 비용 압박은 설치 엔진 수와 엔진 완성도 기반 설치비 상승에서 만든다. 따라서 설계 진입 비용은 모든 미션에서 `50`으로 통일하고, 발사 재시도 실패의 주요 손실은 엔진 설치 비용, 1분기 소비, 분기 연구비 하락으로 둔다.

새 엔진 개발은 선택지를 여는 가벼운 행동으로 둔다. 비용은 `150`, 소요 시간은 없음으로 확정한다. 새 엔진을 여는 것 자체보다 새 엔진을 실제 발사에 쓸 만큼 연구하고 설치하는 비용이 주 장벽이다.

첫 프리셋만 예외로 비용 `0`이다. 프리셋이 없으면 연구도 로켓 설계도 못 하므로 첫 프리셋 생성은 선택이 아니라 필수 단계다. 여기에 요금을 매기면 선택 압박이 아니라 시작 자금을 `150` 깎는 것과 같다.

## 5. 테스트 공개성 데이터

최종 미션 `LowPowerZoneHold`를 제외한 발사에만 적용한다.

| 방식 | 성공률 보정 | 기본 즉시 지원금 | 기본 분기 연구비 변화 | 정산 방식 |
|---|---:|---:|---:|---|
| 공개 테스트 | 0 | 0 | 0 | 큰 보상 또는 큰 역풍 이벤트 |
| 비공개 테스트 | 0 | 0 | 0 | 작은 지원, 회수, 분석 이벤트 |
| 최종 미션 | 0 | 등급표 그대로 | 등급표 그대로 | F 실패 시 -100 |

## 6. 확률 공식

### StaticFire

```text
P = clamp(
    round(
        20
        + SelectedEngineScore × 0.8
        + ExperienceBonus
        + DesignFitModifier
        + VisibilityModifier
    ),
    10,
    90
)
```

### LowAltitude / HighAltitude / TargetZone / ZoneHold / LowPowerZoneHold

```text
P = clamp(
    round(
        20
        + InstalledEngineScore × MissionEngineWeight
        + PreviousMissionBonus
        + ExperienceBonus
        + DesignFitModifier
        + VisibilityModifier
    ),
    10,
    90
)
```

설치 엔진 점수:

```text
InstalledEngineScore =
clamp(
    평균(설치 엔진별 프리셋 성능)
    + 엔진 개수 보정
    - 과중량 페널티,
    0,
    100
)
```

미션별 엔진 가중치:

| 미션 | MissionEngineWeight |
|---|---:|
| LowAltitude | 0.55 |
| HighAltitude | 0.50 |
| TargetZone | 0.45 |
| ZoneHold | 0.42 |
| LowPowerZoneHold | 0.40 |

직전 미션 최고 등급 보너스:

| 최고 등급 | PreviousMissionBonus |
|---|---:|
| S | +18 |
| A | +14 |
| B | +10 |
| C | +5 |
| F 또는 없음 | 0 |

결과 확률:

```text
Success = P
Partial = min(15, 95 - P)
Failure = 100 - Success - Partial
```

설계 보정:

```text
DesignFitModifier = round((DesignFit - 50) × 0.4)
```

`DesignFit`은 로켓 설계 단계에서 목표 경로와 현재 설계를 비교한 `0~100` 값이다. 설치된 엔진 프리셋의 점화 신뢰도가 높을수록 같은 설계 오차에 대한 허용 범위가 넓어진다.

엔진 ON/OFF 타이밍은 `DesignFit`에 포함한다.

테스트 공개성 보정:

```text
Public = 0
Private = 0
FinalMission = 0
```

## 7. 등급 판정

```pseudo
roll = random integer [1, 100]

if roll <= P:
    margin = P - roll

    if margin >= 50:
        S
    else if margin >= 20:
        A
    else:
        B
else if roll <= min(P + 15, 95):
    C
else:
    F
```

## 10. 목표 플레이 리듬

### 고효율 기준 경로

집중 엔진 연구 위주, 각 발사 B, 큰 실패 없음:

- 원하는 엔진 프리셋 1개: 집중 연구 3회 + 정적 연소 시험 1회
- 낮은 고도 도달: 엔진 1~2개 설치 후 설계·발사 1회
- 높은 고도 도달: 필요한 엔진 프리셋 집중 연구 1회 + 엔진 2개 내외 설치 후 설계·발사 1회
- 목표 구역 도달/체류: 엔진 방향과 차단 타이밍을 조정해 설계·발사 각 1회
- 저전력 검증: 필요한 엔진 프리셋 집중 연구 1회 + 효율 설계 후 최종 미션 1회
- 연구·발사 행동: 9~11분기
- 예상 자금 대기: 약 5분기
- 총 약 16분기

이 경우 2018 Q1 시작 기준 2021년 전후에 최종 미션에 도달한다. 플레이 시간이 짧아지므로 공개 테스트 실패, 재시도, 자금 대기를 통해 2024~2026년 압박을 만들도록 수치를 조정한다.

### 일반적인 목표

- 총 행동 28~34분기
- 발사 5~8회
- 대기 3~7회
- 최종 미션 첫 시도 2025~2026년
- 실패 1~2회까지 복구 가능

## 11. 튜닝 우선순위

플레이테스트에서 조정이 필요할 때 아래 순서를 따른다.

1. 초기 분기 연구비 `600`
2. 엔진 프리셋별 집중 연구 비용
3. 엔진 설치 비용
4. 등급별 즉시 지원금
5. 공개/비공개 이벤트 정산 폭
6. 설계 보정 계수
7. 엔진 프리셋 완성도 상승량
8. 엔진 프리셋 스탯 상승량

확률 공식 구조와 36분기 제한은 가급적 변경하지 않는다.

## 12.1 추가 밸런스 점검 메모

설계 진입 비용을 `50`으로 낮춘 뒤에는 아래 항목을 우선 확인한다.

| 항목 | 현재 판단 | 권장 조정 |
|---|---|---|
| 설계 진입 비용 이벤트 | 기존 `-100`, `-150`, `+150` 보정은 새 진입 비용보다 큼 | 할인·할증 폭을 `50` 단위로 재조정하고 최저 비용은 `0`으로 제한 |
| 엔진 설치 비용 | 발사비의 주 장벽으로 남아야 함 | 기본 `350` 유지. 완성도 기반 최대 20% 상승도 유지 |
| 새 엔진 개발 | 선택지 추가가 너무 비싸면 다양한 설계가 막힘 | 첫 프리셋 `0`, 이후 `150`, 시간 소모 없음 유지. 대신 연구와 설치 비용이 실제 투자 판단을 만들게 함 |
| 공개 테스트 보상 | 공개 성공은 자금 회복이 빠르고 이벤트 보상까지 붙을 수 있음 | 설계 진입 비용 패치 후 공개 테스트만 반복하는 전략이 항상 최적인지 플레이테스트 |
| 실패 복구 | 실패 시 진입 비용까지 잃으면 재시도가 과하게 막혔음 | 진입 비용 손실은 작게, 설치비·분기·분기 연구비 하락으로 손실을 체감하게 함 |
| 최종 미션 | 진입 비용보다 엔진 수·설계 적합도·확률 하한/상한이 체감 난이도를 좌우함 | 진입 비용은 `50` 유지. 너무 쉬우면 엔진 가중치나 설계 보정 계수를 먼저 조정 |

## 13. 권장 플레이테스트 통과 기준

10회 자동 또는 수동 테스트에서:

- 초보 플레이어 승률: 35~60%
- 규칙을 이해한 플레이어 승률: 60~80%
- 평균 최종 미션 시점: 2025 Q3~2026 Q3
- 2024년 이전 승리 비율: 10% 미만
- 자금 부족으로 아무 행동도 못 하는 상태: 없음
- 공개 테스트만 반복하는 전략이 항상 최적이 아님
- 비공개 테스트만 반복하는 전략이 항상 최적이 아님
