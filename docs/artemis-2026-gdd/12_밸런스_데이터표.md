## 6. 확률 공식

### Engine

```text
P = clamp(
    round(
        20
        + EngineProgress × 0.8
        + ExperienceBonus
        + EnvironmentModifier
        + DesignFitModifier
    ),
    10,
    90
)
```

### Rocket / Orbit / Moon

```text
P = clamp(
    round(
        20
        + CurrentProgress × 0.6
        + PrerequisiteAverage × 0.2
        + ExperienceBonus
        + EnvironmentModifier
        + DesignFitModifier
    ),
    10,
    90
)
```

이전 단계 평균:

| 단계 | 평균 대상 |
|---|---|
| Rocket | Engine |
| Orbit | Engine, Rocket |
| Moon | Engine, Rocket, Orbit |

결과 확률:

```text
Success = P
Partial = min(15, 95 - P)
Failure = 100 - Success - Partial
```

설계 보정:

```text
DesignFitModifier = round((DesignFit - 50) × 0.4)
```

`DesignFit`은 로켓 설계 단계에서 목표 경로와 현재 설계를 비교한 `0~100` 값이다. 연구 진행도가 높을수록 같은 설계 오차에 대한 허용 범위가 넓어진다.

## 7. 등급 판정

```pseudo
roll = random integer [1, 100]

if roll <= P:
    margin = P - roll

    if margin >= 50:
        S
    else if margin >= 20:
        A
    else:
        B
else if roll <= min(P + 15, 95):
    C
else:
    F
```

## 10. 목표 플레이 리듬

### 고효율 기준 경로

집중 연구 위주, 각 발사 B, 큰 실패 없음:

- 엔진: 집중 연구 5회 + 발사 1회
- 로켓: 집중 연구 6회 + 발사 1회
- 궤도: 집중 연구 6회 + 발사 1회
- 달 착륙: 집중 연구 5회 + 임무 1회
- 연구·발사 행동: 26분기
- 예상 자금 대기: 약 5분기
- 총 약 31분기

이 경우 2018 Q1 시작 기준 2025년 후반 전후에 최종 임무에 도달한다.

### 일반적인 목표

- 총 행동 28~34분기
- 발사 5~8회
- 대기 3~7회
- 달 착륙 첫 시도 2025~2026년
- 실패 1~2회까지 복구 가능

## 11. 튜닝 우선순위

플레이테스트에서 조정이 필요할 때 아래 순서를 따른다.

1. 초기 분기 연구비 `600`
2. 집중 연구 비용
3. 발사 비용
4. 등급별 즉시 지원금
5. 환경 페널티
6. 진행도 증가량

확률 공식 구조와 36분기 제한은 가급적 변경하지 않는다.

## 12. 권장 플레이테스트 통과 기준

10회 자동 또는 수동 테스트에서:

- 초보 플레이어 승률: 35~60%
- 규칙을 이해한 플레이어 승률: 60~80%
- 평균 최종 임무 시점: 2025 Q3~2026 Q3
- 2024년 이전 승리 비율: 10% 미만
- 자금 부족으로 아무 행동도 못 하는 상태: 없음
- 유성우·태양 폭풍에서 무조건 발사해야만 하는 상황: 드묾
