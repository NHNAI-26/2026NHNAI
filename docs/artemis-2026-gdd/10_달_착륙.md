# 10. 달 착륙

> 상태: **확정**  
> 역할: 프로젝트 전체의 최종 시험이자 승패를 결정하는 클라이맥스

## 1. 임무 목적

자동 항법으로 유인 착륙선을 달 표면에 안전하게 착륙시킨다. 플레이어는 착륙 도중 조작하지 않는다.

승리 조건은 달 착륙 임무에서 `B 이상`을 받는 것이다.

## 2. 임무 조건

- 달 착륙 단계 해금
- 달 착륙 준비 진행도 50 이상
- 임무 비용 1,800
- 현재 분기 1개 소비
- 2026년 4분기에도 마지막 시도로 실행 가능

## 3. 장면 구성

최소 에셋:

- 달 표면 또는 간단한 지형
- 유인 착륙선 1개
- 달 배경과 우주
- 하강 엔진 불꽃
- 먼지 파티클
- 유성 파티클
- 태양 폭풍용 통신 노이즈
- 착륙 실패용 폭발 또는 넘어짐

승무원 캐릭터와 실내 장면은 만들지 않는다. 유인 임무는 통신 문구와 임무명으로 표현한다.

## 4. 권장 시퀀스

| 시간 | 상태 | 연출 |
|---:|---|---|
| 0~5초 | 브리핑 | `CREWED LUNAR LANDING`, 날짜, 환경 |
| 5~12초 | 달 접근 | 달과 착륙선 전경 |
| 12~20초 | 착륙선 하강 시작 | 고도·연료·속도 표시 |
| 20~35초 | 자동 항법 | 착륙 지점 탐색, 자세 보정 |
| 35~48초 | 위험 구간 | 센서, 엔진, 유성우, 통신 문제 |
| 48~56초 | 최종 하강 | 먼지, 그림자, 속도 감소 |
| 56~60초 | 결과 | 착륙, 임무 중단, 경착륙 또는 전복 |

총 길이 목표: 45~60초

## 5. 주요 지표

```text
ALTITUDE
VERTICAL SPEED
FUEL
ATTITUDE
LANDING SITE
COMM LINK
```

결과 보고서:

- 착지 수직 속도
- 착륙 지점 오차
- 남은 연료
- 기체 기울기
- 사고 원인

## 6. 사고 목록

| ID | 사고 | 주 연계 환경 | 결과 표현 |
|---|---|---|---|
| `SensorError` | 고도 센서 오류 | 기술 사고 | 고도 값 튐, 착륙 지점 재탐색 |
| `EngineInstability` | 하강 엔진 불안정 | 기술 사고 | 불꽃 변화, 수직 속도 증가 |
| `FuelShortage` | 연료 부족 | 기술 사고 | 연료 경고, 조기 착륙 시도 |
| `LandingSiteHazard` | 착륙 지점 장애물 | 기술 사고 | 옆으로 이동하거나 중단 |
| `MeteorDamage` | 유성 파편 충돌 | 유성우 | 자세 흔들림, 통신 또는 엔진 손상 |
| `CommunicationBlackout` | 통신 두절 | 태양 폭풍 | 자동 모드 유지 여부로 결과 분기 |
| `HardLanding` | 경착륙 | C/F 결말 | 강한 먼지와 충격 |
| `TipOver` | 전복 | F 결말 | 착륙 후 한쪽으로 넘어짐 |

## 7. 등급별 연출

### S

- 안정적인 자동 하강
- 착륙 지점 오차가 매우 작음
- 연료 충분
- 부드러운 착지
- 통신: `TOUCHDOWN CONFIRMED`
- 카메라가 뒤로 빠지며 지구를 배경으로 성공 연출

### A

- 센서 또는 통신 경고가 잠깐 발생
- 자동 시스템이 복구
- 약간의 위치 오차와 낮은 연료로 정상 착륙

### B

- 엔진 불안정, 착륙 지점 변경, 유성 충격 중 하나가 발생
- 마지막 순간 자동 보정
- 경계 수치 안에서 착지
- 착륙선은 서 있고 임무 성공

### C

- 달 접근과 하강에는 성공
- 착륙 지점 또는 시스템 상태가 안전 기준 미달
- 자동 상승 또는 임무 중단
- 또는 기체 손상 없는 경착륙 후 유인 임무 중단
- 게임은 계속되며 재도전 가능

### F

- 하강 엔진 손실
- 과도한 수직 속도로 충돌
- 착륙 후 전복
- 통신과 자동 항법 동시 상실처럼 보이더라도 주요 사고는 하나로 기록
- 임무 실패

인명 피해를 직접 묘사하지 않는다. 승무원 모습이나 사망 연출은 없다.

## 8. 유성우와 태양 폭풍

### 유성우

- 달 접근 또는 하강 초반에 유성 궤적 표시
- B에서는 작은 충돌 후 자세 회복
- C에서는 안전 기준 미달로 자동 중단
- F에서는 센서 또는 엔진 손상으로 착륙 실패

### 태양 폭풍

- 통신 잡음과 HUD 깨짐
- 자동 항법은 계속 작동할 수 있음
- A/B에서는 통신 복구 또는 자율 착륙 성공
- C에서는 안전상 임무 중단
- F에서는 고도 정보 또는 자동 항법 상실

## 9. 카메라

1. 달과 착륙선 전체
2. 착륙선 하부 엔진
3. 지면을 내려다보는 시점
4. 측면 하강 추적
5. 착륙 지점 근접 카메라
6. 성공 시 달 표면 광각

시간이 부족하면 1, 2, 4, 5 네 구도만 사용한다.

## 10. 최종 성공 연출

필수 요소:

- 엔진 불꽃 감소
- 달 먼지 확산
- 착륙 다리 접촉
- 짧은 정적
- `TOUCHDOWN CONFIRMED`
- `ARTEMIS PROJECT SUCCESS`
- 현재 날짜 표시
- 성공 음악
- 결과 요약 화면

국기 설치, 승무원 하차, 달 표면 보행은 P2이며 기본 범위에서 제외한다.

## 11. 완료 기준

- 플레이어 입력 없이 착륙 전 과정이 자동으로 진행된다.
- B 이상은 반드시 착륙선이 서 있는 상태로 끝난다.
- C는 재도전 가능한 부분 성공으로 보인다.
- F는 경착륙 또는 전복 등 명확한 실패 결말을 가진다.
- 2026년 4분기 결과에 따라 즉시 승리 또는 패배가 결정된다.
- 달 착륙 성공 장면은 다른 시험보다 분명히 강한 시청각 보상을 제공한다.
