# 16. QA 및 완료 기준

> 상태: **확정**  
> 목적: “보인다”가 아니라 “처음부터 끝까지 한 판이 정상 종료된다”를 기준으로 검사한다.

## 1. 최종 제출 완료 조건

아래 항목이 모두 참이어야 P0 완료다.

- 새 게임 시작 가능
- 2017년 12월 프롤로그 재생 또는 건너뛰기 가능
- 2018 Q1에서 운영 시작
- 일반·집중 연구가 비용과 진행도를 정확히 반영
- 대기가 1분기를 소비하고 연구비를 지급
- 설계 화면에서 맵과 목표 경로 표시
- 부품 위치, 힘, 방향, 엔진 ON/OFF 타이밍 조정 가능
- 최종 달 착륙 제외 발사에서 공개/비공개 테스트 선택 가능
- 발사 전 연구 단계로 복귀 가능
- 발사 확인창에서 확률 내역 표시
- 네 발사가 모두 자동 3D 장면으로 재생
- 발사 도중 결과 개입 조작 없음
- S/A/B/C/F 결과 처리
- 결과가 진행도와 연구비에 정확히 반영
- 단계 해금
- 이전 단계 재선택
- 달 착륙 B 이상 승리
- 2026 Q4 종료 시 패배
- 다시 시작 가능
- 빌드에서 치명적 오류 없음

## 2. 시간 시스템 테스트

### 경계값

- 2018 Q1에서 시작하는가
- 한 행동마다 정확히 한 분기 증가하는가
- Q4 다음이 다음 연도 Q1인가
- 남은 분기가 정확히 감소하는가
- 2026 Q4에 한 번의 마지막 행동이 가능한가
- 2026 Q4 행동 이후 승리가 아니면 패배하는가
- 달 착륙 성공 시 날짜 증가 전에 승리 처리해도 표시가 모순되지 않는가

### 대기

- 비용이 0인가
- 정기 연구비가 지급되는가
- 날씨나 예보 상태를 변경하지 않는가

## 3. 경제 테스트

- 자금 부족 시 연구·시뮬레이션 버튼 비활성
- 정확한 비용 차감
- 결과별 즉시 지원금
- 결과별 분기 연구비 증감
- 공개 테스트 성공 보상이 크게 적용되는가
- 공개 테스트 실패 손실이 크게 적용되는가
- 비공개 테스트 성공 보상이 작게 적용되는가
- 비공개 테스트 실패 손실이 작게 적용되는가
- 달 착륙 최종 임무에는 공개/비공개 배율이 적용되지 않는가
- 분기 연구비 300 아래로 내려가지 않음
- 분기 연구비 1,000 위로 올라가지 않음
- 발사 종료 분기에 변경된 연구비 지급
- 결과 건너뛰기 시 보상 중복 없음
- 씬 재로드 시 보상 중복 없음
- 다시 시작 시 모든 값 초기화

## 4. 연구·해금 테스트

- 일반 연구 +6
- 집중 연구 +10
- 진행도 최대 100
- 연구가 실패하지 않음
- 엔진 50 + 발사 C 이상에서 로켓 해금
- 로켓 55 + 발사 C 이상에서 궤도 해금
- 궤도 60 + 발사 C 이상에서 달 해금
- 진행도만 충족하고 발사가 F면 해금되지 않음
- 발사 C로 진행도가 임계치를 넘으면 같은 결과 처리 후 해금
- 이전 단계 버튼이 계속 활성
- 실패해도 진행도 감소 없음

## 5. 확률 테스트

고정 시드를 사용해 단위 테스트 또는 디버그 로그로 검증한다.

- Engine 공식이 별도 공식으로 계산되는가
- Rocket/Orbit/Moon의 이전 단계 평균이 올바른가
- 경험 보너스가 0, 3, 6, 9에서 멈추는가
- 공개/비공개 보정이 최종 달 착륙 제외 발사에만 들어가는가
- 성공 확률이 10~90에 제한되는가
- 부분 성공이 최대 15인가
- 실패가 최소 5인가
- 확률 합이 항상 100인가
- `roll=successChance`가 성공인가
- `roll=successChance+1`이 부분 성공 구간이면 C인가
- `roll=96` 이상이 90% 성공률에서 F인가
- 결과가 씬 진입 후 재굴림되지 않는가

## 6. 설계 단계 테스트

- 같은 분기·단계·시드에서 같은 맵과 목표 경로가 생성되는가
- 새 게임 또는 새 분기에서는 다른 맵이 나올 수 있는가
- 목표 경로와 현재 예상 경로가 보이는가
- 부품 위치 변경이 설계 적합도를 바꾸는가
- 힘 크기 변경이 설계 적합도를 바꾸는가
- 방향 변경이 설계 적합도를 바꾸는가
- 엔진 ON/OFF 타이밍 변경이 설계 적합도를 바꾸는가
- 초 단위 또는 경로 지점 단위 타이밍이 저장되는가
- 공개/비공개 선택이 예상 성공률과 보상 표시를 바꾸는가
- 설계 적합도 보정이 -20~+20 사이인가
- 설계 화면 진입만으로 비용·분기·발사 횟수가 변하지 않는가
- 연구 단계로 돌아가면 비용·분기·발사 횟수가 그대로인가
- 발사 버튼 이후에는 복귀할 수 없는가

## 7. 날씨 삭제 확인

- 환경 스케줄이 생성되지 않는가
- 예보 UI가 표시되지 않는가
- 날씨 아이콘과 환경 보정이 사용되지 않는가
- 성공률 계산에 환경 보정 항목이 없는가
- 대기해도 날씨 상태가 이동하지 않는가

## 8. 시뮬레이션 공통 테스트

각 장면에서 S/A/B/C/F 강제 디버그 실행을 제공하는 것을 권장한다.

- S/A/B가 성공 결말
- C가 부분 성공 결말
- F가 실패 결말
- 설계 오류 VFX가 올바르게 활성
- 한 발사에 주요 사고 하나만 재생
- HUD 지표와 보고서 지표 일치
- 카운트다운 후 결과가 노출
- 배속을 사용해도 상태 이벤트 누락 없음
- 건너뛰어도 결과 적용
- 일시정지 후 재개 가능
- 자동 발사 종료 후 메인 화면 복귀
- 메인 화면의 날짜·자금·진행도가 갱신

## 9. 단계별 장면 테스트

### 엔진

- 점화, 유지, 종료 구분
- C는 긴급 정지
- F는 점화 실패·화재·폭발 중 하나
- 엔진 타이밍 오류 표현

### 로켓

- 발사대에서 상승
- 설계 오류 시 흔들림
- C는 목표 미달 후 중단
- F는 추락 또는 발사 실패

### 궤도

- 지구 궤도 장면 인식 가능
- 엔진 타이밍 오류와 통신 오류 구분
- C는 부분 궤도 또는 임무 중단
- F는 궤도 상실·통신 두절

### 달 착륙

- 자동 하강
- B 이상 착륙선이 선 채로 종료
- C는 중단 또는 비치명적 경착륙
- F는 충돌 또는 전복
- B 이상 즉시 승리

## 10. 플레이테스트 질문

테스터에게 설명 없이 플레이하게 한 뒤 확인한다.

1. 왜 연구해야 하는지 이해했는가?
2. 일반과 집중 연구 차이를 이해했는가?
3. 공개 테스트와 비공개 테스트의 차이를 이해했는가?
4. 설계 결과가 발사 결과와 연결되었다고 느꼈는가?
5. 확률 실패가 불공정하다고 느껴졌는가?
6. 3D 장면에서 사고 원인을 이해했는가?
7. 2026 마감 압박을 느꼈는가?
8. 달 착륙 성공이 충분히 보상처럼 느껴졌는가?

## 11. 치명도 분류

### Blocker

- 게임 시작 불가
- 씬 전환 실패
- 설계 단계 진입 또는 복귀 불가
- 결과 적용 불가
- 승리·패배 불가
- 상태 초기화 실패
- 2026 이후 무한 진행

### Critical

- 보상 중복
- 확률 합 오류
- 공개/비공개 보정과 실제 판정 불일치
- 설계 적합도 보정 오류
- 잠긴 단계 실행 가능
- 달 착륙 C/F에서 승리
- B 이상인데 승리하지 않음

### Major

- HUD와 보고서 수치 불일치
- 설계 오류 VFX 누락
- 카메라가 결과를 보여주지 못함
- 버튼 상태 오류

### Minor

- 텍스트 정렬
- 사운드 크기
- 일부 장식 누락
- 작은 애니메이션 끊김

마지막 4시간에는 Blocker와 Critical을 우선 수정한다.
