# 16. QA 및 완료 기준

## 캠페인

- 2018년 1분기에 시작하고 2026년 4분기 뒤 종료되는가
- 연구, 대기, 설계와 발사의 비용·시간이 한 번만 적용되는가
- 자금 부족 행동이 상태를 바꾸지 않고 차단되는가
- 새 엔진 프리셋이 최대 10개까지만 생성되는가

## 연구

- 미니게임 점수와 실제 스탯 증가량이 일치하는가
- 선택한 프리셋과 스탯만 변하는가
- 완성도 상한에서 추가 연구가 막히는가
- 연구한 스탯이 다음 발사의 실제 물리에 반영되는가

## 설계와 물리

- 엔진 수, 위치, 방향과 가동 시간 변화가 궤적을 바꾸는가
- 연료, 출력, 냉각과 점화 값이 실제 엔진 동작에 반영되는가
- 공개 여부만 바꾼 동일 설계가 같은 물리 결과를 만드는가
- 발사 중 설계값이 변경되지 않는가

## 미션

- `StaticFire`의 연소와 안전 조건을 실제 상태로 검사하는가
- `LowAltitude`와 `HighAltitude`가 실제 최고 고도를 검사하는가
- `TargetZone`이 실제 구역 진입을 검사하는가
- `ZoneHold`가 실제 체류 시간을 검사하는가
- `LowPowerZoneHold`가 체류와 효율 제한을 함께 검사하는가
- 실패한 미션이 다음 미션을 열지 않는가
- 처음 성공한 직후 다음 미션이 열리는가
- 최종 미션 성공만 승리로 처리되는가

## 결과

- HUD와 결과 보고서가 같은 텔레메트리를 표시하는가
- 종료 사유가 실제 종료 원인과 일치하는가
- 결과 적용을 다시 호출해도 비용, 해금과 이벤트가 중복되지 않는가
- 사진 또는 결과 UI 실패가 캠페인 복귀를 막지 않는가

## 플레이테스트 질문

1. 실패 원인을 비행과 수치만 보고 설명할 수 있었는가
2. 다음 시도에서 무엇을 바꿀지 판단할 수 있었는가
3. 엔진 연구가 실제 비행 차이로 느껴졌는가
4. 목표 구역과 성공 조건을 발사 전에 이해했는가
5. 최종 미션이 앞선 미션에서 배운 설계를 함께 요구했는가

## 치명도

- Blocker: 진행 불가, 상태 손실, 최종 결과 도달 불가
- Critical: 실제 비행과 결과 불일치, 잘못된 미션 해금, 중복 정산
- Major: 핵심 텔레메트리 오류, 조작 불가, 명확한 연출 파손
- Minor: 문구, 정렬, 비핵심 시각 문제
