# 01. 게임 비전 및 범위

> 상태: **확정**  
> 핵심 질문: “더 연구할 것인가, 설계를 조정해 발사할 것인가, 공개 테스트로 큰 보상을 노릴 것인가?”

## 1. 기본 정보

| 항목 | 확정 내용 |
|---|---|
| 가제 | `ARTEMIS: 2026` |
| 장르 | 프로젝트 운영 + 로켓 설계 조정 + 공개/비공개 테스트 선택 + 자동 3D 발사 시뮬레이션 |
| 시점 | 운영 화면은 2D UI, 설계 화면은 2D/3D 편집 UI, 발사는 3D 시네마틱 시점 |
| 주요 입력 | 마우스 또는 단순 UI 선택 |
| 발사 중 입력 | 결과에 영향을 주는 조작 없음 |
| 목표 플랫폼 | PC 16:9 빌드 우선 |
| 목표 플레이 시간 | 1회 15~25분 |
| 시작 시점 | 2017년 12월 프롤로그, 2018년 1분기부터 플레이 |
| 종료 시점 | 2026년 4분기 |
| 최종 목표 | 유인 달 착륙 임무에서 B 이상 획득 |
| 제작 조건 | 48시간 게임잼 |

## 2. 배경과 플레이어 역할

2017년 12월, 플레이어는 비공개 연락 한 통을 받는다.

> “2026년이 끝나기 전에 사람을 달에 착륙시키십시오.”

플레이어는 프로젝트 총괄 책임자가 된다. 연구원 개개인을 관리하거나 발사 중 로켓을 직접 조종하지 않는다. 제한된 연구비와 시간 안에서 어떤 엔진 프리셋을 연구할지, 언제 발사할지 결정하고, 발사 전 설계 단계에서 엔진을 어디에 몇 개 달지, 부품 위치, 힘, 방향, 엔진 ON/OFF 타이밍을 조정한 뒤 결과를 자동 3D 시뮬레이션으로 확인한다.

## 3. 핵심 판타지

플레이어가 느껴야 하는 감정은 다음 세 가지다.

### 3.1 프로젝트 총괄자의 판단

현재 엔진 기술로 설계 단계에 들어갈지, 돈과 시간을 들여 엔진을 더 연구할지 결정한다.

### 3.2 발사 전의 긴장

현재 엔진 프리셋 성능과 설계 적합도를 알고도 정답을 확신할 수 없다. 비공개 테스트는 안전하지만 보상이 작고, 공개 테스트는 위험하지만 성공하면 지원금과 명성이 크게 오른다.

### 3.3 결과를 지켜보는 긴장

발사 버튼을 누른 뒤에는 개입할 수 없다. 카운트다운, 점화, 경고, 장애 발생, 복구 또는 실패를 지켜보며 엔진 연구와 설계가 만든 결과를 확인한다.

## 4. 디자인 기둥

### 4.1 선택은 발사 전에 끝난다

발사 결과를 바꾸는 실시간 조작은 없다. 전략은 엔진 프리셋 연구, 대기, 발사 시기 선택, 테스트 공개성 선택, 설계 단계의 엔진 배치와 힘·방향·엔진 ON/OFF 타이밍 조정에서 발생한다.

### 4.2 연구는 확실하고 발사는 불확실하다

연구 행동은 선택한 엔진 프리셋 A/B/C의 업그레이드 레벨과 스탯을 올린다. 로켓 연구, 궤도 연구, 달 착륙 연구는 없다. 실패 가능성은 오직 엔진 테스트, 로켓 테스트, 궤도 테스트, 달 착륙 발사 결과에서 발생한다. 최종 달 착륙을 제외한 발사는 공개 테스트와 비공개 테스트 중 하나를 선택한다.

### 4.3 실패는 손해지만 완전한 무효는 아니다

실패하면 정기 연구비가 삭감되고 즉시 보상은 없지만 발사 경험과 시험 기록이 남는다. 엔진 스탯 상승은 연구 단계에서 비용을 내고 수행한 업그레이드로만 발생한다. 실패 장면은 게임의 주요 볼거리다.

### 4.4 3D 시뮬레이션이 보상 화면이다

운영 UI보다 설계와 3D 발사 장면이 더 인상적이어야 한다. 엔진 프리셋을 연구하는 이유는 더 좋은 설계 여유와 발사 결과를 보기 위해서다.

### 4.5 2026년이 항상 보인다

운영 화면 상단에 현재 날짜와 남은 분기를 항상 표시한다. 마지막 4개 분기에는 시각·음향 압박을 강화한다.

## 5. 핵심 자원

플레이어가 관리하는 값은 아래 네 종류뿐이다.

1. 현재 날짜
2. 현재 연구비
3. 분기 정기 연구비
4. 엔진 A/B/C 업그레이드 상태

신뢰도, 연구 데이터, 연구원 수, 시설 레벨, 부품 재고는 별도 자원으로 만들지 않는다. 신뢰도는 분기 연구비 변화에 통합하고, 실패 데이터는 발사 경험과 엔진 프리셋별 시험 기록에 통합한다.

- 로켓 설계 단계
- 맵과 목표 경로 생성
- 엔진 배치, 부품 위치, 힘, 방향, 엔진 ON/OFF 타이밍 조정

- 성공·부분 성공·실패 판정

## 7. 승리와 패배

### 승리

달 착륙 임무에서 `S`, `A`, `B` 중 하나를 획득하면 즉시 승리한다. 착륙선이 정상적으로 착지하고 임무 성공 연출을 재생한다.

### 계속 진행

달 착륙 결과가 `C`이면 부분 성공이다. 임무는 중단되거나 착륙 직전에 자동 복귀하며, 플레이어는 시간이 남아 있으면 다시 연구하거나 재도전한다.

### 패배

2026년 4분기의 마지막 행동까지 달 착륙을 성공하지 못하면 패배한다. 연구비가 부족하더라도 즉시 파산 처리하지는 않는다. 대기 행동으로 연구비를 받을 수 있지만, 남은 시간이 부족하면 자연스럽게 프로젝트 실패가 된다.

## 8. 목표 플레이 경험의 문장

> “나는 발사 중 로켓을 직접 조종하지 않았지만, 연구량과 설계와 공개 테스트 선택을 내가 결정했기 때문에 화면 속 성공과 실패가 모두 내 판단의 결과처럼 느껴졌다.”
