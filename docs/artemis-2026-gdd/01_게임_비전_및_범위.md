# 01. 게임 비전 및 범위

## 한 문장 정의

제한된 시간과 연구비로 엔진을 개발하고 로켓을 조립해, 실제 물리 발사로 여섯 시험 미션을 통과하는 프로젝트 운영 게임이다.

## 목표 경험

- 연구 선택이 엔진의 실제 성능 차이로 이어진다.
- 장착 위치, 방향과 작동 시간이 실제 궤적을 바꾼다.
- 실패 원인을 비행 장면과 텔레메트리에서 읽을 수 있다.
- 2026년 안에 최종 효율 검증을 통과해야 한다.

## 핵심 범위

- 2018년 1분기부터 2026년 4분기까지의 시간 제한
- 연구비와 분기 연구비
- 최대 10개의 엔진 프리셋
- 엔진 완성도와 연료, 냉각, 출력, 점화 신뢰도
- 발사 전 로켓 조립, 엔진 방향, ON/OFF 시간 설정
- 실제 Unity 물리 기반 자동 발사
- 여섯 개의 순차 미션
- 공개·비공개 결과 보고와 후속 이벤트

## 결과 원칙

미션 성공 여부는 실제 비행이 목표 조건을 만족했는지로만 결정한다. 발사 전 예측 결과, 결과 품질 표식, 성장 단계와 과거 기록 보너스는 사용하지 않는다.

## 범위 밖

- 발사 중 직접 조종
- 실제 궤도역학과 다단 분리
- 날씨와 발사창
- 추가 경영 자원과 저장 시스템
- 로켓·궤도·달 착륙 연구 트리
- 결과를 물리와 별개로 정하는 시스템

## 승패

`LowPowerZoneHold`의 실제 조건을 2026년 4분기 안에 만족하면 승리한다. 기간이 끝날 때까지 만족하지 못하면 패배한다.
