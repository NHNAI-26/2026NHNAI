# 04. 엔진 프리셋 연구·미션 진행

> 상태: **확정**  
> 원칙: 연구 대상은 엔진 프리셋뿐이다. 발사 목표는 엔진/로켓/궤도/달 착륙 단계가 아니라 순차 미션으로 관리한다.

## 1. 연구 대상

연구 단계에는 최대 10개의 엔진 프리셋 슬롯이 존재한다. 단, 게임 시작 시 화면에 보이고 사용할 수 있는 프리셋은 `Engine01` 하나뿐이다.

| ID | 표시 이름 | 성격 |
|---|---|---|
| `Engine01`~`Engine10` | 엔진 01~10 | 동일 기본 스펙, 동일 연구 비용, 동일 설치 비용 |

각 엔진 프리셋은 개별 완성도와 스탯을 가진다. 완성도는 연료량, 냉각, 최대 출력, 점화 신뢰도가 공유하는 엔진 전체 개발 한도다. 연구 결과가 Perfect든 Miss든 연구 행동 1회마다 완성도는 `+10` 오른다.

새 프리셋은 `새로운 엔진 개발` 버튼으로 추가한다. 추가 순서는 `Engine02`, `Engine03` 순으로 고정한다. 새 프리셋 개발의 비용과 시간은 아직 미정이며, 확정 전까지 구현은 비용/시간을 별도 밸런스 값으로 분리해 둔다. 10번째 프리셋까지 개발하면 더 이상 새 엔진을 만들 수 없다.

로켓 연구, 궤도 연구, 달 착륙 연구는 만들지 않는다. 엔진 프리셋 연구로 얻은 성능을 0~5번 발사 미션에서 검증한다.

## 2. 연구 행동

연구 버튼은 선택한 엔진 프리셋에만 적용한다.

### 일반 연구

- 1분기 소비
- 선택 엔진의 일반 연구 비용 차감
- 선택 엔진 완성도 고정 증가
- 선택 스탯 소폭 증가
- 실패하지 않음

### 집중 연구

- 1분기 소비
- 선택 엔진의 집중 연구 비용 차감
- 선택 엔진 완성도 고정 증가
- 선택 스탯 중폭 증가
- 실패하지 않음

완성도는 프리셋별로 최대 `100`이다. 완성도 100에 도달한 프리셋은 어떤 스탯도 더 연구할 수 없다. 플레이어는 현재 개발된 프리셋만 연구할 수 있다. 아직 개발되지 않은 프리셋은 카드로 표시하지 않거나, 별도 슬롯 안내 영역에서 `미개발` 상태로만 표시한다.

### 새로운 엔진 개발

- 최대 10개 슬롯 안에서 다음 엔진 프리셋을 생성
- 생성되는 프리셋은 모든 기본 스펙과 비용이 기존 프리셋과 동일
- 생성 직후 완성도 0, 네 스탯 초기값으로 시작
- 생성 순서는 슬롯 인덱스 기준 `Engine02`부터 순차
- 비용과 소요 시간은 미정
- 미정 수치는 연구/설계 코드와 분리된 밸런스 값으로 둠

## 3. 엔진 설치 비용

설계 단계에서 엔진을 추가할 때마다 연구비가 든다.

| 엔진 | 기본 설치 비용 | 역할 |
|---|---:|---|
| 엔진 01~10 | 350 | 연구 상태가 다른 동일 규격 엔진 프리셋 |

설계 진입 버튼을 누르면 선택 미션의 예산을 즉시 차감한다. 설계 화면에서 엔진을 배치하면 화면상 연구비가 즉시 줄어든 것처럼 예약 표시한다. 단, 발사 전 `연구 단계로 돌아가기` 또는 엔진 제거를 선택하면 예약 설치 비용은 환불된다. 설계 진입 때 차감한 예산은 환불하지 않는다. 최종 `발사` 버튼을 누르는 순간 설치 비용만 확정 차감된다.

## 4. 발사 미션

발사 목표는 여섯 개의 순차 미션이다. 기존 `엔진 단계 → 로켓 단계 → 궤도 단계 → 달 착륙 단계` 구조는 사용하지 않는다.

| 미션 ID | 표시 이름 | 역할 | 핵심 조건 |
|---|---|---|---|
| `StaticFire` | 정적 연소 시험 | 엔진을 고정한 상태로 검증 | 지정 시간 연소, 과열 없음 |
| `LowAltitude` | 낮은 고도 도달 시험 | 로켓이 뜨는지 확인 | 낮은 목표 고도 도달 |
| `HighAltitude` | 높은 고도 도달 시험 | 출력 지속과 연료 균형 확인 | 높은 목표 고도 도달 |
| `TargetZone` | 목표 구역 도달 시험 | 높이와 수평 위치를 함께 확인 | 고도 조건 + 목표 구역 도달 |
| `ZoneHold` | 목표 구역 체류 시험 | 속도, 차단 타이밍, 자세 안정 확인 | 목표 구역 일정 시간 유지 |
| `LowPowerZoneHold` | 저전력 검증 시험 | 같은 목표를 효율적으로 수행 | `ZoneHold` 조건 + 전력/연료/비용 제한 |

각 미션은 연구 단계 카드가 아니다. 운영 화면의 `발사 미션` 영역에 잠금 상태, 최고 등급, 발사 횟수, 다음 해금 조건을 표시한다. 활성화된 이전 미션은 언제든 다시 선택할 수 있다.

최종 승리 조건은 `LowPowerZoneHold`에서 `B 이상`을 얻는 것이다. 이 결과를 2026년까지의 유인 달 착륙 성공으로 표현한다.

## 5. 현실 테스트 대응 원칙

미션 구성은 실제 로켓 테스트 절차를 게임용으로 축약한 것이다. 실제 개발은 엔진과 추진계 검증, 낮은 위험의 초기 시험, 더 높은 성능 조건, 통합 운용 조건, 효율과 운용 여유 확인으로 점점 올라간다.

게임 안에서는 이를 아래처럼 단순화한다.

| 현실 테스트 감각 | 게임 미션 |
|---|---|
| 정적 연소·핫파이어 | `StaticFire` |
| 초기 비행 가능성 확인 | `LowAltitude` |
| 성능 한계 확장 | `HighAltitude` |
| 목표 조건 비행 | `TargetZone` |
| 궤도·운용 상태 유지의 축약 | `ZoneHold` |
| 운용 여유와 효율 검증 | `LowPowerZoneHold` |

## 6. 설계·발사 가능 조건

설계 진입 버튼은 선택한 미션이 해금되어 있고 예산이 충분하면 누를 수 있다. 엔진 완성도와 스탯은 검사하지 않는다.

| 미션 | 조건 |
|---|---|
| 정적 연소 시험 | 게임 시작부터 해금 |
| 낮은 고도 도달 시험 | `StaticFire` C 이상 |
| 높은 고도 도달 시험 | `LowAltitude` C 이상 |
| 목표 구역 도달 시험 | `HighAltitude` C 이상 |
| 목표 구역 체류 시험 | `TargetZone` C 이상 |
| 저전력 검증 시험 | `ZoneHold` C 이상 |

```text
목표 구역 체류 시험
LOCKED
필요: 목표 구역 도달 시험 C 이상
```

설계 단계에 들어가는 것만으로는 비용과 분기를 쓰지 않는다. 발사 버튼을 누르기 전에는 연구 단계로 돌아갈 수 있다.

## 7. 미션 해금 조건

다음 미션은 직전 미션 발사 검증을 요구한다.

| 해금 미션 | 필요한 직전 미션 최고 등급 |
|---|---|
| `LowAltitude` | `StaticFire` C 이상 |
| `HighAltitude` | `LowAltitude` C 이상 |
| `TargetZone` | `HighAltitude` C 이상 |
| `ZoneHold` | `TargetZone` C 이상 |
| `LowPowerZoneHold` | `ZoneHold` C 이상 |

`C 이상`은 S/A/B/C를 의미한다. F만으로는 다음 미션이 열리지 않는다.

해금 검사는 발사 결과가 반영된 후 수행한다. 예를 들어 `StaticFire`에서 C를 받으면 `LowAltitude`가 열린다.

## 8. 발사 결과와 엔진 성장

발사는 실패해도 데이터를 남긴다. 하지만 발사 결과가 엔진 프리셋을 직접 업그레이드하지는 않는다. 엔진 성능 상승은 연구 단계에서 연구비를 내고 수행하는 업그레이드로만 발생한다.

발사 결과는 아래 값만 바꾼다.

- 해당 미션의 발사 횟수
- 해당 미션의 최고 등급
- 즉시 지원금
- 분기 연구비
- 사용된 엔진 프리셋의 시험 기록

## 9. 엔진 연구의 지속 가치

후속 미션 성공률과 설계 여유는 설치한 엔진 프리셋들의 성능을 계속 반영한다.

예시:

- 정적 연소 시험: 선택 엔진의 연료 지속력, 냉각 안정성, 점화 신뢰도 반영
- 낮은/높은 고도 도달 시험: 설치 엔진들의 평균 출력과 연료 지속력 반영
- 목표 구역 도달 시험: 엔진 방향, 출력, 자세 안정 반영
- 목표 구역 체류 시험: OFF 타이밍, 속도 제어, 자세 안정 반영
- 저전력 검증 시험: 설치 비용, 총 점화 시간, 출력 효율 반영

따라서 마지막 미션이 열렸어도 개발된 엔진 프리셋 일부를 추가 연구하거나 더 좋은 엔진 조합을 설계하면 최종 성공률이 올라간다. 필요하면 새 엔진 프리셋을 더 개발해 설계 선택지를 늘릴 수 있다.

## 10. 설계 조작의 지속 가치

설계 단계에서는 부품 위치, 힘, 방향, 엔진 ON/OFF 타이밍, 엔진 프리셋 배치를 조정한다.

- 엔진 추가: 현재 개발된 엔진 프리셋 중 하나를 선택해 부착점에 배치
- 엔진 제거: 발사 전이면 예약 비용 환불
- 초 단위 타이밍: `3.0초 ON`, `8.5초 OFF`처럼 설정
- 경로 지점 타이밍: `1번 체크포인트 ON`, `목표 경로 70% 지점 OFF`처럼 설정
- 타이밍은 예상 경로와 설계 적합도에 반영
- 발사 전에는 언제든 연구 단계로 돌아갈 수 있음

엔진 프리셋의 점화 신뢰도가 높을수록 같은 엔진 타이밍 오차를 더 잘 보정한다.

## 11. 발사 경험

각 미션은 발사 시도 횟수를 별도로 기록한다.

- 해당 미션 발사 1회당 성공 확률 `+3%p`
- 최대 `+9%p`
- 성공, 부분 성공, 실패 여부와 무관하게 증가
- UI에는 `발사 경험 +6%`처럼 표시
- 별도의 경험치 게이지는 만들지 않음

발사 경험은 실패에서도 데이터를 얻었다는 설정을 최소한의 시스템으로 표현한다.

## 12. 엔진 완성도 감소 여부

엔진 프리셋 완성도와 스탯은 어떤 경우에도 감소하지 않는다. 실패로 로켓이 파괴되어도 기술 지식 자체는 남는 것으로 처리한다. 손실은 설계 진입 때 차감한 예산, 확정된 엔진 설치 비용, 분기 연구비 삭감으로 표현한다.

## 13. 최종 미션

`LowPowerZoneHold`는 2026년 목표 달성 여부를 판정하는 최종 미션이다.

최종 미션 결과:

- S/A/B: 게임 승리
- C: 부분 성공, 지원금 반영 후 계속
- F: 실패, 분기 연구비 반영 후 계속
- 2026년 4분기 결과가 C/F이거나 최종 미션을 B 이상으로 통과하지 못하면 게임 패배

## 14. 금지 사항

- 엔진 단계/로켓 단계/궤도 단계/달 착륙 단계 구조
- 로켓 연구 버튼
- 궤도 연구 버튼
- 달 착륙 연구 버튼
- 전역 엔진 값 하나로 모든 엔진을 대표하는 구조
- 단계별 세부 연구 노드
- 연구 카드 랜덤 드로우
- 연구 성공 확률
- 연구원 배치 보너스
- 부품 인벤토리와 구매
- 엔진 프리셋 완성도나 스탯 하락
- 발사 결과로 다음 미션이 자동 완성되는 구조
