# 04. 연구·진행도·단계 해금

> 상태: **확정**  
> 원칙: 연구는 확정 성장, 발사는 연구·설계 적합도·테스트 공개성 판정

## 1. 네 단계

각 단계는 `0~100`의 진행도를 가진다.

| ID | 표시 이름 | 역할 |
|---|---|---|
| `Engine` | 엔진 개발 | 추력, 연소 안정, 내열성의 통합 수치 |
| `Rocket` | 로켓 설계 | 구조, 유도, 상승 안정성의 통합 수치 |
| `Orbit` | 궤도 운용 | 궤도 진입, 통신, 우주 운용 안정성의 통합 수치 |
| `Moon` | 달 착륙 준비 | 착륙 엔진, 센서, 자동 하강의 통합 수치 |

세부 기술 트리는 만들지 않는다. 진행도 하나가 각 단계의 모든 기술 성숙도를 대표한다.

## 2. 연구 행동

활성화된 모든 단계에서 아래 두 행동을 사용할 수 있다.

### 일반 연구

- 1분기 소비
- 단계별 비용 차감
- 진행도 `+6`
- 실패하지 않음

### 집중 연구

- 1분기 소비
- 단계별 비용 차감
- 진행도 `+10`
- 실패하지 않음

진행도는 100을 넘지 않는다. 연구 결과 팝업은 길게 만들지 않고, 운영 화면에서 게이지 증가와 짧은 텍스트로 처리한다.

## 3. 설계·발사 가능 조건

- 엔진, 로켓, 궤도 발사: 해당 진행도 20 이상
- 달 착륙 임무: 달 착륙 준비 진행도 50 이상

시뮬레이션 버튼은 조건을 충족하기 전에도 보이지만 잠금 상태로 표시한다.

```text
궤도 시뮬레이션
현재 진행도 14 / 최소 20
```

낮은 진행도에서 설계 단계에 들어갈 수 있는 이유는 위험한 조기 발사라는 선택을 허용하기 위해서다.

## 4. 단계 해금 조건

다음 단계는 진행도와 발사 검증을 모두 요구한다.

| 다음 단계 | 필요한 이전 단계 진행도 | 필요한 발사 최고 등급 |
|---|---:|---|
| 로켓 | 엔진 50 이상 | 엔진 발사 C 이상 |
| 궤도 | 로켓 55 이상 | 로켓 발사 C 이상 |
| 달 착륙 | 궤도 60 이상 | 궤도 발사 C 이상 |

`C 이상`은 S/A/B/C를 의미한다. F만으로는 다음 단계가 열리지 않는다.

해금 검사는 발사 결과와 진행도 변화가 모두 반영된 후 수행한다. 예를 들어 엔진 진행도 47에서 엔진 발사 C를 받아 진행도가 52가 되면 즉시 로켓 단계가 해금된다.

## 5. 발사 결과에 따른 진행도

| 등급 | 진행도 증가 |
|---|---:|
| S | +18 |
| A | +14 |
| B | +10 |
| C | +5 |
| F | +2 |

발사는 연구보다 높은 보상을 줄 수 있지만 비용과 실패 위험이 있다.

## 6. 이전 단계의 지속 가치

후속 발사 성공률과 설계 여유는 해당 단계 진행도뿐 아니라 이전 단계 평균 진행도에도 영향을 받는다.

예시:

- 로켓 발사: 엔진 진행도 반영
- 궤도 발사: 엔진과 로켓 평균 반영
- 달 착륙: 엔진, 로켓, 궤도 평균 반영

따라서 달 착륙 단계가 열렸어도 엔진이나 로켓을 추가 연구하면 최종 성공률이 올라간다.

## 7. 설계 조작의 지속 가치

설계 단계에서는 부품 위치, 힘, 방향뿐 아니라 엔진 ON/OFF 타이밍을 조정한다.

- 초 단위 타이밍: `3.0초 ON`, `8.5초 OFF`처럼 설정
- 경로 지점 타이밍: `1번 체크포인트 ON`, `목표 경로 70% 지점 OFF`처럼 설정
- 타이밍은 예상 경로와 설계 적합도에 반영
- 발사 전에는 언제든 연구 단계로 돌아갈 수 있음

연구 진행도가 높을수록 같은 엔진 타이밍 오차를 더 잘 보정한다.

## 8. 발사 경험

각 단계는 발사 시도 횟수를 별도로 기록한다.

- 해당 단계 발사 1회당 성공 확률 `+3%p`
- 최대 `+9%p`
- 성공, 부분 성공, 실패 여부와 무관하게 증가
- UI에는 `발사 경험 +6%`처럼 표시
- 별도의 경험치 게이지는 만들지 않음

발사 경험은 실패에서도 데이터를 얻었다는 설정을 최소한의 시스템으로 표현한다.

## 9. 진행도 감소 여부

진행도는 어떤 경우에도 감소하지 않는다. 실패로 로켓이 파괴되어도 기술 지식 자체는 남는 것으로 처리한다. 손실은 발사 비용과 분기 연구비 삭감으로 표현한다.

## 10. 달 착륙 단계

달 착륙 단계에는 별도의 사전 시험 버튼을 만들지 않는다. 달 착륙 준비 진행도 50부터 설계 단계에 들어가 최종 임무를 시도한다.

달 착륙 결과:

- S/A/B: 게임 승리
- C: 부분 성공, 진행도·지원금 반영 후 계속
- F: 실패, 진행도·분기 연구비 반영 후 계속
- 2026년 4분기 결과가 C/F이면 게임 패배

## 11. 금지 사항

- 단계별 세부 연구 노드
- 연구 카드 랜덤 드로우
- 연구 성공 확률
- 연구원 배치 보너스
- 부품 인벤토리와 구매
- 진행도 하락
- 발사 결과로 다음 단계가 자동 완성되는 구조
