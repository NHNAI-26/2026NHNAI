# 04. 엔진 프리셋 연구·단계 해금

> 상태: **확정**
> 원칙: 연구 단계의 연구 대상은 엔진 프리셋뿐이다. 로켓, 궤도, 달은 연구 항목이 아니라 설계·발사 단계다.

## 1. 연구 대상

연구 단계에는 미리 정의된 엔진 프리셋들이 존재한다.

| ID | 표시 이름 | 성격 |
|---|---|---|
| `Engine01`~`Engine10` | 엔진 01~10 | 동일 기본 스펙, 동일 연구 비용, 동일 설치 비용 |

각 엔진 프리셋은 개별 업그레이드 레벨과 스탯을 가진다. `엔진 전체 완성률` 같은 단일 연구 수치는 만들지 않는다.

로켓 연구, 궤도 연구, 달 착륙 연구는 만들지 않는다. 로켓·궤도·달은 해금된 뒤 설계 단계와 자동 발사 단계로만 진행한다.

## 2. 연구 행동

연구 버튼은 선택한 엔진 프리셋에만 적용한다.

### 일반 연구

- 1분기 소비
- 선택 엔진의 일반 연구 비용 차감
- 선택 엔진 업그레이드 레벨 `+1`
- 실패하지 않음

### 집중 연구

- 1분기 소비
- 선택 엔진의 집중 연구 비용 차감
- 선택 엔진 업그레이드 레벨 `+2`
- 실패하지 않음

업그레이드 레벨은 프리셋별로 최대 `5`다. 레벨이 오르면 해당 프리셋의 출력, 연소 지속력, 냉각 안정성, 점화 신뢰도가 상승한다. 기본 프리셋은 10개이며, 플레이어는 10개 프리셋 각각을 자유롭게 연구해 서로 다른 성장 상태로 만들 수 있다. 연구 결과 팝업은 길게 만들지 않고, 운영 화면에서 엔진 카드 수치 증가와 짧은 텍스트로 처리한다.

## 3. 엔진 설치 비용

설계 단계에서 엔진을 추가할 때마다 연구비가 든다.

| 엔진 | 기본 설치 비용 | 역할 |
|---|---:|---|
| 엔진 01~10 | 350 | 연구 상태가 다른 동일 규격 엔진 프리셋 |

설계 화면에서 엔진을 배치하면 화면상 연구비가 즉시 줄어든 것처럼 예약 표시한다. 단, 발사 전 `연구 단계로 돌아가기` 또는 엔진 제거를 선택하면 예약 비용은 환불된다. 최종 `발사` 버튼을 누르는 순간 설치 비용과 발사 비용이 함께 확정 차감된다.

이 규칙은 “엔진을 추가할 때마다 연구비가 든다”와 “발사 전까지 무를 수 있다”를 동시에 만족시키기 위한 처리다.

## 4. 네 발사 단계

발사 단계는 네 개다.

| 단계 ID | 표시 이름 | 연구 가능 여부 | 역할 |
|---|---|---|---|
| `Engine` | 엔진 테스트 | 가능 | 선택한 엔진 프리셋을 정적 연소 시험으로 검증 |
| `Rocket` | 로켓 테스트 | 불가 | 엔진 기술을 실제 상승 비행으로 검증 |
| `Orbit` | 궤도 테스트 | 불가 | 엔진 타이밍과 자동 보정으로 궤도 진입 검증 |
| `Moon` | 달 착륙 | 불가 | 최종 유인 달 착륙 임무 |

로켓, 궤도, 달 카드에는 연구 게이지를 표시하지 않는다. 대신 잠금 상태, 발사 최고 등급, 발사 횟수, 다음 해금 조건을 표시한다.

## 5. 설계·발사 가능 조건

설계 진입 버튼은 조건을 충족하기 전에도 보이지만 잠금 상태로 표시한다.

| 단계 | 조건 |
|---|---|
| 엔진 테스트 | 시험할 엔진 프리셋 레벨 1 이상 |
| 로켓 테스트 | 로켓 단계 해금 |
| 궤도 테스트 | 궤도 단계 해금 |
| 달 착륙 | 달 착륙 단계 해금 |

```text
궤도 시뮬레이션
LOCKED
필요: 로켓 테스트 C 이상
```

설계 단계에 들어가는 것만으로는 비용과 분기를 쓰지 않는다. 발사 버튼을 누르기 전에는 연구 단계로 돌아갈 수 있다.

## 6. 단계 해금 조건

다음 단계는 직전 단계 발사 검증을 요구한다.

| 해금 단계 | 필요한 직전 발사 최고 등급 |
|---|---|
| 로켓 | 어떤 엔진 프리셋이든 엔진 테스트 C 이상 |
| 궤도 | 로켓 테스트 C 이상 |
| 달 착륙 | 궤도 테스트 C 이상 |

`C 이상`은 S/A/B/C를 의미한다. F만으로는 다음 단계가 열리지 않는다.

해금 검사는 발사 결과가 반영된 후 수행한다. 예를 들어 엔진 01 테스트에서 C를 받으면 로켓 단계가 열린다.

## 7. 발사 결과와 엔진 성장

발사는 실패해도 데이터를 남긴다. 하지만 발사 결과가 엔진 프리셋을 직접 업그레이드하지는 않는다. 엔진 성능 상승은 연구 단계에서 연구비를 내고 수행하는 업그레이드로만 발생한다.

발사 결과는 아래 값만 바꾼다.

- 해당 단계의 발사 횟수
- 해당 단계의 최고 등급
- 즉시 지원금
- 분기 연구비
- 사용된 엔진 프리셋의 시험 기록

## 8. 엔진 연구의 지속 가치

후속 발사 성공률과 설계 여유는 설치한 엔진 프리셋들의 성능을 계속 반영한다.

예시:

- 로켓 발사: 설치한 엔진들의 평균 출력과 안정성 반영
- 궤도 발사: 엔진 ON/OFF 타이밍과 점화 신뢰도 반영
- 달 착륙: 엔진 개수, 연료 지속력, 냉각 안정성 반영

따라서 달 착륙 단계가 열렸어도 10개 엔진 프리셋 중 일부를 추가 업그레이드하거나 더 좋은 엔진 조합을 설계하면 최종 성공률이 올라간다.

## 9. 설계 조작의 지속 가치

설계 단계에서는 부품 위치, 힘, 방향, 엔진 ON/OFF 타이밍, 엔진 프리셋 배치를 조정한다.

- 엔진 추가: 엔진 01~10 중 하나를 선택해 부착점에 배치
- 엔진 제거: 발사 전이면 예약 비용 환불
- 초 단위 타이밍: `3.0초 ON`, `8.5초 OFF`처럼 설정
- 경로 지점 타이밍: `1번 체크포인트 ON`, `목표 경로 70% 지점 OFF`처럼 설정
- 타이밍은 예상 경로와 설계 적합도에 반영
- 발사 전에는 언제든 연구 단계로 돌아갈 수 있음

엔진 프리셋의 업그레이드 레벨과 점화 신뢰도가 높을수록 같은 엔진 타이밍 오차를 더 잘 보정한다.

## 10. 발사 경험

각 단계는 발사 시도 횟수를 별도로 기록한다.

- 해당 단계 발사 1회당 성공 확률 `+3%p`
- 최대 `+9%p`
- 성공, 부분 성공, 실패 여부와 무관하게 증가
- UI에는 `발사 경험 +6%`처럼 표시
- 별도의 경험치 게이지는 만들지 않음

발사 경험은 실패에서도 데이터를 얻었다는 설정을 최소한의 시스템으로 표현한다.

## 11. 엔진 레벨 감소 여부

엔진 프리셋 업그레이드 레벨과 스탯은 어떤 경우에도 감소하지 않는다. 실패로 로켓이 파괴되어도 기술 지식 자체는 남는 것으로 처리한다. 손실은 발사 비용, 확정된 엔진 설치 비용, 분기 연구비 삭감으로 표현한다.

## 12. 달 착륙 단계

달 착륙 단계에는 별도의 사전 시험 버튼을 만들지 않는다. 달 착륙 단계가 해금되면 설계 단계에 들어가 최종 임무를 시도한다.

달 착륙 결과:

- S/A/B: 게임 승리
- C: 부분 성공, 지원금 반영 후 계속
- F: 실패, 분기 연구비 반영 후 계속
- 2026년 4분기 결과가 C/F이면 게임 패배

## 13. 금지 사항

- 로켓 연구 버튼
- 궤도 연구 버튼
- 달 착륙 연구 버튼
- 전역 엔진 값 하나로 모든 엔진을 대표하는 구조
- 단계별 세부 연구 노드
- 연구 카드 랜덤 드로우
- 연구 성공 확률
- 연구원 배치 보너스
- 부품 인벤토리와 구매
- 엔진 프리셋 업그레이드 하락
- 발사 결과로 다음 단계가 자동 완성되는 구조
