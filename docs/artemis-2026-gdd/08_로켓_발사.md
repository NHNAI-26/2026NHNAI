# 08. 로켓 발사

## 정의

발사는 설계 화면에서 만든 로켓을 실제 Unity 물리로 실행하고, 미션 조건 충족 여부를 평가하는 단계다. 3D 장면은 이미 정해진 결과를 재생하는 영상이 아니다.

## 시작 조건

- 열린 미션이 선택되어 있다.
- 로켓 몸통과 하나 이상의 엔진이 있다.
- 설계와 설치 비용을 지불할 수 있다.
- 엔진 방향과 가동 시간이 유효하다.

## 실행 데이터

```text
LaunchRunData
  missionId
  visibility
  installedEngines
  engineStats
  transforms
  ignitionWindows
  paidCost
```

결과 필드는 실행 데이터에 넣지 않는다.

## 시퀀스

1. 설계 데이터를 검증하고 비용을 확정한다.
2. 시뮬레이션 장면을 연다.
3. 로켓과 엔진에 실제 수치를 적용한다.
4. 카운트다운 뒤 물리를 시작한다.
5. 텔레메트리를 계속 수집한다.
6. 미션 평가기가 목표 조건과 종료 조건을 검사한다.
7. 성공 여부와 종료 사유를 한 번 확정한다.
8. 성공 연출 또는 실패 상태를 보여준다.
9. 현장 사진을 촬영하고 결과 화면으로 이동한다.

## 플레이어 입력

발사 중에는 카메라 조작과 허용된 비상 종료만 제공한다. 추력 방향이나 가동 시간을 비행 중 바꾸지 않는다.

## 텔레메트리

- 고도와 최고 고도
- 수평·전체 이동 거리
- 속도
- 목표 구역 진입 및 체류 시간
- 엔진별 점화 상태와 총 연소 시간
- 남은 연료와 온도
- 실제 종료 사유

표시값과 결과 보고서는 런타임에서 측정한 같은 데이터를 사용한다.

## 결과 연출

- 성공: 현재 로켓을 사용한 낙하산 연출 뒤 결과 매체를 표시한다.
- 실패: 실제 종료 상태를 잠시 보여준 뒤 결과 매체를 표시한다.
- 폭발 또는 과열: 실제 발생한 효과가 보이는 시점에 사진을 촬영한다.

성공 연출 세부는 `../mission-success-cinematic.md`를 따른다. 결과 매체와 이벤트는 `../launch-outcome-events.md`를 따른다.

## 완료 기준

- 실제 설계 차이가 실제 궤적 차이로 나타난다.
- 미션 조건 충족 여부와 보고된 결과가 일치한다.
- 공개 여부는 비행에 영향을 주지 않는다.
- 결과 보고서 수치는 HUD의 최종 수치와 일치한다.
- 동일한 결과를 두 번 적용하지 않는다.
