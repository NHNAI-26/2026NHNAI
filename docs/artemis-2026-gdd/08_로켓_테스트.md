# 08. 로켓 테스트

> 상태: **확정**  
> 역할: 지상 엔진 기술이 실제 비행으로 이어지는 첫 장면

## 1. 시험 목적

시험용 단일 로켓을 자동 발사해 목표 고도와 비행 안정성을 검증한다. 다단 분리나 수동 조종은 구현하지 않는다.

## 2. 시험 조건

- 로켓 단계 해금
- 로켓 진행도 20 이상
- 시험 비용 900
- 현재 분기 1개 소비

## 3. 장면 구성

최소 에셋:

- 시험용 로켓 1개
- 단순 발사대
- 지상과 하늘 배경
- 엔진 불꽃과 연기
- 폭발 VFX
- 구름
- 강풍용 먼지 또는 빠른 구름
- 뇌우용 비와 번개

엔진 시험에서 사용한 불꽃, 연기, 폭발을 재사용한다.

## 4. 권장 시퀀스

| 시간 | 상태 | 연출 |
|---:|---|---|
| 0~4초 | 브리핑 | 시험명, 날짜, 환경 |
| 4~8초 | 카운트다운 | 발사대 조명, 3-2-1 |
| 8~13초 | 점화·이륙 | 연기 확산, 로켓 상승 |
| 13~24초 | 대기권 상승 | 고도·속도·자세 표시 |
| 24~32초 | 위험 구간 | 강풍, 추력 저하, 유도 오류 가능 |
| 32~38초 | 결과 | 목표 고도 달성, 중단 또는 추락 |

총 길이 목표: 30~40초

## 5. 주요 지표

```text
ALTITUDE
VELOCITY
ATTITUDE
ENGINE STATUS
```

결과 보고서:

- 최고 고도
- 최대 속도
- 평균 자세 오차
- 사고 원인

## 6. 사고 목록

| ID | 사고 | 주 연계 환경 | 결과 표현 |
|---|---|---|---|
| `GuidanceDrift` | 유도 오차 | 기술 사고 | 로켓이 서서히 기울어짐 |
| `ThrustLoss` | 추력 손실 | 기술 사고 | 불꽃 감소, 상승 둔화 |
| `StructuralStress` | 구조 진동 | 강풍 | 기체 흔들림과 경고 |
| `LightningInterference` | 번개 간섭 | 뇌우 | 전자장비 오류, 순간 자세 상실 |
| `MeteorNearLaunch` | 상층 대기 유성 잔해 | 유성우 | 근접 궤적 또는 외부 충격 |
| `Crash` | 추락·파괴 | F 결말 | 기울어 하강 후 폭발 |

## 7. 등급별 연출

### S

- 거의 수직으로 안정 상승
- 목표 고도를 크게 초과
- 경고 없음 또는 짧은 경고
- 화면 밖으로 상승하며 성공

### A

- 경미한 자세 오차
- 자동 유도 시스템이 복구
- 목표 고도를 안정적으로 달성

### B

- 큰 흔들림 또는 일시적 추력 저하
- 목표 고도 직전에 복구
- 최소 기준을 넘긴 직후 시험 종료

### C

- 목표 고도의 70~95% 도달
- 안전 한계를 넘기기 전 자동 엔진 정지
- 기체 회수 또는 원거리 낙하로 처리
- `FLIGHT ABORTED`

### F

- 발사대 점화 실패
- 상승 직후 유도 상실
- 구조 파괴 또는 추락
- 폭발 연출

## 8. 환경별 표현

### 강풍

- 로켓이 한쪽으로 흔들림
- 빠르게 이동하는 구름
- 먼지와 연기가 비스듬히 흐름
- A/B이면 자동 유도 복구
- C/F이면 경로 이탈

### 뇌우

- 어두운 하늘
- 비와 번개
- 계기판 또는 HUD 노이즈
- F이면 번개 간섭 후 유도 상실 가능

### 유성우

로켓 단계 보정은 -5뿐이다. 하늘의 유성 궤적을 약하게 보여주되 주요 위협은 궤도 단계보다 작게 표현한다.

## 9. 카메라

1. 발사대 전체
2. 노즐과 연기
3. 로켓 추적 카메라
4. 측면 원거리 카메라
5. 실패 시 지면 또는 광각 카메라

## 10. 구현 축소선

- 단 분리 없음
- 실제 공기저항 없음
- 실제 비행 경로 계산 없음
- 성공 경로는 애니메이션 곡선 사용
- 실패 시점부터만 Rigidbody를 활성화해 기울기와 추락을 표현 가능
- 로켓 내부와 승무원 장면 없음

## 11. 완료 기준

- 발사대에서 상승까지 한 흐름으로 보인다.
- 강풍과 뇌우가 성공 확률뿐 아니라 장면에도 반영된다.
- B의 가까스로 성공과 C의 조기 중단이 구분된다.
- 실패 시 로켓이 단순히 사라지지 않고 원인을 볼 수 있다.
- 결과 지표가 등급과 모순되지 않는다.
