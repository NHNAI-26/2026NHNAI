# 03. 시간·연구비·경제

> 상태: **확정**  
> 원칙: 경제는 선택을 만들기 위한 최소 구조이며, 독립적인 경영 게임으로 확장하지 않는다.

## 1. 시간 구조

- 프롤로그 시점: 2017년 12월
- 첫 플레이 분기: 2018년 1분기
- 마지막 플레이 분기: 2026년 4분기
- 총 행동 가능 분기: 36
- 모든 행동은 현재 분기 하나를 소비한다.
- 동시에 여러 연구를 진행할 수 없다.
- 2026년 4분기에는 마지막 행동 한 번을 수행할 수 있다.
- 그 행동 결과가 승리가 아니면 프로젝트 실패로 종료한다.

분기 표시는 다음과 같이 한다.

| 분기 | 화면 날짜 |
|---|---|
| 1분기 | 1~3월 |
| 2분기 | 4~6월 |
| 3분기 | 7~9월 |
| 4분기 | 10~12월 |

UI의 기본 표기는 `2024 Q3`이며, 보조 텍스트로 `2026년까지 9분기`를 표시한다.

## 2. 경제 값

### 현재 연구비

현재 행동에 사용할 수 있는 일회성 자금이다. 연구와 발사를 시작할 때 차감된다.

### 분기 정기 연구비

매 분기 종료 시 자동으로 지급되는 금액이다. 발사 성과에 따라 증액 또는 삭감된다. 별도의 신뢰도 수치를 만들지 않고, 기관의 신뢰와 투자 상태를 이 값으로 표현한다.

## 3. 시작 값

- 초기 연구비: `2,200`
- 초기 분기 정기 연구비: `600`
- 분기 연구비 하한: `300`
- 분기 연구비 상한: `1,000`
- 부채: 허용하지 않음
- 유지비와 급여: 없음

모든 금액은 현실 화폐 단위가 아닌 게임용 추상 연구비 단위다.

## 4. 한 행동의 경제 처리

### 연구

```text
연구 버튼 선택
→ 비용이 충분한지 검사
→ 비용 차감
→ 선택 엔진 프리셋 레벨과 스탯 즉시 증가
→ 분기 종료
→ 정기 연구비 지급
```

### 설계와 발사

```text
설계 진입 버튼 선택
→ 로켓 설계 단계 진입
→ 맵과 목표 경로 확인
→ 엔진 프리셋 배치, 부품 위치, 힘, 방향 조정
→ 엔진 설치 비용 예약 표시
→ 발사 전이면 연구 단계로 복귀 가능
→ 발사 버튼 선택
→ 발사 비용과 엔진 설치 비용 확정 차감
→ 설치 엔진 성능·설계 적합도·테스트 공개성으로 결과 고정
→ 자동 3D 발사 시뮬레이션
→ 등급에 따른 즉시 지원금과 분기 연구비 변화
→ 분기 종료
→ 변경된 분기 연구비 지급
```

설계 단계 진입과 일반 설계 수정은 비용과 분기를 소비하지 않는다. 엔진 추가 비용은 설계 중 예약 표시만 하며, 엔진 제거·설계 초기화·연구 단계 복귀 시 환불된다. 최종 `발사` 버튼을 누른 뒤에는 발사 비용과 엔진 설치 비용이 확정되어 되돌릴 수 없다.

### 대기

```text
대기 선택
→ 비용 없음
→ 현재 분기 종료
→ 정기 연구비 지급
```

발사 결과로 분기 연구비가 바뀌면, 해당 발사가 끝나는 분기부터 변경된 금액을 지급한다.

## 5. 발사 등급별 기본 경제 효과

| 등급 | 의미 | 즉시 지원금 | 분기 연구비 변화 |
|---|---|---:|---:|
| S | 압도적 성공 | +900 | +150 |
| A | 우수 성공 | +600 | +100 |
| B | 목표 달성 | +400 | +50 |
| C | 부분 성공 | +150 | 0 |
| F | 실패 | 0 | -100 |

변경 후 분기 연구비는 항상 300~1,000 사이로 제한한다.

최종 달 착륙을 제외한 발사는 공개 테스트와 비공개 테스트 중 하나를 선택한다.

| 테스트 방식 | 성공률 보정 | 즉시 지원금 배율 | 분기 연구비 변화 배율 | 실패 시 분기 연구비 삭감 |
|---|---:|---:|---:|---:|
| 공개 테스트 | -10%p | ×1.5 | ×1.5 | -150 |
| 비공개 테스트 | +10%p | ×0.5 | ×0.5 | -50 |

공개 테스트는 하이 리스크 하이 리턴이다. 성공하면 보상이 크지만 실패 시 기관 신뢰 손실도 크다. 비공개 테스트는 로우 리스크 로우 리턴이다. 실패해도 손실이 작지만 성공해도 지원금과 분기 연구비 상승이 작다.

달 착륙 최종 임무는 공개/비공개를 선택하지 않는다. 달 착륙 보상은 위 기본 경제 효과를 그대로 사용한다.

## 6. 자금 부족 처리

행동 비용보다 현재 연구비가 적으면 해당 버튼을 비활성화하고 필요한 금액을 표시한다.

```text
집중 연구
필요 950 / 보유 720
[연구비 부족]
```

자금이 부족해도 게임을 즉시 끝내지 않는다. `1분기 대기`는 항상 선택할 수 있으며, 분기 정기 연구비를 받아 복구할 수 있다. 다만 대기하는 동안 마감이 가까워지므로 자금 부족이 시간 압박으로 전환된다.

## 7. 경제가 만드는 두 가지 연구 선택

### 일반 연구

- 비용이 낮음
- 선택 엔진 프리셋 레벨 증가량이 작음
- 같은 목표까지 더 많은 분기가 필요함
- 자금이 부족하거나 안전하게 운영할 때 유리함

### 집중 연구

- 비용이 높음
- 선택 엔진 프리셋 레벨 증가량이 큼
- 시간을 아낄 수 있음
- 자금 확보가 잘되었거나 마감이 가까울 때 유리함

둘 중 하나가 항상 우월하지 않도록 비용 대비 시간 효율을 다르게 둔다. 엔진 프리셋 10개의 기본 스펙, 연구 비용, 설치 비용은 모두 같다.

## 8. 실패의 손실과 보상

발사 실패 시:

- 발사 비용은 돌려주지 않는다.
- 확정된 엔진 설치 비용은 돌려주지 않는다.
- 즉시 지원금은 없다.
- 분기 연구비가 100 감소한다.
- 엔진 프리셋 스탯은 발사 결과로 증가하지 않는다.
- 해당 단계 발사 경험 보너스가 3%p 증가한다.

따라서 실패는 분명한 손해지만 완전히 무의미하지 않다. 별도의 연구 데이터 재화나 원인 분석 화면은 만들지 않는다. 실패 데이터는 발사 경험과 시험 기록에만 흡수한다.
