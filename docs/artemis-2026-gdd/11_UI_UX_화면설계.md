# 11. UI·UX 화면 설계

> 상태: **확정**  
> 원칙: 플레이어가 한 화면에서 날짜, 돈, 기술, 설계 진입, 다음 행동을 판단할 수 있어야 한다.

## 1. 전체 화면 수

필수 화면은 7개다.

1. 프롤로그
2. 프로젝트 운영 화면
3. 로켓 설계 화면
4. 발사 확인 모달
5. 자동 3D 시뮬레이션 HUD
6. 결과 보고서
7. 승리·패배 결과 화면

별도 연구소 씬, 기술 트리 화면, 설정 전용 씬은 만들지 않는다.

UI는 런타임에서 모든 오브젝트를 코드로 새로 만드는 방식이 아니라, Canvas와 주요 패널·카드·버튼 프리팹을 배치하거나 인스턴스화하는 방식으로 만든다. 코드에서 직접 생성하는 UI는 디버그용 임시 화면에만 허용한다.

## 2. 프로젝트 운영 화면

### 2.1 권장 레이아웃

```text
┌──────────────────────────────────────────────────────────────┐
│ ARTEMIS: 2026       2024 Q3       남은 9분기                 │
│ 연구비 2,350        분기 연구비 +750                         │
├───────────────────────┬──────────────────────────────────────┤
│ 엔진 프리셋           │ 선택 엔진 / 발사 미션 정보          │
│                       │                                      │
│ 엔진 01 완성도 30%  │ 선택: 엔진 01                       │
│ [새로운 엔진 개발]  │ 연료량 / 냉각 / 최대 출력 / 점화    │
│                       │                                      │
│                       │ [일반 연구] [집중 연구] [설계 진입] │
│                       │                                      │
│ 낮은 고도  최고 A     │                                      │
│                       ├──────────────────────────────────────┤
│ 높은 고도  최고 없음  │ 설계에서 엔진 배치와 타이밍 조정    │
│ 목표 구역  최고 없음  │                                      │
│                       │                                      │
│ 저전력 검증 LOCK      │ [1분기 대기]                          │
└───────────────────────┴──────────────────────────────────────┘
```

모바일 대응은 범위에서 제외한다. 16:9 화면에서 스크롤 없이 핵심 정보를 모두 표시한다.

## 3. 상단 정보 바

항상 표시:

- 프로젝트명
- 현재 연도와 분기
- 남은 분기
- 현재 연구비
- 분기 정기 연구비

마감 압박 표현:

| 남은 기간 | 표현 |
|---|---|
| 13분기 이상 | 일반 표시 |
| 12분기 이하 | 남은 분기 강조 |
| 4분기 이하 | `FINAL YEAR` 표시, 경고음과 붉은 강조 |
| 마지막 분기 | `FINAL LAUNCH WINDOW` 표시 |

색만으로 정보를 전달하지 않고 텍스트도 함께 사용한다.

## 4. 엔진 프리셋 카드와 발사 미션

연구 화면 왼쪽의 주 목록은 엔진 프리셋 카드다. 처음에는 `Engine01` 카드 하나만 표시한다. `새로운 엔진 개발` 버튼을 누르면 다음 슬롯의 카드가 추가된다.

엔진 프리셋 카드에 표시할 정보:

- 엔진 표시 이름
- 엔진 완성도
- 네 스탯 요약
- 설치 비용
- 엔진 시험 최고 등급
- 엔진 시험 횟수
- 선택 상태

새 엔진 개발 버튼 예시:

```text
새로운 엔진 개발

남은 슬롯 7 / 10
비용/시간 미정
```

발사 미션은 연구 단계 카드가 아니다. 별도 `발사 미션` 영역에 잠금 상태, 최고 등급, 발사 횟수, 해금 조건만 표시한다. 활성화된 이전 발사 미션은 언제든 다시 선택할 수 있다.

## 5. 선택 미션 정보 카드

선택 정보 카드에 표시:

- 선택 엔진명과 엔진 스탯
- 선택 스탯 설명과 현재 위험 관계
- 일반 연구/집중 연구 비용과 스탯 상승량
- 선택 발사 미션명
- 공개 테스트 보상
- 비공개 테스트 보상
- 설계 단계에서 조정할 항목

예시:

```text
목표 구역 체류
공개 테스트: 보상 ×1.5 / 실패 손실 큼
비공개 테스트: 보상 ×0.5 / 실패 손실 작음
설계 항목: 부품, 힘, 방향, 엔진 ON/OFF
```

저전력 검증 최종 미션에서는 공개/비공개 테스트 선택을 숨기고 `FINAL MISSION`을 표시한다.

## 6. 행동 버튼

### 일반 연구

```text
일반 연구
선택 엔진 비용
완성도 +10 / 선택 스탯 소폭 증가
1분기
```

### 집중 연구

```text
집중 연구
선택 엔진 비용
완성도 +10 / 선택 스탯 중폭 증가
1분기
```

### 새로운 엔진 개발

```text
새로운 엔진 개발
다음 프리셋 생성
비용/시간 미정
```

### 설계 진입

```text
목표 구역 체류 설계 진입
예산 1,300
시간 0
```

### 대기

```text
1분기 대기
비용 0
분기 연구비 +750
```

버튼은 비용, 효과, 시간 세 정보를 동시에 보여준다.

## 7. 로켓 설계 화면

설계 진입 버튼을 누르면 예산을 즉시 차감하고 로켓 설계 화면으로 전환한다. 이 화면은 발사 전 판단 화면이며, 아직 분기와 발사 횟수는 소비하지 않는다.

필수 정보:

```text
ZONE HOLD DESIGN — 2024 Q3

목표 경로: 목표 구역 3초 체류
테스트 방식: 공개 테스트
설계 적합도: 64

주요 위험: 방향 오류 / 점화 불안정

[연구 단계로 돌아가기]      [발사]
```

필수 조작:

- 부품 위치 조정
- 힘 크기 조정
- 힘 방향 조정
- 엔진 ON/OFF 타이밍 조정
- 공개 테스트 / 비공개 테스트 선택
- 설계 초기화
- 연구 단계로 돌아가기
- 발사

맵에는 출발 지점, 목표 지점, 목표 경로, 현재 예상 경로를 표시한다. 현재 설계가 목표 경로에서 벗어나는 정도를 색과 숫자로 함께 표시한다.

엔진 ON/OFF 조정 UI는 둘 중 하나를 선택한다.

- 타임라인 방식: 초 단위 마커를 놓아 ON/OFF 설정
- 경로 마커 방식: 목표 경로 위 지점에 ON/OFF 설정

## 8. 발사 확인 모달

설계 화면에서 발사 버튼을 누르면 바로 자동 발사로 넘어가지 않고 확인창을 표시한다.

필수 정보:

```text
목표 구역 체류 — 2024 Q3

설치 엔진 점수         68
직전 미션 보너스       +10
발사 경험              +3%
테스트 방식            공개 테스트
설계 적합도            64
주요 위험              방향 오류 / 점화 불안정
엔진 설치 비용          700
예산                    이미 차감
소요 시간               1분기

[취소]                  [발사]
```

예상 성공률과 확률 계산 내역은 정식 UI에 표시하지 않는다. 발사 버튼을 누른 순간 결과가 고정되고 이후에는 되돌릴 수 없다.

## 9. 연구 완료 피드백

연구는 별도 결과 화면을 만들지 않는다.

- 비용 숫자가 감소
- 엔진 프리셋 카드의 완성도와 스탯이 애니메이션으로 증가
- `엔진 02 완성도 10% → 20%`
- 날짜가 다음 분기로 이동
- 새 정기 연구비가 들어오는 숫자 표시

전체 피드백은 1~2초 안에 끝낸다.

## 10. 3D 시뮬레이션 HUD

공통 배치:

```text
┌──────────────────────────────────────────────────────────────┐
│ ENGINE STATIC FIRE TEST              2022 Q1                 │
│ STATUS: NOMINAL                                              │
│                                                              │
│                         3D VIEW                              │
│                                                              │
│ THRUST  98%       TEMP  82%       STABILITY 91%              │
│                                                   [x2] [건너뛰기]│
└──────────────────────────────────────────────────────────────┘
```

원칙:

- 플레이어가 누를 수 있는 결과 개입 버튼은 표시하지 않는다.
- 경고 시 수치, 텍스트, 경고음을 함께 사용한다.
- 화면 전환 직후 등급을 노출하지 않는다.
- `건너뛰기`는 해당 종류의 발사를 한 번 이상 본 뒤 활성화하는 것을 권장한다.

## 11. 결과 보고서

결과 보고서는 5~8초 안에 읽을 수 있어야 한다.

```text
ZONE HOLD TEST REPORT

RESULT: B — 목표 달성

목표 구역 오차       4.8m
체류 시간            3.2초
선체 건전성          78%
사고                  엔진 OFF 지연 / 자동 복구

엔진 기록            변화 없음
즉시 지원금          +400
분기 연구비          +50

[프로젝트로 돌아가기]
```

등급 외에 반드시 “왜 이런 결과가 나왔는가”를 사고 원인 한 줄로 보여준다.

## 12. 미션 해금 피드백

해금 시 결과 보고서 다음에 짧은 오버레이를 표시한다.

```text
NEW MISSION UNLOCKED
LOW-POWER VERIFICATION
```

별도 씬이나 긴 연출은 만들지 않는다.

## 13. 승리 화면

필수 요소:

- `ARTEMIS PROJECT SUCCESS`
- 최종 미션 성공 날짜
- 최종 등급
- 총 발사 횟수
- 총 실패 횟수
- 사용한 총 연구비
- `다시 시작`

## 14. 패배 화면

원인 문구:

```text
2026 Q4 종료
최종 검증 목표를 달성하지 못했습니다.
PROJECT DEADLINE MISSED
```

엔진 프리셋 상태와 마지막 최종 미션 결과 요약을 보여줘 재도전 동기를 만든다.

## 15. 튜토리얼

팝업은 최대 3개다.

1. `연구는 기술을 확정적으로 올리지만 한 분기를 사용합니다.`
2. `시뮬레이션에서는 맵을 보고 로켓 부품, 힘, 방향, 엔진 ON/OFF 타이밍을 조정한 뒤 발사합니다.`
3. `2026년이 끝나기 전에 최종 검증 미션을 통과하십시오.`

첫 설계 화면에서 목표 경로와 설계 적합도를 강조하는 포인터를 한 번 보여준다.

## 16. 사용성 규칙

- 잠긴 기능의 조건을 항상 표시한다.
- 버튼을 눌렀는데 아무 반응이 없는 상태를 만들지 않는다.
- 연구비 부족 이유를 숫자로 표시한다.
- 공개/비공개 테스트의 보상과 손실 차이를 숫자로 표시한다.
- 발사 전 연구 단계로 돌아갈 수 있음을 명확히 표시한다.
- 등급은 색과 문자 둘 다 사용한다.
- 모든 핵심 버튼에 키보드 포커스를 지원하면 좋지만 P1이다.
