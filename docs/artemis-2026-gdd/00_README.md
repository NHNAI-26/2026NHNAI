## 한 문장 소개

2018년부터 2026년까지 우주개발 프로젝트를 운영하며 엔진을 연구하고 로켓을 조립해, 실제 물리 발사로 연속된 시험 미션을 통과하는 게임이다.

## 핵심 규칙

1. 플레이어는 발사 전에 엔진, 위치, 방향과 작동 시간을 정한다.
2. 발사 뒤 로켓은 설정된 값으로 실제 Unity 물리를 실행한다.
3. 미션 성공은 실제 비행 상태가 목표 조건을 만족했는지로 결정한다.
4. 성공한 미션은 다음 미션을 연다.
5. 최종 미션 성공이 승리 조건이다.
6. 공개·비공개 선택은 결과 뒤 매체와 이벤트에만 영향을 준다.
7. 엔진 완성도는 연구 가능량만 제한한다.
8. 시간, 연구비, 분기 연구비, 엔진 완성도와 네 스탯 외의 경영 자원은 추가하지 않는다.
