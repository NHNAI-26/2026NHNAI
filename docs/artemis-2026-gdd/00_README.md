> 기준일: 2026-09-04  
> 제작 조건: **48시간 게임잼**  
> 주요 대상: 기획자, 프로그래머, 아티스트, 사운드 담당자, 구현 보조 AI

## 한 문장 소개

2017년 12월 한 통의 연락으로 시작된 우주개발 프로젝트를 운영하며, 연구와 발사 시기를 결정하고, 발사 전 로켓 설계를 조정한 뒤 자동으로 진행되는 3D 발사를 지켜보며 **2026년이 끝나기 전에 유인 달 착륙을 성공시키는 프로젝트 운영 게임**이다.

## 최종 장르

- 프로젝트 운영
- 위험 관리
- 발사 시기 선택
- 로켓 설계 조정
- 공개·비공개 테스트 선택
- 자동 3D 발사 시뮬레이션
- 제한 시간 전략

발사 중 로켓을 직접 조종하는 게임이 아니다. 플레이어는 연구비, 10개 엔진 프리셋의 업그레이드 상태, 남은 시간을 보고 **어느 엔진을 연구할지, 기다릴지, 설계 단계로 갈지** 결정한다. 설계 단계에서는 이번 발사 맵과 목표 경로를 보고 엔진을 어디에 몇 개 달지, 힘, 방향, 엔진 ON/OFF 타이밍을 조정한다. 최종 달 착륙이 아닌 발사는 공개 테스트와 비공개 테스트 중 하나를 고른다. `발사` 버튼을 누른 뒤에는 자동 3D 시뮬레이션으로 결과가 판정된다.

## 반드시 지킬 핵심

1. 플레이어는 발사 중 결과에 개입하지 않는다.
2. 엔진 연구 결과는 프리셋 개체별 확정 성장이고, 발사 결과는 설치된 엔진 성능·설계 적합도·테스트 공개성에 따라 결정된다.
3. 모든 발사는 3D 장면으로 자동 재생된다.
4. 날씨, 환경 예보, 발사창 보정은 만들지 않는다.
5. 엔진 → 로켓 → 궤도 → 달 착륙 순서로 진행한다.
6. 다음 단계가 열려도 엔진 연구와 이전 단계 발사 재시도는 계속 가능하다.
7. 날짜, 연구비, 분기 연구비, 엔진 프리셋 업그레이드 상태 외의 경영 자원은 만들지 않는다.
8. 2026년 4분기 안에 달 착륙을 성공하지 못하면 패배한다.
9. 로켓 설계는 발사 전 조정에 한정한다. 실제 궤도역학이나 완전한 물리 계산이 아니라, 연구·설계 결과를 시각화하는 **연출형 자동 시뮬레이션**으로 구현한다.
10. 48시간 안에 완성 가능한 범위를 넘는 기능은 추가하지 않는다.
