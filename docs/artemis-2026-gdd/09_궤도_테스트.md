# 09. 궤도 테스트

> 상태: **확정**  
> 역할: 엔진 타이밍과 진입 각도 설계가 가장 강하게 드러나는 중후반 시험

## 1. 시험 목적

무인 시험선을 설계한 뒤 지구 궤도에 진입시켜 궤도 유지, 통신, 자동 보정 능력을 검증한다.

실제 궤도역학을 계산하지 않는다. 설계 단계에서는 목표 궤도 경로와 예상 경로를 단순화해 보여주고, 자동 발사 단계에서는 지구 주위를 도는 미리 정의된 경로와 속도 연출로 구현한다.

## 2. 시험 조건

- 궤도 단계 해금
- 궤도 진행도 20 이상
- 발사 비용 1,200
- 현재 분기 1개 소비
- 설계 단계 진입은 비용과 분기를 소비하지 않음
- 발사 버튼 선택 전에는 연구 단계로 복귀 가능

## 3. 장면 구성

최소 에셋:

- 지구 구체 1개
- 우주 배경
- 시험선 또는 로켓 상단부 1개
- 엔진 점화 효과
- 설계 오류 경고 VFX
- 작은 파편 또는 스파크
- 간단한 궤도 선
- 설계 단계용 목표 궤도 선
- 힘·방향 조정 핸들

## 4. 권장 시퀀스

설계 단계에서는 목표 궤도 선, 진입 각도, 엔진 ON/OFF 지점을 보여준다. 플레이어는 부품 위치, 점화 방향, 엔진 타이밍을 조정한 뒤 발사한다.

| 시간 | 상태 | 연출 |
|---:|---|---|
| 0~4초 | 브리핑 | `ORBITAL INSERTION TEST` |
| 4~10초 | 지구 접근 | 시험선과 지구 전경 |
| 10~18초 | 궤도 진입 점화 | 속도와 궤도 오차 표시 |
| 18~28초 | 궤도 안정화 | 지구 곡면을 따라 이동 |
| 28~38초 | 위험 구간 | 진입 각도 오류, 점화 시간 오류, 통신 오류 |
| 38~45초 | 결과 | 안정 궤도, 임무 중단, 재진입 또는 통신 두절 |

총 길이 목표: 35~45초

## 5. 주요 지표

```text
ORBIT ALTITUDE
ORBIT ERROR
VELOCITY
COMM LINK
HULL INTEGRITY
```

결과 보고서:

- 목표 궤도 오차
- 통신 유지율
- 선체 건전성
- 사고 원인

## 6. 사고 목록

| ID | 사고 | 주 연계 설계 항목 | 결과 표현 |
|---|---|---|---|
| `UnderBurn` | 속도 부족 | ON 시간 부족 또는 OFF 과다 | 궤도가 낮아지고 지구 쪽으로 내려감 |
| `OverBurn` | 과도한 점화 | OFF 타이밍 지연 | 궤도 오차가 커짐 |
| `CommunicationLoss` | 통신 두절 | 공개 테스트 실패 연출 | HUD 노이즈와 신호 감소 |
| `AttitudeFailure` | 자세 제어 이상 | 기술 사고 | 시험선 회전 |
| `Deorbit` | 궤도 상실 | F 결말 | 지구 방향으로 하강 |

## 7. 등급별 연출

### S

- 목표 궤도에 빠르게 진입
- 오차 0~2%
- 통신 98~100%
- 경미한 진입 각도 오차가 있어도 무손상

### A

- 궤도 오차 또는 통신 경고
- 자동 보정 점화로 정상화
- 임무 목표 달성

### B

- 과점화, 통신 두절 또는 자세 오류 중 하나가 발생
- 예비 시스템으로 복구
- 선체 또는 통신 지표가 낮지만 목표 달성

### C

- 지구 궤도 진입에는 성공했으나 안정 유지 실패
- 시험 데이터를 전송한 뒤 임무 중단
- 안전 재진입 또는 통신 상실 직전 종료

### F

- 속도 부족으로 재진입
- 점화 시간 오류로 자세 제어 상실
- 공개 테스트 실패 시 완전 통신 두절
- 목표 궤도에 진입하지 못함

## 8. 통신 오류 연출 규칙

- 화면에 짧은 전자 노이즈
- 통신 수치가 떨어짐
- 경고음과 끊기는 음성
- A/B에서는 보조 통신으로 복구
- C에서는 데이터 일부만 전송
- F에서는 통신 완전 두절

## 9. 엔진 타이밍 오류 연출 규칙

- ON이 늦으면 진입 각도가 낮아짐
- OFF가 늦으면 목표 궤도보다 높게 튐
- ON 시간이 짧으면 속도 부족
- A/B에서는 자동 보정 점화로 복구
- C/F에서는 궤도 유지 실패

## 10. 카메라

1. 지구와 시험선 전체
2. 시험선 후방 점화 장면
3. 궤도 선을 보여주는 측면
4. 엔진 재점화 또는 자세 보정 클로즈업
5. 실패 시 지구 방향 하강 또는 회전 장면

## 11. 구현 축소선

- 타원 궤도 수치 계산 없음
- 발사 중 플레이어 궤도 조작 없음
- 지구 한 바퀴를 실제 시간으로 돌지 않음
- 미리 정의한 Bezier 또는 Animation 경로 사용
- 성공과 부분 성공은 같은 기본 경로를 공유
- 실패 결말은 재진입, 통신 두절, 회전 중 하나만 사용

## 12. 완료 기준

- 지구 궤도 시험임을 한눈에 알 수 있다.
- 설계 단계에서 목표 궤도와 현재 예상 경로를 비교할 수 있다.
- 엔진 타이밍 오류와 통신 오류가 별도의 시각·음향 표현을 가진다.
- 궤도 성공, 부분 진입, 궤도 상실을 구분할 수 있다.
- 실제 물리 없이도 텔레메트리 변화가 설득력 있게 이어진다.
