# 09. 궤도 테스트

> 상태: **확정**  
> 역할: 유성우와 태양 폭풍이 가장 강하게 드러나는 중후반 시험

## 1. 시험 목적

무인 시험선을 지구 궤도에 진입시켜 궤도 유지, 통신, 우주 환경 대응 능력을 검증한다.

실제 궤도역학을 계산하지 않는다. 지구 주위를 도는 미리 정의된 경로와 속도 연출로 구현한다.

## 2. 시험 조건

- 궤도 단계 해금
- 궤도 진행도 20 이상
- 시험 비용 1,200
- 현재 분기 1개 소비

## 3. 장면 구성

최소 에셋:

- 지구 구체 1개
- 우주 배경
- 시험선 또는 로켓 상단부 1개
- 엔진 점화 효과
- 유성 파티클
- 충돌 스파크 또는 작은 파편
- 태양 폭풍용 화면 노이즈
- 간단한 궤도 선

## 4. 권장 시퀀스

| 시간 | 상태 | 연출 |
|---:|---|---|
| 0~4초 | 브리핑 | `ORBITAL INSERTION TEST` |
| 4~10초 | 지구 접근 | 시험선과 지구 전경 |
| 10~18초 | 궤도 진입 점화 | 속도와 궤도 오차 표시 |
| 18~28초 | 궤도 안정화 | 지구 곡면을 따라 이동 |
| 28~38초 | 위험 구간 | 유성우·태양 폭풍·통신 오류 |
| 38~45초 | 결과 | 안정 궤도, 임무 중단, 재진입 또는 통신 두절 |

총 길이 목표: 35~45초

## 5. 주요 지표

```text
ORBIT ALTITUDE
ORBIT ERROR
VELOCITY
COMM LINK
HULL INTEGRITY
```

결과 보고서:

- 목표 궤도 오차
- 통신 유지율
- 선체 건전성
- 사고 원인

## 6. 사고 목록

| ID | 사고 | 주 연계 환경 | 결과 표현 |
|---|---|---|---|
| `UnderBurn` | 속도 부족 | 기술 사고 | 궤도가 낮아지고 지구 쪽으로 내려감 |
| `OverBurn` | 과도한 점화 | 기술 사고 | 궤도 오차가 커짐 |
| `CommunicationLoss` | 통신 두절 | 태양 폭풍 | HUD 노이즈와 신호 감소 |
| `MeteorNearMiss` | 유성 근접 통과 | 유성우 | 여러 유성 궤적 |
| `MeteorImpact` | 유성 충돌 | 유성우 + C/F | 스파크, 자세 변화, 선체 손상 |
| `AttitudeFailure` | 자세 제어 이상 | 기술 사고 | 시험선 회전 |
| `Deorbit` | 궤도 상실 | F 결말 | 지구 방향으로 하강 |

## 7. 등급별 연출

### S

- 목표 궤도에 빠르게 진입
- 오차 0~2%
- 통신 98~100%
- 유성우라면 인상적인 근접 통과 후 무손상

### A

- 궤도 오차 또는 통신 경고
- 자동 보정 점화로 정상화
- 임무 목표 달성

### B

- 유성 충돌, 통신 두절 또는 자세 오류 중 하나가 발생
- 예비 시스템으로 복구
- 선체 또는 통신 지표가 낮지만 목표 달성

### C

- 지구 궤도 진입에는 성공했으나 안정 유지 실패
- 시험 데이터를 전송한 뒤 임무 중단
- 안전 재진입 또는 통신 상실 직전 종료

### F

- 속도 부족으로 재진입
- 유성 충돌로 자세 제어 상실
- 태양 폭풍으로 완전 통신 두절
- 목표 궤도에 진입하지 못함

## 8. 유성우 연출 규칙

유성우는 궤도 테스트의 대표 이벤트다.

- 배경 유성은 항상 여러 개 지나간다.
- A/B에서는 최소 한 번 가까이 지나가 긴장감을 준다.
- B에서는 작은 충돌 후 복구 가능
- C에서는 충돌 후 임무 중단
- F에서는 주요 충돌 또는 연쇄 자세 상실
- 실제 파편 시뮬레이션 대신 파티클과 짧은 Rigidbody 반응 사용

## 9. 태양 폭풍 연출 규칙

- 화면에 짧은 전자 노이즈
- 통신 수치가 떨어짐
- 경고음과 끊기는 음성
- A/B에서는 보조 통신으로 복구
- C에서는 데이터 일부만 전송
- F에서는 통신 완전 두절

## 10. 카메라

1. 지구와 시험선 전체
2. 시험선 후방 점화 장면
3. 궤도 선을 보여주는 측면
4. 유성 근접 통과 클로즈업
5. 실패 시 지구 방향 하강 또는 회전 장면

## 11. 구현 축소선

- 타원 궤도 수치 계산 없음
- 플레이어 궤도 조작 없음
- 지구 한 바퀴를 실제 시간으로 돌지 않음
- 미리 정의한 Bezier 또는 Animation 경로 사용
- 성공과 부분 성공은 같은 기본 경로를 공유
- 실패 결말은 재진입, 통신 두절, 회전 중 하나만 사용

## 12. 완료 기준

- 지구 궤도 시험임을 한눈에 알 수 있다.
- 유성우와 태양 폭풍이 별도의 시각·음향 표현을 가진다.
- 궤도 성공, 부분 진입, 궤도 상실을 구분할 수 있다.
- 실제 물리 없이도 텔레메트리 변화가 설득력 있게 이어진다.
