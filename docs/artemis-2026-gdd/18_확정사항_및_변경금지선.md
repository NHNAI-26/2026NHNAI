# 18. 확정사항 및 변경 금지선

> 상태: **최종 승인 기준**  
> 목적: 제작 중 기획이 다시 커지거나 핵심이 바뀌는 것을 막는다.

## 1. 최종 확정된 게임

`ARTEMIS: 2026`은 연구와 발사 시기를 결정하고, 발사 전 로켓을 설계한 뒤 결과를 자동 3D 시뮬레이션으로 지켜보는 프로젝트 운영 게임이다.

플레이어는 발사 중 직접 조종하지 않는다. 조작 실력보다 다음 판단이 중요하다.

- 어느 단계에 연구비를 쓸지
- 일반 연구와 집중 연구 중 무엇을 선택할지
- 현재 환경에서 시험할지
- 더 나은 발사창을 기다릴지
- 이번 맵에 맞는 부품 위치, 힘, 방향을 어떻게 정할지
- 실패를 감수하고 마감 전에 강행할지

## 2. 확정된 핵심 루프

```text
환경 예보 확인
→ 연구 / 대기 / 시뮬레이션 진입 선택
→ 연구·대기라면 한 분기 경과
→ 시뮬레이션이면 로켓 설계 단계
→ 발사 전이면 연구 단계로 복귀 가능
→ 발사 버튼으로 비용·시간·결과 확정
→ 자동 3D 발사 시뮬레이션 시청
→ 진행도와 연구비 반영
→ 다음 단계 해금
→ 2026년 전 달 착륙 시도
```

이 흐름을 바꾸는 기능은 추가하지 않는다.

## 3. 확정된 4단계

1. 엔진 테스트
2. 로켓 테스트
3. 궤도 테스트
4. 달 착륙

단계를 합치거나 늘리지 않는다. 네 단계 모두 3D 장면이 필요하다.

## 4. 확정된 자원

- 날짜
- 현재 연구비
- 분기 정기 연구비
- 네 단계 진행도
- 내부 기록용 시험 횟수와 최고 등급

플레이어가 별도로 관리하는 다섯 번째 경영 자원을 추가하지 않는다.

## 5. 확정된 시간 구조

- 2017년 12월 프롤로그
- 2018 Q1 시작
- 2026 Q4 종료
- 1행동 = 1분기
- 총 36행동 가능
- 병렬 연구 없음

## 6. 확정된 연구 구조

- 일반 연구: 저비용, +6
- 집중 연구: 고비용, +10
- 둘 다 1분기
- 연구 실패 없음
- 세부 기술 트리 없음

## 7. 확정된 설계·발사 구조

- 설계 단계에서는 맵과 목표 경로를 보여준다.
- 플레이어는 부품 위치, 힘, 방향을 조정한다.
- 발사 전에는 연구 단계로 비용·시간 소모 없이 돌아갈 수 있다.
- 발사 결과는 연구, 환경, 설계 적합도, 확률로 결정된다.
- 결과는 발사 버튼 직후 한 번만 결정된다.
- 자동 3D 장면은 결정된 결과를 표현한다.
- S/A/B 성공
- C 부분 성공
- F 실패
- 달 착륙은 B 이상만 승리
- 실패해도 진행도 +2와 경험 보너스 획득
- 실패 시 분기 연구비 삭감

## 8. 확정된 발사창 구조

- 현재 포함 4분기 예보
- 현재 분기에만 시험 가능
- 미래 발사창을 사용하려면 시간을 보내야 함
- 환경은 성공 확률과 3D 연출에 모두 반영
- 유성우와 태양 폭풍은 궤도·달 단계의 대표 위험
- 예보는 MVP에서 정확
- 한 분기당 주 환경 하나

## 9. 확정된 시뮬레이션 방향

- 발사 중 직접 조작 없음
- QTE 없음
- 자동 카메라
- 설계 데이터에 맞춘 경로와 상태 기반 연출
- 실패 구간에서만 단순 물리 사용 가능
- 실제 궤도역학 없음
- 한 시험당 주요 사고 최대 하나
- S/A/B는 성공 기본 시퀀스 공유
- C와 F는 결말 분기

## 10. 제작 중 추가 금지

아래 아이디어가 좋아 보여도 48시간 버전에는 추가하지 않는다.

- 연구원
- 시설
- 부품 구매
- 부품 인벤토리
- 연료 선택
- 국가별 계약
- 정치 이벤트
- 승무원 스탯
- 생명 유지
- 실제 궤도 계산
- 발사 중 로켓 조종
- 발사 중 착륙 조종
- 랜덤 연구 카드
- 두 개 이상의 화폐
- 인벤토리
- 업적
- 영구 성장
- 저장·불러오기
- 대규모 스토리
- 오픈 월드 관제센터
- 복수 엔딩 분기

## 11. 변경 가능한 범위

플레이테스트 결과에 따라 변경 가능:

- 비용
- 진행도 증가량
- 환경 보정 수치
- 즉시 지원금
- 분기 연구비 증감
- 카메라 타이밍
- 시뮬레이션 길이
- 텔레메트리 숫자 범위
- 텍스트 표현
- VFX 강도

단, 수치 변경 후에도 아래 경험은 유지해야 한다.

> 연구를 더 하면 안전해지고, 좋은 환경을 기다리면 유리하지만, 돈과 2026 마감 때문에 무한히 준비할 수 없다.

## 12. 범위 변경 승인 질문

새 기능을 넣기 전에 아래 질문에 모두 `예`라고 답할 수 있어야 한다.

1. 네 설계 단계와 자동 3D 발사 완성을 방해하지 않는가?
2. 2시간 이내에 구현·검증 가능한가?
3. 기존 자원이나 화면 수를 늘리지 않는가?
4. 발사 시기 판단을 더 명확하게 만드는가?
5. 버그 발생 시 즉시 제거할 수 있는 독립 기능인가?

하나라도 아니오라면 추가하지 않는다.

## 13. 최종 엘리베이터 피치

> 2026년까지 유인 달 착륙을 완수해야 합니다. 제한된 연구비로 기술을 높이고, 유성우와 태양 폭풍을 피해 발사 시기를 선택하십시오. 발사 전에는 맵과 목표 경로를 보고 로켓을 설계할 수 있습니다. 발사 버튼 이후에는 자동 3D 시뮬레이션이 당신의 판단 결과를 보여줍니다.

## 14. 최종 승인 문장

이 문서 묶음은 48시간 게임잼 버전의 최종 기획이다. 추가 아이디어보다 네 설계·발사의 연결, 판정의 공정성, 2026 마감 압박, 3D 결과 연출의 완성을 우선한다.
