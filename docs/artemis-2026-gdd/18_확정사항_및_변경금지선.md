# 18. 확정사항 및 변경 금지선

> 상태: **최종 승인 기준**  
> 목적: 제작 중 기획이 다시 커지거나 핵심이 바뀌는 것을 막는다.

## 1. 최종 확정된 게임

`ARTEMIS: 2026`은 연구와 발사 시기를 결정하고, 발사 전 로켓을 설계한 뒤 결과를 자동 3D 시뮬레이션으로 지켜보는 프로젝트 운영 게임이다.

플레이어는 발사 중 직접 조종하지 않는다. 조작 실력보다 다음 판단이 중요하다.

- 어느 엔진 프리셋에 연구비를 쓸지
- 새 엔진 프리셋을 개발해 설계 선택지를 늘릴지
- 선택 엔진에 일반 연구와 집중 연구 중 무엇을 적용할지
- 공개 테스트로 큰 보상을 노릴지
- 비공개 테스트로 손실을 줄일지
- 이번 맵에 맞는 엔진 프리셋 배치, 부품 위치, 힘, 방향, 엔진 ON/OFF 타이밍을 어떻게 정할지
- 실패를 감수하고 마감 전에 강행할지

## 2. 확정된 핵심 루프

```text
연구비·엔진 프리셋 상태·남은 시간 확인
→ 연구 / 새 엔진 개발 / 대기 / 시뮬레이션 진입 선택
→ 연구·대기라면 한 분기 경과
→ 시뮬레이션이면 로켓 설계 단계
→ 발사 전이면 연구 단계로 복귀 가능
→ 발사 버튼으로 비용·시간·결과 확정
→ 자동 3D 발사 시뮬레이션 시청
→ 시험 기록과 연구비 반영
→ 다음 미션 해금
→ 2026년 전 최종 미션 시도
```

이 흐름을 바꾸는 기능은 추가하지 않는다.

## 3. 확정된 발사 미션

1. 정적 연소 시험
2. 낮은 고도 도달 시험
3. 높은 고도 도달 시험
4. 목표 구역 도달 시험
5. 목표 구역 체류 시험
6. 저전력 검증 시험

기존 엔진/로켓/궤도/달 착륙 단계 시스템은 사용하지 않는다. 여섯 미션 모두 자동 3D 발사 연출이 필요하다.

## 4. 확정된 자원

- 날짜
- 현재 연구비
- 분기 정기 연구비
- 개발된 엔진 프리셋 업그레이드 상태
- 남은 엔진 프리셋 슬롯 수
- 내부 기록용 발사 횟수와 최고 등급

플레이어가 별도로 관리하는 다섯 번째 경영 자원을 추가하지 않는다.

## 5. 확정된 시간 구조

- 2017년 12월 프롤로그
- 2018 Q1 시작
- 2026 Q4 종료
- 1행동 = 1분기
- 총 36행동 가능
- 병렬 연구 없음

## 6. 확정된 연구 구조

- 연구 대상은 엔진 프리셋뿐
- 시작 시 개발된 프리셋은 엔진 01 하나
- 새로운 엔진 개발로 엔진 02부터 순서대로 추가
- 프리셋 종류는 최대 10개로 고정
- 새 엔진 개발 비용과 소요 시간은 미정
- 일반 연구: 선택 엔진 레벨 +1
- 집중 연구: 선택 엔진 레벨 +2
- 둘 다 1분기
- 연구 실패 없음
- 세부 기술 트리 없음
- 로켓, 궤도, 달 착륙 연구 버튼 없음
- 연구 단계 4개 구조 없음

## 7. 확정된 설계·발사 구조

- 설계 단계에서는 맵과 목표 경로를 보여준다.
- 플레이어는 엔진 프리셋 배치, 부품 위치, 힘, 방향, 엔진 ON/OFF 타이밍을 조정한다.
- 엔진 추가 시 설치 비용이 예약 표시된다.
- 발사 전에는 연구 단계로 돌아갈 수 있고 예약 설치 비용은 환불된다.
- 최종 미션이 아닌 발사는 공개 테스트 또는 비공개 테스트를 선택한다.
- 공개 테스트는 하이 리스크 하이 리턴이다.
- 비공개 테스트는 로우 리스크 로우 리턴이다.
- 발사 결과는 설치 엔진 성능, 설계 적합도, 테스트 공개성, 확률로 결정된다.
- 결과는 발사 버튼 직후 한 번만 결정된다.
- 자동 3D 장면은 결정된 결과를 표현한다.
- S/A/B 성공
- C 부분 성공
- F 실패
- 저전력 검증 최종 미션은 B 이상만 승리
- 실패해도 발사 경험과 시험 기록은 남음
- 실패 시 분기 연구비 삭감

## 8. 확정된 UI 제작 구조

- 운영 화면, 설계 화면, 발사 확인 모달, 결과 보고서는 프리팹 기반으로 만든다.
- 엔진 프리셋 카드, 발사 목표 카드, 스탯 행, 반복 버튼은 프리팹 인스턴스로 구성한다.
- 코드가 모든 UI 오브젝트를 직접 생성하는 방식은 정식 구현 경로에서 사용하지 않는다.
- 코드 생성 UI는 디버그용 임시 화면에만 허용한다.

## 9. 삭제된 날씨 구조

- 날씨 없음
- 환경 예보 없음
- 발사창 보정 없음
- 유성우, 태양 폭풍, 강풍, 뇌우 없음
- 발사 시기 판단은 날씨가 아니라 연구비, 엔진 프리셋 상태, 남은 시간, 공개/비공개 테스트 위험으로 만든다.

## 10. 확정된 시뮬레이션 방향

- 발사 중 직접 조작 없음
- QTE 없음
- 자동 카메라
- 설계 데이터에 맞춘 경로와 상태 기반 연출
- 실패 구간에서만 단순 물리 사용 가능
- 실제 궤도역학 없음
- 한 발사당 주요 사고 최대 하나
- S/A/B는 성공 기본 시퀀스 공유
- C와 F는 결말 분기

## 11. 제작 중 추가 금지

아래 아이디어가 좋아 보여도 48시간 버전에는 추가하지 않는다.

- 연구원
- 시설
- 별도 부품 구매
- 부품 인벤토리
- 연료 선택
- 국가별 계약
- 정치 이벤트
- 승무원 스탯
- 생명 유지
- 실제 궤도 계산
- 발사 중 로켓 조종
- 발사 중 착륙 조종
- 랜덤 연구 카드
- 시작 시 엔진 10개 전체 노출
- 로켓/궤도/달을 연구 단계로 분리
- 엔진/로켓/궤도/달 착륙 단계 시스템 복구
- 정식 UI 전체 동적 생성
- 두 개 이상의 화폐
- 인벤토리
- 업적
- 영구 성장
- 저장·불러오기
- 대규모 스토리
- 오픈 월드 관제센터
- 복수 엔딩 분기

## 12. 변경 가능한 범위

플레이테스트 결과에 따라 변경 가능:

- 비용
- 새 엔진 개발 비용과 소요 시간
- 엔진 프리셋 연구 비용과 레벨 상승량
- 즉시 지원금
- 분기 연구비 증감
- 카메라 타이밍
- 시뮬레이션 길이
- 텔레메트리 숫자 범위
- 공개/비공개 테스트 보정
- 엔진 ON/OFF 타이밍 허용 오차
- 텍스트 표현
- VFX 강도

단, 수치 변경 후에도 아래 경험은 유지해야 한다.

> 연구를 더 하면 안전해지고, 비공개 테스트는 손실을 줄이며, 공개 테스트는 큰 보상을 노릴 수 있지만, 돈과 2026 마감 때문에 무한히 준비할 수 없다.

## 13. 범위 변경 승인 질문

새 기능을 넣기 전에 아래 질문에 모두 `예`라고 답할 수 있어야 한다.

1. 여섯 발사 미션과 자동 3D 발사 완성을 방해하지 않는가?
2. 2시간 이내에 구현·검증 가능한가?
3. 기존 자원이나 화면 수를 늘리지 않는가?
4. 발사 시기 판단을 더 명확하게 만드는가?
5. 버그 발생 시 즉시 제거할 수 있는 독립 기능인가?

하나라도 아니오라면 추가하지 않는다.

## 14. 최종 엘리베이터 피치

> 2026년까지 유인 달 착륙에 필요한 최종 검증을 통과해야 합니다. 제한된 연구비로 기술을 높이고, 발사 전에는 미션 목표 경로를 보고 로켓을 설계하십시오. 공개 테스트는 위험하지만 보상이 크고, 비공개 테스트는 안전하지만 보상이 작습니다. 발사 버튼 이후에는 자동 3D 시뮬레이션이 당신의 판단 결과를 보여줍니다.

## 15. 최종 승인 문장

이 문서 묶음은 48시간 게임잼 버전의 최종 기획이다. 추가 아이디어보다 여섯 발사 미션의 연결, 판정의 공정성, 2026 마감 압박, 3D 결과 연출의 완성을 우선한다.
