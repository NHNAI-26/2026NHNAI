# 18. 확정사항 및 변경 금지선

> 기준일: 2026-09-06
>
> 이 문서는 현재 기획의 최상위 결정 기록이다.

## 1. 확정된 게임

2018년부터 2026년까지 연구와 예산을 운영하고, 엔진을 개발해 로켓을 조립한 뒤 실제 물리 발사로 연속된 시험 미션을 통과하는 게임이다.

## 2. 핵심 루프

```text
연구/대기/새 엔진 개발
-> 미션 선택
-> 로켓 조립과 발사 설정
-> 실제 물리 발사
-> 미션 조건 평가
-> 결과 보고와 후속 이벤트
-> 다음 행동
```

## 3. 발사 미션

1. `StaticFire`
2. `LowAltitude`
3. `HighAltitude`
4. `TargetZone`
5. `ZoneHold`
6. `LowPowerZoneHold`

직전 미션을 처음 성공하면 다음 미션을 연다. 최종 미션 성공이 승리 조건이다.

## 4. 자원과 연구

- 날짜와 분기
- 현재 연구비와 분기 연구비
- 최대 10개의 엔진 프리셋
- 프리셋별 완성도와 네 엔진 스탯

완성도는 연구 가능량의 상한만 정한다. 별도 성장 단계, 경험치, 숙련도는 만들지 않는다.

## 5. 발사 결과

- 시뮬레이션 전에 결과를 정하지 않는다.
- 실제 물리 상태로 미션 성공 여부를 평가한다.
- 결과는 성공 여부, 종료 사유와 실제 텔레메트리로 기록한다.
- 재시도 횟수와 과거 기록은 다음 비행 성능을 올리지 않는다.
- 공개/비공개 선택은 물리 결과를 바꾸지 않는다.

## 6. 설계와 물리

- 엔진 스탯은 추력, 연료, 열과 점화에 직접 반영한다.
- 엔진 위치와 방향은 힘과 토크에 직접 반영한다.
- ON/OFF 시간은 엔진 작동 구간에 직접 반영한다.
- 실제 비행 결과 위에 연출용 경로를 강제로 씌우지 않는다.
- 결과를 맞추기 위한 숨은 보정치나 강제 성공을 추가하지 않는다.

## 7. 공개성과 결과 이벤트

공개 여부는 결과가 난 뒤 표시 매체와 이벤트 후보를 고르는 데만 쓴다. 이벤트는 정산 단계에서 한 번 적용하며 이미 끝난 비행의 성공 여부를 바꾸지 않는다.

## 8. 추가 금지

- 날씨, 환경 예보, 발사창 시스템
- 별도 저장 시스템과 추가 경영 자원
- 실제 궤도역학 범위 확장

## 9. 변경 가능한 범위

- 엔진과 미션의 실제 물리 수치
- 목표 구역 위치와 크기
- 카메라, VFX, 사운드와 보고서 표현
- 결과 이후 이벤트의 수치
- 사용성 개선과 접근성

이 범위의 변경도 실제 물리 결과와 보고 데이터의 일치를 깨면 안 된다.

## 10. 최종 승인 문장

플레이어가 만든 로켓이 실제로 날고, 그 비행이 목표를 충족했는지가 모든 발사 결과의 유일한 근거다.
