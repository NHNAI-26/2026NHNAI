# 17. AI 구현 인수인계 명세

> 상태: **구현 계약**  
> 이 문서는 코딩 AI, 콘텐츠 생성 AI, 자동화 도구가 기획을 임의 확장하거나 바꾸지 않도록 작성되었다.

## 9. 결과 적용 원자성

`ApplyResult()`는 멱등성을 가져야 한다.

```pseudo
function ApplyResult(run):
    if run.resultApplied:
        return

    run.resultApplied = true

    mission.attemptCount += 1
    mission.bestGrade = BetterOf(mission.bestGrade, grade)

    rewards = ApplyVisibilityMultiplier(grade, run.launchVisibility)

    funds += rewards.immediateFunding
    quarterlyFunding += rewards.quarterlyFundingDelta
    quarterlyFunding = clamp(quarterlyFunding, 300, 1000)

    totalLaunches += 1

    if grade == F:
        totalFailures += 1
```

씬 이벤트, 건너뛰기, 결과 버튼이 모두 이 함수를 호출해도 한 번만 반영되어야 한다.

## 10. 시뮬레이션 구현 계약

각 발사는 최소 세 개의 시각 분기를 갖는다.

```yaml
visual_branches:
  success:
    grades: [S, A, B]
  partial:
    grades: [C]
  failure:
    grades: [F]
```

S/A/B의 차이는 경고 강도, 지표, 사고 복구, 결과 보고서로 표현한다. 별도 영상 전체를 만들 필요는 없다.

각 설계 미션:

```yaml
design_requirements:
  - show_mission_name
  - show_date
  - show_launch_visibility
  - show_generated_map
  - show_target_path
  - allow_part_placement
  - allow_force_adjustment
  - allow_direction_adjustment
  - allow_engine_on_off_timing_adjustment
  - show_design_fit
  - show_current_probabilities
  - allow_return_to_research_before_launch
  - launch_button_commits_cost_time_and_result
```

각 자동 시뮬레이션:

```yaml
simulation_requirements:
  - show_mission_name

  - show_launch_visibility
  - play_countdown_or_preparation

```

## 11. AI가 질문 없이 결정해도 되는 것

- 클래스와 파일의 세부 이름
- UI 프리팹 계층
- 애니메이션 구현 방식
- 카메라 전환 시간의 미세 조정
- 텍스트 문구의 자연스러운 다듬기
- 디버그 로그 형식
- 코드 스타일
- 폴더 구조

## 12. AI가 임의로 결정하면 안 되는 것

- 새 자원 추가
- 미션 수 변경
- 엔진/로켓/궤도/달 착륙 단계 시스템 복구
- 시작 시 엔진 프리셋 10개를 모두 표시
- 발사 후 조작형 시뮬레이션으로 변경
- 확률 실패 제거
- 날씨 또는 환경 예보 추가
- 2026 마감 변경
- 최종 미션 C를 승리로 처리
- 발사 도중 QTE 추가
- 실제 물리 구현을 이유로 여섯 발사 연출 중 하나 삭제
- 결과를 씬 내부에서 다시 추첨
- 실패 시 엔진 프리셋 레벨 감소

## 14. 구현 성공 정의

AI 구현은 단순히 코드가 컴파일되는 상태가 아니라 다음 흐름이 실제 빌드에서 끝까지 작동해야 성공이다.

```text
새 게임
→ 엔진 연구
→ 정적 연소 시험
→ 낮은 고도 도달 해금
→ 낮은 고도 도달 설계·발사
→ 높은 고도 도달 해금
→ 높은 고도 도달 설계·발사
→ 목표 구역 도달 해금
→ 목표 구역 도달 설계·발사
→ 목표 구역 체류 해금
→ 목표 구역 체류 설계·발사
→ 저전력 검증 해금
→ 저전력 검증 최종 미션
→ 승리 또는 2026 시간 초과
→ 다시 시작
```
