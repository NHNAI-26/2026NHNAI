# 02. 전체 플레이 흐름

## 전체 흐름

```text
새 게임
-> 연구 화면
-> 연구 / 대기 / 새 엔진 개발 / 미션 선택
-> 로켓 설계
-> 발사 확인
-> 실제 물리 발사
-> 성공 여부와 종료 사유 확정
-> 결과 보고 및 후속 이벤트
-> 다음 미션 해금 또는 연구 화면 복귀
-> 최종 성공 / 기간 만료
```

## 연구 화면

플레이어는 남은 기간과 연구비를 보고 엔진 프리셋 하나를 개발하거나, 새 프리셋을 만들거나, 분기를 기다리거나, 열린 발사 미션의 설계 단계로 간다.

## 설계와 발사

설계 화면에서 엔진을 장착하고 방향과 가동 시간을 정한다. 발사 확정 뒤에는 설정을 바꿀 수 없다. 시뮬레이션은 해당 설계를 실제 물리에 적용해 실행한다.

## 결과와 진행

- 성공하면 다음 미션을 연다.
- 실패하면 실제 종료 사유와 텔레메트리를 보여주고 연구 화면으로 돌아간다.
- 열린 이전 미션은 다시 선택할 수 있다.
- 재시도는 별도 성능 보너스를 만들지 않는다.
- 최종 미션 성공은 승리로 이어진다.
- 기간 만료 시 최종 미션을 성공하지 못했다면 패배한다.

## 상태 전환 원칙

- 비용과 결과 효과는 한 번만 적용한다.
- 결과 화면을 다시 열어도 해금과 정산을 반복하지 않는다.
- 공개 여부는 발사 뒤 표시 매체와 이벤트만 바꾼다.
- 발사 중 수집한 상태가 아닌 값으로 결과를 다시 계산하지 않는다.
