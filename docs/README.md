## 게임 기획 문서

- [ARTEMIS: 2026 GDD v1.0](artemis-2026-gdd/00_README.md)

`ARTEMIS: 2026 GDD v1.0`은 48시간 게임잼용 게임 기획 문서입니다. 게임의 범위, 플레이 흐름, 밸런스, Unity 구현 구조, 콘텐츠 제작 계획과 QA 기준을 포함합니다.

5. [테스트 공개성, 설계 보정, 확률](artemis-2026-gdd/05_테스트공개성_설계보정_확률.md)

### 문서 적용 기준

- 수치가 충돌하면 [밸런스 데이터표](artemis-2026-gdd/12_밸런스_데이터표.md)를 우선합니다.
- 구현 방식이 충돌하면 [AI 구현 인수인계 명세](artemis-2026-gdd/17_AI_구현_인수인계.md)와 [확정 사항 및 변경 금지선](artemis-2026-gdd/18_확정사항_및_변경금지선.md)을 우선합니다.
- GDD는 제품 요구 사항을 정의합니다. 저장소 작업 방식과 코드 규칙은 저장소의 개발 지침을 따릅니다.
- 원본 파일의 무결성은 [문서 매니페스트](artemis-2026-gdd/MANIFEST.md)에서 확인할 수 있습니다.
