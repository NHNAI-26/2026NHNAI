## 1. 목표

기존 로켓 조립·발사 프로토타입을 **부품을 로켓 표면 원하는 위치에 붙이고, 드래그로 화면을 돌려보며
조립하고, 연료가 소진되면 중력에 의해 추락하는** 물리 샌드박스로 확장한다.

작업 전 상태: (a) 부착이 하단 슬롯 2개로 고정, (b) 카메라 회전 불가, (c) 연료 없음 → 추력 무한 → 영원히 상승.

UD-013에 따라 이 기능들은 본편 편입 대상이지만, 편입 형태는 미해결이다(OI-011).

## 5. 핵심 조작 흐름 (구현된 형태)

1. **조립** — 로켓 `isKinematic` 고정. **우클릭 드래그**로 궤도 회전, 휠로 줌.
2. **좌클릭 드래그**로 부품을 집는다. 이미 붙은 부품도 다시 집어 옮길 수 있다.
3. 드래그 중 커서 레이캐스트가 로켓 표면(`Body` 캡슐, SF-012)에 맞은 지점에 부품을 놓는다. 자세는 로켓 기준 유지 (UD-009).
4. 표면 위에서 놓으면 부착, 밖에서 놓으면 시작 위치로 복귀.
5. **발사** — Space. `isKinematic` 해제, 엔진 수집, 연료 만탱크, `Log.D`로 엔진 수 기록.
6. **상승** — 엔진 위치에 추력 → 비대칭 배치가 그대로 토크.
7. **엔진별 소진** — 소진된 엔진부터 추력 0, 로그 한 줄. 남은 엔진 쪽으로 토크. 동일 부품이면 동시 소진이라 안 나타남 (AR-010).
8. **전 엔진 소진** — 추력 0, 중력만으로 감속·정점·낙하.
9. **접지** — 지면과 순수 물리 충돌. 리셋·폭발·판정 없음 (UD-008). 재시험은 Play Mode 재시작 (AR-011).

### 대체·오류 흐름
- 부착 실패 시 드래그 시작 위치로 복귀.
- 발사 후 부품 드래그 비활성, 카메라 회전은 유지 (AR-004).
- 엔진 0개 / 연료 0으로 발사해도 차단 없음, 추력만 없음 (AR-012).

## 7. 제약

- 씬 편집은 최후 수단. `SimulationTest.unity`는 아직 git 미추적.
- 직렬화 필드는 `[SerializeField] private` + 공개 읽기 전용 프로퍼티 (프로젝트 CLAUDE.md, SF-013).

# 14. 2차 라운드 — 지면 충돌 / 엔진 프리팹 / 불꽃 이펙트

1차 결과물을 사용자가 직접 돌려 본 뒤 요청: "발사 하고 나면 땅이 없어지는 거야? 떨어지면 땅에

## 14.4 구현한 것

- **`Rocket.cs`** — `Launch()`에서 `isKinematic`을 푼 직후
  `collisionDetectionMode = CollisionDetectionMode.Continuous`를 설정. `ContinuousDynamic`이 아니라
  `Continuous`인 이유는 지면이 정적 콜라이더이고 씬에 Rigidbody가 하나뿐이기 때문. `Awake`가 아니라
  `Launch`에 둔 이유는 `Awake`가 바디를 키네마틱으로 만들어 연속 판정이 무의미해지기 때문.
- **`RocketPart.cs`** — 직렬화 `ParticleSystem flame` 추가. `TryBurn`이 양쪽 경로에서 private
  `SetFlame(bool)`을 호출하므로, 추력을 멈추는 바로 그 자리에서 불꽃도 꺼진다. 불꽃 때문에 `Rocket.cs`를
  고칠 필요가 없었다. `isEmitting`으로 걸러 매 프레임 `Play()`를 다시 부르지 않고, null이어도 동작한다.
- **씬** — `Ground` localScale `(2,1,2)` → `(40,1,40)` = 400 m × 400 m. `Engine_A`/`Engine_B`를 프리팹
  인스턴스로 교체. **이후 개정**: 프리셋 패널 드래그가 유일한 배치 경로가 되면서 `Engine_A`/`Engine_B`와
  `Slot_L`/`Slot_R`을 모두 씬에서 삭제했다(RK-007 `superseded`). 현재 상태는 `docs/rocket-simulation.md` 참조.
- **`Assets/03. Prefabs/Simulation/RocketEngine.prefab`** — Cube 메시 + BoxCollider + `RocketPart` +
  자식 `Flame` ParticleSystem. 로컬 위치 `(0,-0.5,0)`, 회전 `(90,0,0)`으로 콘의 +Z를 부품의 −Y에
  맞추고, 로컬 스케일 `(2,1.25,2)`로 부모의 비균등 스케일 `(0.5,0.8,0.5)`을 상쇄한다.
  수명 0.15초, 속도 6, 방출 60/초, 콘 10°, `simulationSpace = World`(로켓이 70 m/s 이상으로 움직여
  Local이면 불꽃이 기체에 붙어 버린다), `playOnAwake = false`.
- **`Assets/05. Arts/Material/EngineFlame.mat`** — `Universal Render Pipeline/Particles/Unlit`,
  투명 + 가산, 주황. 프로젝트 Uber 파티클 셰이더는 **의도적으로 쓰지 않았다**(SF-019).
- **`RocketSimulationTests.cs`** — 세 번째 테스트 `Flame_TurnsOnWhileBurning_AndOffWhenDry`.
