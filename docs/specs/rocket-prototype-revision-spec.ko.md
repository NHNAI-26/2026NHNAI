# 로켓 발사 프로토타입 개선 계획

> 개정일: 2026-09-06
>
> 상태: 본편 방향 확정

## 목표

프로토타입의 자유 조립과 실제 물리를 본편 발사 흐름에 연결한다. 플레이어는 발사 전 설계하고, 발사 뒤 로켓은 그 설계대로 움직인다.

## 확정된 동작

- 로켓 표면 자유 부착
- 로컬 축 이동·회전 기즈모
- 엔진 위치와 방향에 따른 실제 힘과 토크
- 엔진별 연료, 열과 점화 상태
- 우클릭 궤도 카메라
- 연속 충돌을 사용하는 지면 접촉
- 미션별 실제 텔레메트리 수집
- 물리 상태 기반 성공 조건 평가

## 본편 연결

```text
DesignData
-> 로켓과 엔진 생성
-> 실제 물리 실행
-> 텔레메트리 수집
-> 미션 평가
-> LaunchResult
```

`DesignData`에는 엔진 프리셋, 위치, 회전, 작동 구간과 비용만 넣는다. 결과는 시뮬레이션이 끝난 뒤 만든다.

## 요구사항

- 엔진은 로켓에 붙어 있을 때만 로켓 질량과 추력에 참여한다.
- 추력은 엔진의 실제 위치와 `up` 방향에 적용한다.
- 비대칭 설계는 실제 토크를 만든다.
- 연료 소진, 과열, 점화 실패와 충돌을 구조화된 종료 사유로 전달한다.
- 미션 평가기는 표시 문구가 아닌 런타임 상태를 읽는다.
- 발사 결과 적용은 한 번만 실행한다.
- 공개 여부는 물리와 미션 평가에 영향을 주지 않는다.

## 제외

- 발사 중 추력 조작
- 다단 분리
- 짐벌과 자동 자세 제어
- 실제 궤도역학
- 실행 결과를 바꾸는 연출 경로
- 설계를 하나의 결과 보정값으로 환산하는 처리

## 검증

- 같은 설계와 초기 상태가 같은 궤적을 만든다.
- 엔진 위치·방향·수량을 바꾸면 예상한 물리 차이가 난다.
- 접지와 수면 접촉이 실제 충돌 상태에서 발생한다.
- 미션 조건 충족 여부와 결과 보고가 일치한다.
- 시뮬레이션 종료 뒤 임시 객체와 입력 잠금이 정리된다.
