# 발사 결과 이벤트

실제 비행의 성공/실패가 확정된 뒤 운영 효과를 적용한다. 발사 판정과 물리는 바꾸지 않는다. 효과 단위는 돈, 시간, 엔진 완성도, 엔진 스탯뿐이다.

## 이벤트 9종

최종 미션을 제외한 발사를 일반 미션이라고 부른다. 종료 사유는 `LaunchTerminationReason`으로 전달하며 표시 문자열을 분석하지 않는다.

| ID / 이름 | 발생 조건 | 효과 |
|---|---|---|
| `SponsorBoost` 후원 기관 추가 지원 | 일반 미션 공개 성공 | 즉시 연구비 +300, 분기 연구비 +50 |
| `CleanTelemetry` 깨끗한 비행 데이터 | 일반 미션 성공 | 대상 엔진 완성도 +5, 최저 스탯 +4, 다음 일반 연구 시간 면제 |
| `PublicPressure` 공개 성공 뒤 일정 압박 | 일반 미션 공개 성공, 발사 시작 연도 2025년 이전 | 즉시 연구비 +250. 다음 정상 행동이 대기면 분기 연구비 -50, 설계 진입이면 비용 -100 |
| `NearMissInspection` 근접 사고 점검 | 일반 미션 지면 추락 실패 | 다음 설계 진입 비용 -150, 대상 엔진 완성도 +3 |
| `RecoveredPayload` 시험 장비 회수 | 일반 미션 비공개 이륙 실패 | 같은 미션 다음 설치비 20% 할인, 최대 300 |
| `PadDamage` 발사대 손상 | 일반 미션 지면 추락 실패 | 즉시 연구비 -200, 다음 설계 진입 비용 +150, 사용 엔진 무작위 한 프리셋 완성도 -3 |
| `QuietLessons` 조용한 실패 분석 | 일반 미션 비공개 실패 | 대상 엔진 완성도 +4, 최저 스탯 +3 |
| `MediaBacklash` 공개 실패 역풍 | 일반 미션 공개 실패 | 분기 연구비 -100, 다음 발사가 공개면 보상 배율 -0.25 |
| `FinalProof` 최종 검증 인정 | `LowPowerZoneHold` 성공 | 기존 승리 처리, 효율 검증 통과 표시, 대상 엔진 완성도 +10, 최저 스탯 +5 |

장비 회수는 이륙하지 못한 장비를 다시 사용한다는 내용으로 표시한다. 실패 분석은 수집하지 않는 사고 원인을 추정하지 않고 최저 스탯을 올린다. 최종 실패에는 이벤트가 없다.

## 선택과 정산

- 적합한 후보 중 동일 가중치로 하나를 선택한다. 다른 후보가 있으면 직전 이벤트를 제외한다. 후보가 없으면 적용하지 않는다.
- 이벤트 전용 난수는 캠페인 시드로 초기화한다. 연구 난수에 영향을 주지 않는다. 모델 생성자의 `eventRandom` 함수로 테스트 선택을 제어할 수 있다.
- 보상 대상은 설치 개수가 가장 많은 엔진 프리셋이다. 동률이면 프리셋 ID가 앞선 쪽을 선택한다. 설치 엔진이 없으면 엔진 효과와 연구 시간 혜택을 생략한다.
- 발사대 손상의 엔진은 사용한 서로 다른 프리셋 중 동일 확률로 고른다.
- 최저 스탯 동률 순서는 연료 탱크 용량, 냉각 능력, 최대 출력, 점화 신뢰도다.
- 기본 발사 보상 정산 후, 분기 진행 전에 이벤트를 적용한다. 변경된 분기 연구비가 해당 분기 수입에도 반영된다.
- 완성도와 스탯은 0~100, 연구비는 0 이상, 분기 연구비는 기존 설정 범위로 제한한다. 보고서에는 제한 후 실제 증감량을 표시한다.
- 결과 보고서와 이벤트 알림은 정산 결과만 읽는다. 다시 열거나 재발행해도 효과를 중복 적용하지 않는다.

## 남은 효과 소비

- 일정 압박은 다음 정상 처리 행동에서 끝난다. 대기, 일반/집중 연구, 새 엔진 개발, 설계 진입을 포함한다. 실패한 행동은 소비하지 않는다.
- 설계 진입 비용 보정은 진입 비용을 실제 지불할 때 소비한다. 이후 설계에서 돌아와도 이미 지불한 비용과 소비된 보정을 되돌리지 않는다. 지불 전 취소는 소비하지 않는다.
- 같은 미션 설치비 할인은 발사를 확정할 때 소비한다. 다른 미션, 설계 편집, 발사 취소, 예산 부족으로는 소비하지 않는다. 할인액은 정수 설치비의 20%를 버림한 값이며 최대 300이다.
- 보상 배율 감소는 다음 발사 확정 때 귀속된다. 공개 발사는 기본 즉시 보상과 기본 분기 보상 배율에서 0.25를 빼고, 비공개/최종 발사는 효과 없이 소비한다. 배율은 0 아래로 내려가지 않으며 기본 실패 손실과 이벤트 보상에는 적용하지 않는다.
- 연구 시간 면제는 지정된 엔진의 다음 일반 연구에만 적용한다. 연구비는 정상 지불하며 시간과 분기 수입이 모두 발생하지 않는다. 다른 엔진 연구, 집중 연구, 실패한 연구 행동은 혜택을 유지한다.
- 같은 종류의 혜택은 중첩하지 않고 갱신한다. 새 시간 면제는 대상 엔진을, 새 설치비 할인은 대상 미션을 갱신한다. 서로 다른 종류는 함께 유지한다.
- 새 게임에서 모든 이벤트 상태와 전용 난수를 초기화한다. 기존 연구 세션 수명을 따르며 별도 디스크 저장 시스템은 추가하지 않는다.

## 코드와 UI

`ResearchLaunchEvents.cs`가 후보, 선택, 효과, 대기 상태와 비용 계산을 담당하고 `ResearchPrototypeModel`의 행동 처리에 연결된다. 실제 종료 사유는 평가기 → 미션 컨트롤러 → 스테이지 호스트 → 연구 세션 → 모델 순서로 전달한다.

결과 보고서에는 이벤트 이름, 설명, 실제 효과를 기본 보상과 구분해서 표시한다. 성공 확률, 굴림, 위험도 안내는 표시하지 않는다. 연구 화면과 설계 확인 화면에 남은 효과를 다시 표시한다. 비용 표시와 실제 결제는 같은 모델 계산을 사용한다.
