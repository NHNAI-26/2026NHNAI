# 대사 음성 베이커 (Voice Baker)

동물의 숲 NPC / 데이브 더 다이버식 지껄임 목소리를 만드는 에디터 툴. `Tools/Voice Baker`.

## 왜 오프라인 베이크인가

같은 소리를 만드는 방법은 두 가지다.

1. **런타임 합성** — 대사를 출력하면서 글자마다 음절 샘플을 `AudioSource.pitch` 랜덤으로 쏜다.
   대사가 바뀌어도 자동으로 따라오지만, 재생 코드·프리셋 데이터·보이스 풀이 전부 런타임에 실린다.
2. **오프라인 베이크** — 에디터에서 미리 합성해 대사 한 줄을 `.wav` 하나로 굽는다.

이 프로젝트는 2번을 택했다. 이유는 **런타임 비용이 정확히 0** 이기 때문이다. 구운 클립은
`SoundDatabaseSO` 의 평범한 SFX 행일 뿐이고, 재생은 이미 있는 `SoundManager.Instance.PlaySfx(id)` 를
그대로 탄다. 새 런타임 코드도, 빌드에 실리는 새 에셋 타입도 없다.

대신 대사를 고치면 다시 구워야 한다. 대사 수가 수백 줄로 늘고 텍스트가 자주 바뀌기 시작하면
그때 런타임 합성을 다시 검토한다. 그 전까지는 이쪽이 싸다.

관련 코드는 전부 `Assets/06. Packages/Editor/Voice/` 아래, 에디터 전용 어셈블리(`Border.Editor`)에 있다.

## 음절 샘플 녹음 가이드

프리셋에 넣는 것은 **대사가 아니라 무의미 음절**이다. 글자마다 이 풀에서 하나를 무작위로 뽑는다.

- **개수 4~8개.** 그 이하면 반복이 들리고, 그 이상은 캐릭터 개성이 흐려진다.
- **길이 80~150ms.** 길면 다음 글자와 겹쳐 웅웅거린다.
- **자음을 다양하게.** 바 / 데 / 무 / 키 / 포 / 타 처럼 조음 위치를 흩는다. 모음만 바꾸면 다 비슷하게 들린다.
- **`.wav` PCM 으로 저장.** 임포터 Load Type 이 `Decompress On Load` 여야 툴이 파형을 읽는다
  (Unity 기본값이라 보통 그냥 된다). `Streaming` 이나 `Compressed In Memory` 면 툴이 에러를 띄우고 멈춘다.
- 샘플레이트·채널은 안 맞춰도 된다. 툴이 모노 44100Hz 로 리샘플·다운믹스한다.

## 프리셋 파라미터

`Voice/Voice Preset` 으로 만든다. 에셋은 `Assets/02. ScriptableObjects/Audio/` 아래에 둔다.

| 항목 | 캐릭터에 미치는 영향 |
|---|---|
| `Pitch Range` | **가장 중요한 knob.** 재생 배속 범위. 속도와 피치가 같이 움직여 포먼트도 밀리므로 사람 목소리가 아니라 만화 캐릭터로 들린다 (Audacity 의 Change Pitch 가 아니라 Change Speed 쪽). `(0.75, 0.9)` 아저씨, `(0.9, 1.15)` 보통, `(1.3, 1.6)` 꼬마·작은 생물. 범위를 넓게 잡을수록 들뜬 말투가 된다. |
| `Seconds Per Char` | 말하는 속도. 타자기 연출(`PrologueBeat.typeSecondsPerChar`, 기본 0.06)과 맞춰야 글자와 소리가 붙어 보인다. |
| `Volume` / `Volume Jitter` | Jitter 를 0 으로 두면 기계적으로 균일하고, 0.15 쯤 주면 사람이 말하는 느낌이 난다. |

시드는 프리셋이 아니라 창에 있다. 같은 (프리셋, 대사, 시드) 는 항상 같은 파형을 내므로,
마음에 드는 소리가 나올 때까지 "굴리기" 로 시드를 바꿔가며 듣고 그 상태로 굽는다.
시드 `0` 은 매번 랜덤이라 구울 때마다 결과가 달라진다 — 확정된 대사에는 쓰지 않는다.

## 굽고 나서

1. 파일은 `Assets/04. Audios/SFX/Voice/<이름>.wav` 로 나온다.
   `Audios` 폴더의 `BGM/` `SFX/` 구분은 `SoundDatabaseSO` 의 두 목록과 1:1 로 대응한다.
   음성은 `SfxEntry` 로 등록되므로 `SFX/` 아래에 둔다.
2. **`SoundDatabase.asset` 에는 직접 끌어다 놓는다.** 툴이 자동 등록하지 않는다.
   `SoundDatabase.asset` 은 팀 전원이 공유하는 단일 YAML 파일이라, 굽는 사람마다 자동으로 행을 추가하면
   그 파일이 상시 머지 충돌 지점이 된다. 인스펙터에는 이미 "ID = 클립 이름" 버튼과 중복 ID 경고가 있다.
3. 재생은 `SoundManager.Instance.PlaySfx("<id>")`. 프롤로그처럼 비트 단위로 붙이려면
   `PrologueBeat.sfxId` 에 그 id 를 넣으면 된다 (`PrologueController` 가 비트마다 한 번 재생한다).

## 알아둘 것

- **임포트 노멀라이즈는 툴이 꺼준다.** Unity 오디오 임포터는 기본으로 피크 노멀라이즈를 켜는데,
  그대로 두면 구운 파일 음량이 창에서 들은 미리듣기와 달라진다. `Bake` 가 `m_Normalize` 를 끈 뒤 재임포트한다.
- **미리듣기가 끊기는 경우.** 미리듣기는 `SoundDatabaseSOEditor` 의 프리뷰 소스를 공유한다.
  재생 중에 `SoundDatabase.asset` 을 선택했다 해제하면 그쪽 인스펙터가 프리뷰를 정지시킨다. 다시 누르면 된다.
- **`VoicePresetSO` 는 에디터 전용 어셈블리에 있다.** 런타임 스크립트에서 참조하면 플레이어 빌드에서 깨진다.
  이 에셋은 굽는 시점에만 존재하는 입력이다.
- 초성·모음 분석 없이 **완전 무작위**로 음절을 고른다. 입모양이 대사와 맞아떨어지는 느낌이 필요해지면
  그때 `VoiceBaker` 의 음절 선택부에 한글 초성 매핑을 넣는다.
